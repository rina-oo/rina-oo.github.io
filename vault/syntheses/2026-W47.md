# 주간 종합: 2026-W47

이번 주는 서로 다른 날 나온 두 편이 거의 짜 맞춘 듯 맞물리는 게 가장 눈에 띄었다. 하나는 이론으로 예고하고, 다른 하나는 며칠 뒤 그 예고를 실측으로 확인했다.

## 흐름 1 — 이론이 예고한 숫자를 실측이 재확인하다

[[2611.18359|Envisioning Agentic Robotics]]는 파운데이션 모델을 로봇의 의사결정 계층(Embodied System 2)으로 쓸 때, 디지털 세계와 달리 물리 세계엔 데드라인이 있다는 "capped scaling" 개념을 내세우며 프론티어 모델이 S1 제어 스킬보다 40~8,000배 느리다는 수치를 제시했다. 순전히 문헌 종합에서 나온 추정치였는데, 오늘 리뷰한 [[2611.26444|Mind2Act World]]가 56,700개 에피소드 규모의 실측으로 거의 같은 이야기를 독립적으로 확인해준다. GPT-6 Astra는 호출당 11.0초가 걸리는 반면 VLA/WAM 정책은 77.1ms(π0.5)~488.1ms(InternW0)에 그쳐, 비율로 치면 22~143배 — 서베이가 예고한 범위의 아래쪽 끝과 겹치거나 살짝 못 미치는 수준이지만 방향은 정확히 일치한다. 더 흥미로운 우연은 두 논문이 서로를 인용하지 않았을 텐데도 똑같은 해법을 각자 제안했다는 점이다. 서베이는 모델·하네스·프로토콜을 한 장으로 요약하는 "harness card"를, Mind2Act World는 실패 코드·중단 지점·난이도별 성공률을 한 장으로 요약하는 "model profile card"를 각각 제안했다. 이론이 "이런 보고 형식이 필요하다"고 말한 걸, 실무가 "이렇게 만들어 봤다"로 거의 동시에 답한 셈이다.

[[2611.14815|BirdDreams]]는 이 둘과 결이 다르지만 같은 생태계 안에 들어온다. 주행 world model이 ego 차량의 반사실적 동작에 주변 차량이 그럴듯하게 반응하도록 투시-BEV를 동시 생성하는 기술인데, Mind2Act World가 한계로 꼽은 문제 — 과제별 시범 데이터가 적고 실패 후 복구 궤적이 아예 없다는 것 — 를 메울 수 있는 데이터 생성 축으로 읽힌다. 서베이가 이론을, 벤치마크가 실측을 맡았다면, world model은 그 둘 사이에서 "더 다양한 반사실 데이터를 누가 만들어줄 것인가"라는 다음 질문에 답할 후보다.

## 흐름 2 — 검증 가능한 환경을 누가, 어떤 층위에서 대량 생산하는가

[[2611.21072|Sage S2.1 Flash]]와 [[2611.22115|Xing4]]는 같은 전략(검증 가능한 환경을 대량 합성해 RL로 에이전트를 훈련)을 전혀 다른 층위에서 추진한다. Sage는 실제 MCP/웹 실행 트레이스에서 도구 그래프를 뽑아 77,760개 노드·804개 환경을 합성하는 ToolSpace로 모델 자체의 능력을 넓히는 데 집중하고, Xing4는 그 RL이 Ascend NPU 8,192장 위에서 실제로 굴러가게 만드는 데 집중한다(TeleGym으로 이기종 에이전트 하네스를 통합하고, HyperParallel-FSDP로 파이프라인 병렬화 자체를 걷어냈다). 흥미로운 대칭은 둘 다 자기 접근의 한계를 똑같은 지점에서 드러낸다는 것이다. Sage는 verifiable 환경으로 환원되지 않는 과제(SWE-bench Pro, 웹 검색)에서 1위를 놓치고, Xing4는 애초에 "그래서 이 인프라로 만든 모델이 얼마나 좋은가"를 보여주는 벤치마크 점수를 거의 제시하지 않는다. 인프라 투자(합성 환경 규모, 분산 학습 속도)와 모델 품질 사이의 연결고리가 두 보고서 모두에서 증명되지 않은 채 남아 있다는 뜻이다.

## 흐름 3 — 모델을 키우는 대신 결정의 구조를 바꾸기

[[2611.21373|WeVisForensics]]와 [[2611.24738|Jeveration]]은 전혀 다른 과제(딥페이크 탐지 vs 이미지 생성)를 풀면서 같은 종류의 재설계를 한다. WeVisForensics는 "영상 하나를 한 번에 판정"하는 대신 투자관이 필요할 때 전문 감식관을 부르는 2단 구조로 판정을 쪼개고, 투자관·감식관을 서로 다른 속도(fast/slow)로 동시 진화시킨다. Jeveration은 "토큰을 순차적으로 뽑는" 대신 128개 이미지 코드 전체가 공유하는 random state 하나를 매개로 한 번의 forward pass에서 동시에 "결정"하게 만든다. 둘 다 모델 파라미터를 늘리거나 더 많이 추론시키는 대신, 결정이 내려지는 구조 자체(누가 무엇을 언제 판단하는가, 코드들이 서로 어떻게 의존하는가)를 바꿔서 성능을 얻었다는 공통점이 있다.

## 다음 주 주목할 것

Mind2Act World가 예고한 "Mind/Act 오라클을 끼운 교정 실험"이 실제로 나오면, Envisioning Agentic Robotics의 이론적 분류와 실측 데이터가 얼마나 더 정교하게 맞아떨어지는지 확인할 좋은 기회가 될 것 같다. Sage와 Xing4 양쪽 다 인프라 규모와 최종 모델 품질을 직접 연결하는 벤치마크를 내놓지 않았는데, 둘 중 하나라도 이 간극을 다음 기술보고서에서 메우는지도 지켜볼 지점이다. BirdDreams는 코드·가중치 공개 계획이 아직 없어, 실제로 Mind2Act World류 벤치마크의 데이터 다양성 문제를 메우는 도구로 쓰일 수 있을지는 공개 여부에 달려 있다.
