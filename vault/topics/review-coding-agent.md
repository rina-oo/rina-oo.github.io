# 리뷰 허브: coding-agent

일일 논문 리뷰 중 `coding-agent` 태그가 붙은 논문들.
- 2026-09-01 [[2608.28281|코딩 에이전트에게 '뭘 시킬지'만 판단하는 모델을 따로 평가한다면]] — 코드를 직접 짜는 Worker는 고정한 채 "다음에 뭘 시킬지"만 판단하는 Controller 모델의 능력을, 실행 비용이 다른 세 단계(질문형·부분태스크·전체태스크)로 나눠 측정하는 벤치마크 LoopArena를 읽는다.
- 2026-09-07 [[2609.04148|궤적을 뒤집으면 환경이 나온다]] — 터미널 코딩 에이전트의 실행 로그(trajectory)를 거꾸로 재생해서 그 안에 숨어있던 실행 가능한 워크스페이스를 복원하고, 거기서 새 문제를 다시 만들어내는 Qwen팀의 데이터 합성 파이프라인을 읽는다.
