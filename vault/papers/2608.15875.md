# 이해·예측·행동을 하나의 정책으로 — GigaBrain-0.7: Scaling Embodied Foundation Models to Emergent Capabilities with a Three-System Architecture

> 원제: 이해·예측·행동을 하나의 정책으로 — GigaBrain-0.7: Scaling Embodied Foundation Models to Emergent Capabilities with a Three-System Architecture
> 리뷰: [블로그 전문](https://rina-oo.github.io/posts/2608.15875/)

## TL;DR
GigaBrain 팀의 세 번째 임바디드 파운데이션 모델. System 1(행동, PaliGemma2+Action Expert MoT)·System 2(이해/계획, PaliGemma2)·System 3(예측/평가, GigaWorld-1 기반 World Value Model)로 나뉜 3계층 구조를 하나의 배포 정책에 통합하고, 37,256시간의 이질적 임바디드 궤적(실로봇/UMI/EGO/시뮬/월드모델 생성)과 2.7억 개 VLM QA 샘플을 원스테이지로 동시 학습시킨다. Soft Knowledge Insulation으로 행동 학습 그래디언트가 VLM 지식을 해치지 않게 감쇠시키고, World Value Model이 예측한 미래 관측(subgoal image)과 진행도 가치(value→advantage)를 System 1에 조건으로 주입한다. post-training 후 π0.5·GigaBrain-0.1 대비 특히 휴머노이드(Maker H01) 복합 조작에서 큰 격차로 우위(74.1% vs 45.2%)이며, 배포 후에도 offline AWR → online actor-critic(사람 교정 포함)으로 지속 개선한다.

## 핵심 기여
- System 1/2/3 3계층 구조: System 2가 CoT+서브태스크를, System 3가 subgoal 이미지+advantage를 System 1에 조건으로 공급하는 명시적 인터페이스 설계
- Dual-Stream MoT(액션 익스퍼트가 VLM+자신 스트림에 양방향 attend, VLM은 자기 자신에만 causal attend)로 결합 아키텍처 확정 — Last/Multi-Layer Cross Attention보다 우수
- Soft Knowledge Insulation: FM(행동) 그래디언트를 계수 α로 감쇠시켜 VLM 백본에 전달, NTP 그래디언트는 감쇠 없이 전달
- World Value Model: 동일 백본에서 미래 영상(subgoal)과 task-progress 가치를 동시 산출, advantage $A_t=\mathbb{1}[V_{t+\delta t}-V_t>0]$로 이진화해 조건 주입. subgoal 50%/value 15% 독립 드롭아웃으로 신호 없을 때도 강건
- 데이터 피라미드: 실로봇 55%/UMI 22%/EGO 8%/시뮬 4%/WM생성 11%, 16개 로봇 형태 통합 표현(관절+엔드이펙터+마스크)
- 경험 기반 지속 개선: offline AWR($\tilde{A}_t=G_t-\tilde{V}_t$) → online actor-critic + 사람 교정, 4개 실로봇 과업에서 SFT 30.0% → offline 57.5% → online 100%

## 한계
- UMI/EGO 데이터 소스 조합 실험(로봇 3000h+UMI+EGO)에서 최종 조건만 총 데이터량(9000h)이 다른 조건(6000h)보다 많아, "이종 소스 조합 효과"와 "데이터 총량 효과"가 분리되지 않음
- MiMo-Embodied 벤치마크: 공개 최종 체크포인트의 헤드라인 점수(0.5704)는 저자 스스로 "held-out 아님"이라 인정 — 공정 비교치는 그 이전 체크포인트의 0.4621
- 백본 비교(PaliGemma2/Qwen3.5/Gemma4)에서 Gemma4 Clean Desk 결과가 각주로 별도 프로토콜(제한된 위치 일반화)임을 명시 — 표 내 조건 불일치. 저자도 "스케일링 법칙 아닌 진단"으로 한정
- 온라인 RL의 구체 알고리즘·보상 설계·사람 개입 프로토콜은 "전용 후속 리포트"로 미룸 — 이 논문만으로 재현 불가
- 코드/가중치는 "공개 예정"(미래형) — 작성 시점 실제 접근 가능 여부 미확인
- 로봇 실험 평가 시행 수가 "보통 10~20회"로만 명시, 데이터 스케일링 곡선 개별 점의 정확한 시행 수·신뢰구간 불명
- LaTeX 소스에 전혀 다른 논문(월드 모델 정책 평가자, WMBench) 초록/결론 초안이 주석으로 남아있어 최종 교정 이전 상태로 보임
