# Compile by Training: Turning Natural-Language Specifications into Local Neural Functions

> 원제: Compile by Training: Turning Natural-Language Specifications into Local Neural Functions
> 리뷰: [블로그 전문](https://rina-oo.github.io/posts/2609.04199/)

## TL;DR
Program-as-Weights(PAW)의 순전파 예측 컴파일러(초 단위, 낮은 정확도)에 이어, teacher LLM이 명세로부터 합성 데이터셋을 만들고 그 데이터로 공유 0.6B 인터프리터용 LoRA 어댑터를 직접 파인튜닝하는 두 번째 컴파일러 "compile by training"을 제안한다. 컴파일에 초 단위 대신 분 단위(~51초)를 투자하는 대신, PAW가 정답을 하나도 못 맞힌 FuzzyBench-Hard 부분집합에서 LEM을 0.224→0.836으로 끌어올린다. 컴파일된 함수는 이후 teacher 호출 없이 로컬에서 반복 실행되며, 서로 다른 컴파일된 함수들을 묶어 웹사이트 도우미·3D 아바타 제어·영어-Claudish 번역기 같은 실사용 서비스를 구성할 수 있음을 보인다.

## 핵심 기여
- Compile(s)→p_s, Run(p_s,x)→ŷ 인터페이스: 적응을 런타임 의존이 아닌 빌드 타임 단계로 재정의
- PAW 순전파 예측(θ_s^(0), r_s)을 웜스타트로 삼고, teacher 합성 데이터 D_s~T(s)로 100 스텝 파인튜닝해 정확도를 크게 개선
- teacher synthesis·모델 로딩·학습을 동시에 시작하는 streaming compile path + API/GPU 워커 분리 큐 구조로 분 단위 빌드를 인터랙티브 서비스 수준(동시 4작업, 평균 대기 1.01초)으로 만듦
- supervision sweep: teacher 품질(저비용 단독 0.746 vs GPT-5.5 혼합 0.851)이 데이터 양보다 더 크게 기여하며, 데이터 스케일링은 매끄럽지 않고 구간별로 정체됨(1440→2400 상승, 2400→3600 정체, 7200에서 재상승)
- paw-helper(30개 컴파일 프로그램으로 구성된 웹사이트 도우미), Avatar Director(자연어→액션 DSL, 44개 중 43개 성공), Claudish 번역기(공개 열흘 100,747건) 세 응용으로 독립 컴파일된 함수들의 조합 가능성을 실증

## 한계
저자 인정: 합성 supervision이 teacher 오류를 상속할 수 있어 정답 보장이 필요한 응용은 별도 검증/결정론적 경로 필요, 체계적 사용자 연구 부재. 리뷰어 지적: FuzzyBench-Hard가 기존 방법의 완전 실패 사례만 모은 부분집합이라 헤드라인 개선폭(+0.612)의 전체 벤치마크 일반화 여부 불명; PAW 웜스타트 대비 무작위 초기화의 ablation 부재로 웜스타트의 필수성 미검증; 0.6B 인터프리터+LoRA 조합이 복잡한 다단계 추론 함수까지 확장되는지에 대한 스케일링 분석 없음; LEM 판정자 검증 샘플(128개)이 헤드라인 지표를 뒷받침하기에 다소 작음.
