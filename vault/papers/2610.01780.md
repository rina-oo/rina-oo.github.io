# RealCompanion: Benchmarking Human Understanding from Reasoning over Longitudinal Real-World Conversations

> 원제: RealCompanion: Benchmarking Human Understanding from Reasoning over Longitudinal Real-World Conversations
> 리뷰: [블로그 전문](https://rina-oo.github.io/posts/2610.01780/)

## TL;DR
실제 AI 컴패니언 사용자 10명의 대화(27,218개 메시지, 최장 120일)를 동의 하에 공개한 longitudinal 벤치마크. 기존 벤치마크는 대화를 메모리 사실 주위로 구성해 π(과거 맥락 필요 비율)를 암묵적으로 1로 고정하지만, 실제 대화에서는 π가 3.4%에 불과함을 측정. Pooled ablation은 이 효과를 식별하지 못한다는 것을 Proposition으로 증명하고(Δ=πγ1+(1-π)γ0), 실측 분해로 "메모리가 도움된다"는 관측 개선분의 96%가 메모리 불필요 항목에서 나옴을 보임. 모든 채팅 라벨은 5단계(Referent→Verification→Classification→Grounding→Validation) 추론 trace를 동반해 감사 가능.

## 핵심 기여
- 생성/authored 벤치마크가 아닌 실제 배포 제품의 대화 기록에서 "과거가 필요한 비율" 자체를 처음으로 자연 발생률로 측정(3.4%, strict reading 1.3%).
- Proposition(The memory effect is not identified by a pooled ablation): Δ=πγ1+(1-π)γ0 분해로, π가 작을 때 pooled ablation이 메모리 효과를 식별하지 못함을 증명하고 실측(96%가 no-memory 항목에서 옴)으로 검증.
- 채팅 ground truth 생성을 5단계(A referent/B verification/C classification/D grounding/E validation)로 분리하고 각 단계의 판단 근거를 trace로 공개, verification은 단조적으로만 참조를 제거하므로 추정된 demand rate가 true rate의 하한이 되도록 설계(Proposition: one-sided error).
- Profile(사실)과 Persona(추론)를 분리한 5개 파일 스키마를 참가자별로 공개, 모든 claim이 원문 메시지를 인용.
- 메모리 필요 여부 탐지기가 실제 메시지에서는 AUROC 0.53(chance 수준)인 반면 authored question에서는 0.80로 올라간다는 것을 보여, authored corpus의 구조적 편향(cue leakage)을 실증.
- 3개 에이전트 시스템(Claude Opus 5.5, Codex GPT-5.6-sol, Antigravity Gemini 3.8 Flash)의 persona reconstruction이 처리 토큰 30배 차이에도 F1 0.69 전후로 동일함을 보임.

## 한계
- 참가자 10명이 단일 companion 애플리케이션 사용자에 한정, 2명이 전체 메시지의 73% 차지해 결과가 소수 관계 패턴에 좌우될 위험.
- 익명화 과정에서 전 메시지를 모델이 재작성(rewrite)했고, 이것이 검색/응답 점수에 미치는 영향은 측정되지 않음.
- on-screen 판단과 graded 응답 채점이 단일 reader/judge 조합에 의존(이진 판단 κ=0.804, graded scale κ=0.545로 더 낮음).
- 단일 companion 제품 위에서만 검증되어, 3.4%라는 demand rate가 다른 제품/UI에서도 재현될지는 알 수 없음 — 다만 방법론(pooled ablation의 비식별성)은 도메인에 무관하게 성립.
- 코드·데이터는 논문 시점에 OSF/익명 리뷰 링크로만 공개되어 안정적 공개 저장소 확인 불가.
