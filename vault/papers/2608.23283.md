# '완료된 작업'을 지능의 단위로 삼기 — Apodex 1.1: Scaling Agentic Intelligence for Complex Work

> 원제: '완료된 작업'을 지능의 단위로 삼기 — Apodex 1.1: Scaling Agentic Intelligence for Complex Work
> 리뷰: [블로그 전문](https://rina-oo.github.io/posts/2608.23283/)

## TL;DR
에이전트 지능을 정답률이 아니라 "완료된 작업(completed work)"으로 정의하는 Apodex 1.1 기술 보고서. 학습 가능한 실행 환경(파일·검색·코드)을 넓히는 Environment Scaling과, 태스크 분해·위임·병렬 조율을 정책으로 학습시키는 Agentic Coordination Scaling을 하나의 task contract 형식(E=(W,W0,q,A,T,Ω,B,D,V_D))과 지속 실행 런타임 AgentOS로 묶는다. 결과 점수 외에 실행 과정 자체를 채점하는 HDS6 프로세스 평가 프레임워크를 도입하고, PIVOT-RL(hindsight 기반 국지적 교정)로 학습한다. FrontierFinance·FrontierScience-Research에서 비교군 1위, IMO 2025/2026·USAMO 2026 금메달 기준선 통과, 35B mini 모델도 동급 대비 우위를 보이지만, GDPVal·HLE·APEX-Agents는 Claude Opus 5에 못 미치고 코딩(Terminal-Bench, SWE-bench)도 프론티어급에 뒤처진다.

## 핵심 기여
- Task Contract 형식화: 워크스페이스·목표·행동·전이·관측·예산·딜리버리계약·검증기를 하나의 튜플로 통일해 환경 구성, 협업 조율, 평가를 같은 언어로 기술
- Environment Scaling: 파일(권위/변환)·검색(발견/증거정합)·코드(실행/검증) 세 계열 환경을 profession-conditioned 시나리오 레지스트리(33도메인×318직업×1208클러스터)와 "forward cheap, inverse expensive" 검증 원칙으로 확장
- Agent Team 1.1: 잠재적 분해를 외부화한 태스크 보드, 비대칭 검증(검증자에게 좁은 단일 주장만 부여), 적응형 Max Team Effort(약한/논쟁적 주장에만 추가 조사 배정), 증거-그래프 기반 2단계 종합(evidence-graph construction + agentic synthesis)
- AgentOS 런타임: /inputs·/workspace·/outputs 3구역 네임스페이스, 단일-게시자 리스+매니페스트 대조로 공유 납품 무결성 보장, 프로바이더 신호 기반 tiered compaction, 소프트/하드 예산 이원화
- PIVOT-RL: 궤적을 사후분석해 실패로 이어지는 결정 지점(pivot)을 찾고 그 지점부터 짧은 교정 힌트를 붙인 국지적 연속 태스크로 학습, 비동기 최적화로 이질적 워크로드 처리
- HDS6 프로세스 평가: 6능력×4루브릭=24항목 + Mapper→Judge→Reviewer→Arbiter 채점 파이프라인 + 조작된 행동 서술 시 전체 무효화되는 무결성 게이트

## 한계
- 경쟁 모델 점수 다수가 제3자 리더보드가 아니라 저자 팀의 자체 하네스 재현값(GDPVal 외부 모델 전부, Claude Opus 5 APEX-Agents, FrontierFinance 일부) — 재현 설정이 원 논문과 동일했는지 불명확해 교차 비교 신뢰도에 유보 필요
- 논문 자신이 인정하듯 FrontierResearchBench(97개 end-to-end 과학 워크플로)에서는 최고 성능 시스템(GPT-5.6-Sol, Grok-4.6)조차 20.6% pass rate에 그침 — 산출물 상호일관성을 요구하는 고난도 실행에서는 모든 시스템이 여전히 취약
- 코딩 벤치마크(Terminal-Bench 2.1, SWE-bench Verified)에서 Apodex 1.1이 Gemini/Kimi/DeepSeek/Claude Opus 5에 모두 뒤처짐 — 파일/검색/과학 연구 강점이 순수 리포지토리 코딩까지는 전이되지 않음
- SFT/RL 절에 구체적 ablation 수치가 딸린 문단이 주석 처리(`%`)된 채 소스에 남아 있고 내부 미결 리뷰 주석(`\ownercheck`)도 다수 잔존 — 아직 확정되지 않은 초안 상태로 공개된 정황
- 부록에 계획됐던 EASIX 임상 생존분석·T-REMD 분자동역학·AI4AI 데이터 루프·법률/금융 사례 4건이 `\iffalse`로 비활성화되어 실제 공개본에는 미포함, 사유 설명 없음
- HDS6 채점 파이프라인 자체(GPT-5.5/Claude Sonnet 5/Claude Opus 5 조합)의 신뢰도·정합성을 별도로 검증한 근거가 제시되지 않음
- 3개 평가 패널(Deep Discover/Solve/Research)이 서로 다른 모델 크기·실행 모드·집계 방식(v1.0 Deep Discover만 8회 집계)을 써서 패널 간 비교가 불가능 — 특히 35B mini 모델(Deep Research)은 v1.0 대비 HDS6 개선 폭이 397B 모델보다 눈에 띄게 작음
