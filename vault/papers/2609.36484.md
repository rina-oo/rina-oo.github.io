# The Teacher Is a Direction, Not a Destination: Extrapolating RL-Induced Representation Residuals in On-Policy Distillation

> 원제: The Teacher Is a Direction, Not a Destination: Extrapolating RL-Induced Representation Residuals in On-Policy Distillation
> 리뷰: [블로그 전문](https://rina-oo.github.io/posts/2609.36484/)

## TL;DR
RL로 학습된 teacher를 on-policy distillation으로 베낄 때, teacher를 '도착점'이 아니라 '방향'으로 보자는 제안입니다. hidden state 공간에서 base→teacher residual을 teacher보다 더 멀리 extrapolate해서 학생에게 가르치면, 네 가지 base/teacher 조합 모두에서 student가 teacher를 능가합니다.

## 핵심 기여
- RL이 base 모델에 가한 변화를 hidden state 공간의 층별 residual $\Delta^{(l)}_t = h^{(l)}_{T,t} - h^{(l)}_{B,t}$로 정의. teacher와 base를 학생이 생성한 동일 prefix에 forward pass시켜 매 rollout마다 동적으로 계산.
- RIDE(RL-Induced Direction Extrapolation): target을 teacher 지점에 고정하지 않고 $h^\star = \lambda h_T + (1-\lambda) h_B$로 teacher 너머까지 extrapolate. $\lambda=1$에서 기존 OPRD(representation distillation)와 정확히 일치하는 일반화.
- 이 regression을 reward 극대화 + 이차 penalty로 재해석: $(\lambda-1) r(h) - \tfrac12\|h-h_T\|^2$, $r(h)=\langle h-h_T, \Delta\rangle$. output-space extrapolation의 KL-regularized RL 해석과 대응되는 representation-space 버전.
- 이론적으로 output-space extrapolation의 advantage 분산이 $(\lambda-1)^2\mathrm{Var}[\rho]$ 항 때문에 teacher-base 차이가 있는 한 사라지지 않고 증폭되는 반면, RIDE의 target은 두 frozen 모델의 결정론적 forward pass라 조건부 분산이 정확히 0임을 증명.
- 4개 base/teacher 쌍(R1-Distill-1.5B, Qwen3-4B, Llama-3.2-3B, Phi-4-mini) 전부에서 teacher를 근소하게 상회(+0.32~+1.08점)하는 유일한 방법. output-space extrapolation(ExOPD)은 네 쌍 모두 teacher 미달, 일부는 원본 student보다도 낮음.
- 메커니즘 분석: language-model head의 가장 약한 512개 singular 방향이 hidden-state residual 에너지의 79.8%를 담지만 centered-logit residual 에너지의 30.0%만 설명 — head가 정보가 가장 많은 방향을 가장 세게 감쇠시킨다는 실측.

## 한계
- direction ablation에서 랜덤 방향 대조군(같은 norm, 엉뚱한 방향)도 OPRD 대비 0.54점 개선을 보임. RIDE의 진짜 residual은 거기서 추가로 1.34점 더 얻는 수준이라, "RL 방향이 특별하다"는 주장의 margin이 크지 않음 — 효과의 상당 부분이 "target을 teacher 밖으로 밀어낸다는 사실 자체"에서 올 가능성.
- 두 번째 frozen forward pass(base 모델)가 추가로 필요해 연산 비용이 OPRD 대비 증가하지만 실제 wall-clock 오버헤드는 미보고.
- Llama-3.2-3B 쌍은 AIME 벤치마크 점수가 평가 하한선 근처(0.21~1.30점)라 증거가 주로 AIMO 하나에 의존. 저자들도 인정하는 한계.
- 같은 초기화를 공유하는 base/teacher/student 설정과 단일 RL 레시피(수학 추론)에서만 검증. head를 공유하지 않는 설정이나 다른 도메인으로의 일반화는 미검증.
- 코드·체크포인트는 "출판 시 공개 예정"으로 현재 시점 재현 불가.
