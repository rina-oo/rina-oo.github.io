# 정답 없는 문제를 '스파이 게임'으로 채점한다 — From RLVR to RLSVR: Task Transformation Induces Self-Verifiable Rewards for Open-Ended LLM Self-Improvement

> 원제: 정답 없는 문제를 '스파이 게임'으로 채점한다 — From RLVR to RLSVR: Task Transformation Induces Self-Verifiable Rewards for Open-Ended LLM Self-Improvement
> 리뷰: [블로그 전문](https://rina-oo.github.io/posts/2607.23802/)

## TL;DR
RLVR은 수학·코딩처럼 결정론적 verifier가 있는 도메인에만 적용 가능했다. 이 논문은 self-supervised learning의 task-transformation 원리를 RL 보상 설계에 옮겨, verifier가 없는 open-ended 과제(요약, 창작)를 environment가 정답(스파이 정체)을 쥐고 있는 다중 에이전트 소셜 게임으로 변환하는 RLSVR 패러다임을 제안한다. 구현체 SpyRL은 정보가 결손된 스파이 1명과 civilian n-1명이 같은 과제를 수행한 뒤 서로 투표로 스파이를 색출하게 하고, 이 투표 결과(완전히 검증 가능)를 과제 수행 단계의 zero-sum 보상으로 역전파한다. 외부 judge나 reward model 없이 요약·창작·수학 세 도메인 전부에서 기존 self-play 기법(R-Zero, Absolute Zero) 대비 일관된 향상을 보였다.

## 핵심 기여
- RLSVR: self-supervised learning의 pretext-task 원리를 RL 보상에 적용해, task transformation으로 환경이 스스로 정답(latent variable)을 쥐고 검증하는 보상 설계 프레임워크를 정식화
- SpyRL: 정보 비대칭 기반 소셜 추리 게임(스파이 찾기)으로 RLSVR을 구체화. 스파이 색출(detection) 단계는 완전히 규칙 기반 검증 가능, 이 결과를 다시 성능(performing) 단계의 zero-sum 보상으로 연결하는 two-stage coupled optimization 구조
- civilian 사이의 상대 경쟁까지 보상에 반영($\lambda(m_{c_j}-\bar m_c)$ 항)해 "스파이만 피하면 되는" 게임이 아니라 "동료보다도 나아야 하는" 게임으로 설계
- 요약(ROUGE 평균 +4.56/+4.04), 창작(A/B 승률 51%→75~84%), 검증 가능한 수학 추론(+8.40%p/+6.32%p)까지 verifiable/non-verifiable 경계 없이 일관된 향상 확인
- 투표 수와 GPT-4o 품질 순위의 상관관계 검증으로 vote 기반 보상이 실제 품질과 정렬됨을 별도 확인; group size ablation(n=3→5에서 최대 이득, n=6·8은 수확체감)과 module ablation(alternating optimization이 핵심)으로 설계 요소 분리

## 한계
- 품질-투표 정렬 검증에 다시 GPT-4o(LLM judge)를 사용해, 논문이 극복하려는 "judge 의존성" 문제에서 완전히 자유롭지 않음 (학습 루프 밖 사후 검증이라 직접적 순환은 아님)
- 연산 비용(n개 롤아웃 × performing/detection 이중 추론)에 대한 정량적 분석이 본문에 없음 — 재현 시 가장 궁금한 지점
- Qwen3-4B/8B 단일 계열로만 검증, 다른 모델 계열·스케일에서의 일반화는 미확인
- information-degradation operator $g(\cdot)$의 마스킹 비율(요약/창작 20%, 수학 40%)에 대한 ablation 부재 — group size는 ablation했으면서 이 하이퍼파라미터는 근거 없이 고정
