# MerchantBench: Benchmarking LLM Agents for Long-Term Coherence in E-Commerce Operations

> 원제: MerchantBench: Benchmarking LLM Agents for Long-Term Coherence in E-Commerce Operations
> 리뷰: [블로그 전문](https://rina-oo.github.io/posts/2607.28956/)

## TL;DR
98,843개 실제 e커머스(1688) 상품 레코드에 기반한 365일 주문 단위 POMDP 시뮬레이션 MerchantBench를 제안. 8개 LLM × 2개 에이전트 프레임워크(ReAct/Hermes) × 3회 반복, 총 48회의 365일 실행으로 평가. 최고 LLM 구성(Hermes+Qwen3.7-Max)의 최종 순자산이 인간 참가자 평균의 27.3%에 그침. 격차의 원인을 "운영을 계속 안 함(Operational Coherence 붕괴)"과 "지속하되 전략을 못 고침(Strategic Coherence 붕괴)"으로 분해해 트레이스 수준에서 분석.

## 핵심 기여
- 즉시 관측되는 Upstream Supplier Events(가격 변동/단종/배송 지연)와 지연 관측되는 Downstream Order Outcomes(취소/재고소진/반품/악평)를 분리한 order-level 시뮬레이터. 주문은 생성 시점에 이미 잠재적 결과가 확률적으로 정해지되 생애주기 도달 전까지 에이전트에 숨겨짐.
- 부분관측 POMDP 정식화: 중간 보상 0, 종료 시점 순자산(현금+보증금+배송중자금+미수금)만 보상. 수요·리스크 파라미터·미래 이벤트는 잠재 상태로 완전히 숨김.
- Sustained Window Rate(SWR, 30일 롤링 윈도우 전체에서 최소 1회 도구 호출 비율의 최솟값) 지표로 "활동 지속성"을 정량화. Human/Rule-based는 100%인데 LLM은 10.6~99.4%(ReAct), 17.8~66.1%(Hermes)로 크게 갈림.
- Operational Coherence(Activity Decay로 나타남) vs Strategic Coherence(Goal Consistency 실패=Control-Loop Narrowing/Premature Abandonment, Evidence-Calibrated Adaptation 실패)의 2축 분해. Kimi K2.6 한 실행은 104일째 "회복 불가" 판단 후 523개 윈도우 중 355개에서 무행동.
- 반복 실행 간 변동계수(CV)로 안정성 측정: Qwen3.7-Max+Hermes는 평균 1위(59.5천 RMB)지만 CV 55.1%로 불안정, GPT-5.6 Sol+ReAct는 CV 3.3%로 안정적. 평균 순위만으로 신뢰도를 판단할 수 없음을 시사.

## 한계
- Human 참가자가 3명뿐이라 개인차가 결과를 크게 좌우할 가능성. 참가자 동기부여/보상 설계가 논문에 상세히 나오지 않음.
- 데이터가 1688(중국 도매 플랫폼) 단일 소스. 618/11.11 같은 중국 특화 계절성이 강해 다른 시장에 일반화되는지 불명.
- Coherence 붕괴 사례들이 질적 트레이스 예시 중심이며, 48회 실행 전체에 걸친 정량 집계(예: Premature Abandonment 발생 비율)는 제시되지 않음.
- LLM 자체 능력과 에이전트 프레임워크(ReAct/Hermes)의 인프라적 차이가 결과에 뒤섞여 있어 분리하기 어려움. Kimi K2.6이 Hermes에서 오히려 저하되는 등 모델-프레임워크 상호작용이 단순하지 않음.
