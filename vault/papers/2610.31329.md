# 박스부터 투명한 머리카락까지, 한 모델로 — WeVisOne-VL: Unified Visual Perception from Objects to Pixels

> 원제: 박스부터 투명한 머리카락까지, 한 모델로 — WeVisOne-VL: Unified Visual Perception from Objects to Pixels
> 리뷰: [블로그 전문](https://rina-oo.github.io/posts/2610.31329/)

## TL;DR
Qwen3-VL 기반 2B/4B 모델. 좌표를 `<0>`~`<1000>` 토큰으로 양자화하고 인스턴스마다 `<OBJ>` 토큰 하나를 추가로 생성해 9.6M 파라미터 경량 픽셀 디코더(visual feature adapter + box-guided deformable query decoder + instance-conditioned dynamic mask head)를 트리거하는 구조로, detection·referring·counting·pointing·OCR(object-level)과 segmentation·matting(pixel-level)을 하나의 autoregressive 인터페이스로 통합. 1억 장+/36억 bbox 규모의 자체 데이터 엔진(WDE, 지식 그래프 기반 수집 + 다중 전문가 모델 검증 + 모델 오류 피드백 루프)과 3단계 SFT + 불확실성 기반 샘플링을 쓴 mixed-task GRPO로 학습. 30여 개 벤치마크에서 비슷한 크기 VLM·전용 grounding 모델 대비 우위, 특히 absent-target rejection에서 격차가 큼.

## 핵심 기여
- `<OBJ>` 토큰의 hidden state + 예측 박스를 그대로 디코더 쿼리로 재사용(q_i=W_h h_i, p_i=MLP(φ(b_i)))해 별도 segmentation 모델(SAM 등) 없이 박스→픽셀 연결
- 인스턴스별 동적 커널([k_i,β_i]=MLP(q̃_i), M_i=k_i^T P+β_i)로 공유 feature map에서 인스턴스마다 다른 마스크를 생성, coarse-to-fine 3단 정제로 세밀한 경계(머리카락, 알파 투명도) 복원
- 지식 그래프 기반 타겟 수집 + 복수 로컬라이제이션 전문가(SAM3, Rex-Omni, 자체 OV detector) 교차검증 + 모델 오류 피드백 루프로 구성된 데이터 엔진(WDE), hard negative 구축 시 "탐지기가 못 찾았다고 바로 negative로 단정하지 않고" 전체 이미지 재검증하는 절차 포함
- RL 샘플 선택에 불확실성 점수 U(x)=4μ(1-μ)σ 사용(성공률 50% 근처 + 보상 분산 큰 샘플 우선), GRPO 보상은 Hungarian-matched IoU^3 합을 (N_gt+N_pred)로 정규화해 누락·중복 동시에 패널티
- Ref-ZOM rejection rate 86.0%(기존 최고 수준 모델들은 0.3~41.9%), RefCOCOg-Rej 67.4%(기존 최고 22.5%) 등 absent-target 거절 능력에서 압도적 우위

## 한계
- segmentation·matting 과제도 RL 단계에서는 박스 기반 보상만 쓰고 마스크/알파 품질 자체는 RL로 직접 최적화하지 않음(SFT 단계 품질에 의존)
- rejection 관련 비교 벤치마크(WeRef-Bench, WeRefMat, PR-Bench)가 전부 저자 자체 제작 — 비교 대상 모델들이 애초에 rejection을 학습한 적 없어 공정성 논란 여지
- 데이터 엔진 각 단계(지식 그래프, hard example 구성, 피드백 루프)나 디코더 설계 선택에 대한 ablation 부재 — 구성요소별 기여도 분리 불가
- CoT 추론 미사용(추론 효율 트레이드오프), 단일 턴 예측만 지원, 일반 VLM 능력은 베이스 모델 대비 제한적 학습 데이터로 저하 가능성 (저자 자인 한계)
