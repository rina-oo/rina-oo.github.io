# 한 번의 forward pass로 그림을 그리다 — Jeveration이 이미지를 '결정'하는 법

> 원제: 한 번의 forward pass로 그림을 그리다 — Jeveration이 이미지를 '결정'하는 법
> 리뷰: [블로그 전문](https://rina-oo.github.io/posts/2611.24738/)

## TL;DR
NUS의 Jeveration은 이미지 생성을 "타입이 있는 결정(typed decision)"으로 재정의해, frozen VLM(Qwen3.5-4B) + 공유 LoRA 어댑터가 단 한 번의 forward pass로 128개 이미지 코드를 동시에 뽑는다. 독립 병렬 샘플링은 코드 간 상호의존(total correlation)을 못 잡아 이미지가 뭉개지는 문제(Fig.1)를, 모든 코드 위치가 공유하는 random state $\xi$ + 2단계 distribution-matching 학습(1단계: masked prediction으로 이미지 분포 학습, 2단계: Di[M]O 스타일 token-level matching으로 $\theta$가 $\xi$를 실제로 활용하게 훈련)으로 해결한다. 같은 체크포인트가 text-to-image, image-to-image, dense prediction(세그멘테이션/깊이/법선)을 모두 커버한다. 512px 이미지를 H200에서 78ms, Janus-Pro-7B 대비 122배 빠르게 생성하며 GenEval 0.74.

## 핵심 기여
- 이미지 생성을 diffusion(반복 denoising)/autoregressive(순차 토큰)가 아닌 "병렬 결정"으로 재정의한 첫 사례. System One(Jev) 계열을 판단 작업에서 생성 작업으로 확장
- 공유 random state $\xi$: 모든 코드 위치가 $(y,\xi)$에 조건화되어 독립 샘플링이면서도 $\xi$를 매개로 전역 일관성 확보. total correlation = KL(p‖q_ind) 분석으로 독립 샘플링의 한계를 이론적으로 짚음
- 2단계 학습: (1) masked model $\phi$로 이미지 분포 자체를 학습 (2) distribution matching loss $\mathcal L_{DM}$ = sg(p_ψ - p_φ)ᵀℓ_θ 로 $\theta$가 $\xi$를 실제로 활용해 "한 번에 맞는" 코드를 뽑도록 훈련. 직접 지도학습만으로는 모델이 $\xi$를 무시하는 실패 사례를 사전에 확인
- confidence-guided correction: 저신뢰 위치를 frozen 모델이 여러 라운드로 보정한 타겟으로 직접 지도(추론 시에는 영향 없음, 학습에만 사용)
- 하나의 frozen VLM + 공유 LoRA로 text-to-image/image-to-image/dense prediction 통합. joint training이 text-to-image 품질을 거의 깎지 않음(GenEval 0.73→0.74)
- 속도: 512px 78ms/이미지(H200), unified 모델 중 최速이면서 GenEval도 최고(0.74)

## 한계
- GenEval(0.74)은 높지만 DPG-Bench(78.24)는 중위권 — 복잡한 다중 속성/긴 프롬프트 추종력에서는 diffusion 계열에 밀리는 것으로 보이나 논문이 원인을 분석하지 않음
- 코드 개수 N=128, dense query 432개로 설정이 고정되어 있어 더 높은 해상도·더 복잡한 장면으로 확장 가능한지 불명
- surface normal 예측만 유독 dense-only 모델 대비 격차가 큼(24.2° vs 21.2°). "세밀한 지역 기하가 용량 공유에 민감하다"는 설명이 피상적
- 1단계 masked model(GenEval 0.64)에서 2단계 distribution matching으로 0.74까지 오르는데, 이 상승이 방법론 자체의 효과인지 단순 추가 학습량 때문인지 분리된 ablation 없음
- 제시된 생성 샘플이 선별적(cherry-picked)이라 실패 사례 비율을 가늠하기 어려움
