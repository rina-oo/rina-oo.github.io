# BirdDreams: Joint Perspective and BEV Video Generation for a Plausible, Reactive Driving World Model

> 원제: BirdDreams: Joint Perspective and BEV Video Generation for a Plausible, Reactive Driving World Model
> 리뷰: [블로그 전문](https://rina-oo.github.io/posts/2611.14815/)

## TL;DR
자율주행 월드 모델에서 주변 차량의 미래 레이아웃을 외부 입력(HD맵·3D box 궤적)으로 받는 대신, 1인칭 RGB 영상과 schematic BEV 영상을 하나의 dual-branch causal video diffusion transformer로 joint attention을 통해 동시에 생성하도록 설계. BEV를 보조 예측 타겟으로 두어 레이아웃 자체를 "예측되는 미래"의 일부로 만들고, BEV의 고정 미터 스케일·정사영 특성을 이용해 ego trajectory를 기하학적 reprojection으로 조건화(BEV-aware action conditioning)함으로써 궤적 추종 정확도와 반사실적 상황에서의 주변 차량 반응성을 동시에 개선. PhysicalAI-AV·nuScenes에서 기존 공개 모델·OmniDreams 변형 대비 궤적/영상 지표 대부분에서 최상위, 사람 평가(N=375)에서도 베이스라인 대비 선호도 우위(57% vs 24%).

## 핵심 기여
- OmniDreams 사전학습 백본을 두 개의 causal video diffusion transformer(perspective/BEV)로 분기시켜 Mixture-of-Transformers 구조로 joint attention 결합. attention projection은 공유, FFN·출력 헤드는 분리.
- Diffusion Forcing에 스트림별(persp/BEV) 독립 노이즈 샘플링을 추가. 한 스트림이 상대적으로 깨끗할 때 다른 스트림의 denoising을 돕는 학습 신호 생성 — ablation에서 FVD 489.9→439.4, FTD 1.144→1.018 개선 확인.
- BEV-aware action conditioning: 직전 BEV 프레임을 입력 ego trajectory의 상대 회전·이동으로 reprojection하여 soft condition으로 사용(Gen3C의 warped-render conditioning 아이디어를 depth 없이 평면 BEV 기하로 구현). 실제 정답 미래 BEV로 학습시켜 reprojection 자체가 정답이 아니라 힌트로 작동.
- Resampling Forcing으로 2단계 미세조정하여 자기회귀 롤아웃의 exposure bias(오차 누적) 완화.
- Flexible conditioning: 동일 모델로 초기 RGB 프레임, 초기 BEV 프레임, 전체 RGB 비디오 중 어떤 것을 조건으로 줘도 나머지 스트림/시점을 생성 가능 — BEV를 직접 편집해 시나리오를 커스터마이징하는 데 활용.

## 한계
- 코드·체크포인트 비공개(프로젝트 페이지만 존재, GitHub 링크 없음) — 재현 불가.
- 반사실적 시나리오 비교의 베이스라인(OmniDreams HDMap)이 독립된 제3의 모델이 아니라 자사 모델을 조건 제거해 만든 변형. 다른 계열 월드 모델과의 비교는 없음.
- 사람 평가 규모가 25명·375 쌍 비교로 작음. "적절한 반응 없음" 항목에서는 베이스라인과의 격차(19% vs 11%)가 다른 항목(불가능한 움직임 27%→9%, 부자연스러운 주행 24%→6%)보다 작아, 공간적 일관성은 개선됐지만 차량 간 실제 상호작용 추론 능력은 상대적으로 덜 개선된 것으로 보임.
- 학습에 H100 64장·약 670시간 주행 데이터 필요, 개인 재현 난이도 높음.
- 충돌로 끝나는 롤아웃을 "그럴듯한 결과"로 서술하나, 모델에 명시적 물리 제약이 없어 실제 안전성 검증에 쓰기엔 그럴듯함과 물리적 타당성을 구분할 장치가 추가로 필요해 보임(논문에 미언급).
- WAM(ego-trajectory prediction) 확장 실험은 저자 스스로 "preliminary"라 칭함, 100개 클립 규모로 확정적 결론은 이름.
