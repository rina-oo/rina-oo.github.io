# ComBodied Agents: a New Paradigm of Human-Centric Agentic AI

> 원제: ComBodied Agents: a New Paradigm of Human-Centric Agentic AI
> 리뷰: [블로그 전문](https://rina-oo.github.io/posts/2608.10915/)

## TL;DR
Digital Agent(디지털 상태 중심)와 Embodied Agent(물리적 상태 중심)에 이은 세 번째 축으로 Combodied Agent를 제안하는 포지션 페이퍼. 사람의 상태와 agency 자체를 모델링·개입·평가의 1차 대상으로 삼아야 한다고 주장하며, task 성공률만으로 평가하는 현재 에이전트 패러다임이 사용자의 이해도·자율성·역량 저하를 놓친다는 문제의식에서 출발한다. Personal World Model(PWM), perception-memory-prediction-intervention closed loop, cloud-to-edge 3단계 배포, agency preservation 평가지표를 하나의 프레임워크로 통합. 실험/구현 없이 프레임워크만 제시.

## 핵심 기여
- Digital/Embodied Agent와 구별되는 세 번째 action substrate로 Combodied Agent를 정의 (human-centric state modeling, longitudinality, intervention, co-agency, agency preservation 5속성)
- 사람 상태 사후분포 $Z_t \sim q_\phi(\cdot \mid D_{\leq t}, M_t, C_t)$ → PWM 예측 $p_\theta(Z,E,Y \mid \cdots)$ → ParetoArgmax 기반 개입 정책 선택 → 피드백으로 이어지는 closed-loop 수식화
- PWM을 user profile / longitudinal memory / personalized agent / generative agent와 명확히 구분: "행동 조건부 미래 궤적에 대한 보정된(calibrated) 분포"라는 검증 계약이 차별점
- 클라우드 중심 → 하이브리드(프라이버시 게이트웨이) → 엣지 네이티브로 이어지는 3단계 배포 아키텍처, 태스크별 라우팅 문제로 재정식화
- task 성공률 대신 agency preservation(autonomy, contestability, informed decision-making, capability growth, over-reliance risk, reversibility, boundary/consent, relationship preservation) 8개 지표를 non-compensatory 원칙과 함께 제안, CombodiedBench 스케치

## 한계
- 실험/구현이 전혀 없는 규범적 제안. PWM 학습 목표(예시로 제시된 손실함수)나 sparse personal data에서의 개인화 방법론은 구체화되지 않음
- agency preservation 지표(correction success rate, declining independent attempts 등)의 실제 측정 방법론 부재. over-reliance 측정은 "에이전트 없이 수행했을 때"라는 반사실적 비교를 요구하는데, 이는 논문이 causal PWM에서 스스로 경계했던 confounding 문제와 동일한 함정
- business-model misalignment를 지적하면서도 참여도 최적화가 기본값인 산업 구조에서 이 프레임워크가 실제로 채택될 유인/경로에 대한 논의는 얕음
- 3축 taxonomy(Figure 7)의 셀 배정(예: Family-Health는 Caregiver+Advocate)이 실제 배포 관찰에 근거한 것인지 저자들의 선험적 설계인지 불분명
