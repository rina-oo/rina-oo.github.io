# Look Only When Needed: Certificate-Guided Visual Routing for Efficient Diffusion VLMs

> 원제: Look Only When Needed: Certificate-Guided Visual Routing for Efficient Diffusion VLMs
> 리뷰: [블로그 전문](https://rina-oo.github.io/posts/2610.36671/)

## TL;DR
Diffusion VLM이 매 디코딩 스텝마다 이미지 토큰 전체를 다시 처리하는 비효율을 겨냥해, FULL forward와 TEXT-ONLY forward의 예측 일치 여부로 이미지 접근 여부와 언마스킹 개수를 동시에 결정하는 학습·임계값 없는 디코딩 기법 LOWN을 리뷰합니다. LLaDA-V 기준 10개 벤치마크에서 베이스라인 점수의 99.6%를 0.35배 FLOPs로 달성합니다.

## 핵심 기여
- LLaDA-V 디코딩 경로에서 FULL forward(이미지 포함)와 TEXT-ONLY forward(이미지 제외, position ID 유지)의 예측을 스텝마다 나란히 기록해, top-1 예측이 83.4% 일치하고 최종 토큰의 85.0%가 언마스킹 전에 이미 top-1로 떠 있었음을 측정. 이미지 의존도는 벤치마크별로 7.9~43.8%(평균 22.8%)로 편차가 커 고정 스케줄로는 포착 불가능함을 확인.
- 직전 FULL forward의 예측·확신도를 anchor로 저장하고, 매 스텝 TEXT-ONLY forward로 anchor를 검증(certificate)해 일치하면 재사용, 불일치하면 FULL forward를 재호출하는 LOWN 제안. 확신도 순 인증 접두사 길이가 이미지 접근 여부와 언마스킹 개수를 동시에 결정. 학습도 임계값 튜닝도 불필요.
- 비용 모델 $R = f + \sigma\rho$로 분석: TEXT-ONLY forward는 attention의 제곱 비용 항 덕분에 FULL forward 대비 3~10%밖에 안 들어, FULL 호출 빈도 $f$를 낮추는 것만으로 큰 폭의 FLOPs 절감.
- LLaDA-V(10개 벤치마크, 베이스라인 99.6% 점수를 0.353배 FLOPs로), LaViDa, VidLaDA-8B 세 backbone에서 검증. RedVTP·ZOO-Prune(visual token pruning), Fast-dLLM(KV 캐싱)과 직교적으로 결합 가능해 pruning FLOPs를 추가로 57.6~77.3% 절감, 캐싱과 결합 시 5.6~7.0배 wall-clock 가속.
- Ablation으로 FLOPs 절감의 대부분(27~68%)이 visual routing(이미지 접근 여부 결정) 자체에서 나오고, adaptive acceptance(한 번에 더 언마스킹)는 추가로 21~43%를 보탠다는 것을 분리해서 확인.

## 한계
- 이미지 의존도가 구조적으로 높은 chart/document 과제(DocVQA 등)에서는 절감 폭이 작음. 부록 사례 하나는 15스텝 중 14스텝이 FULL forward라 0.90배 FLOPs까지 상승 — 벤치마크 평균 0.45배 대비 입력별 비용 편차가 큼.
- 비용이 디코딩 완료 전까지 확정되지 않아 고정 예산이 필요한 서빙 환경에는 부적합할 수 있음. pruning과의 결합이 "부분적으로" 완화한다고만 언급되고 구체적 완화 폭은 미제시.
- anchor가 묵을수록 신뢰도 하락(1스텝: 4.1~11.0% 불일치, 8스텝: DocVQA 25.3%). 실제로는 92~97%가 1스텝 anchor만 쓰지만, 이는 설계상 불일치 시 즉시 갱신되기 때문이며 더 긴 응답·늦게 발생하는 이미지 의존 상황에서도 유지될지는 미검증.
- 경쟁 기법(RedVTP, ZOO-Prune, KLASS) 비교가 10% 단위 이산 그리드에서 "LOWN 이상 FLOPs의 최저 설정"을 고르는 방식이라, 더 촘촘한 그리드에서도 같은 경향이 유지되는지는 불확실.
- 모든 평가가 greedy decoding 기준. 샘플링 temperature를 높인 환경에서 top-1 일치 기반 certificate가 과신하게 될 가능성은 논문에서 다뤄지지 않음.
