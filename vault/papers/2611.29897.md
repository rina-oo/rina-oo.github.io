# Motion Mamba 2.0: Autoregressive Diffusion Mamba for Long-Horizon Humanoid Control

> 원제: Motion Mamba 2.0: Autoregressive Diffusion Mamba for Long-Horizon Humanoid Control
> 리뷰: [블로그 전문](https://rina-oo.github.io/posts/2611.29897/)

## TL;DR
ECCV'24 Motion Mamba의 후속작. Root-body 2단계 autoregressive diffusion에 Mamba-3 recurrent state와 Persistent Content Memory(PCM)를 결합해, bounded attention cache가 잃어버리는 장거리 맥락을 고정 크기 recurrent 압축 → attention 가독 slot으로 변환하는 인터페이스를 제공한다. Retargeted HiPHI 39.52초(19윈도우) 롤아웃에서 Root CE 7.55cm로 최저 오차를 달성했고, CUDA Graph·커널 퓨전·실행 흐름 단순화로 RTX 4090 윈도우당 추론을 1685ms→276ms(6.138배)로 줄이면서 출력 비트 동일성을 유지했다. Unitree G1 실로봇 100회 시도에서 낙상 0회, 94회 완전 성공.

## 핵심 기여
- Root(전역 궤적)-Body(전신 자세) 2단계 diffusion denoiser. 매 디노이징 스텝마다 root 예측이 먼저 갱신되고 그 로컬 특징이 body 입력으로 즉시 전달되는 방식으로 결합(ARDY의 root-body 분해 계승).
- Mamba-3 resumable recurrence 채택. 채널별 회전(위상 누적 $\phi_i=\phi_{i-1}+\pi\Delta_i\tanh\theta_i$)과 인접 두 시점의 trapezoidal 가중 결합으로 상태를 갱신. 상태 크기는 시퀀스 길이와 무관하게 고정.
- Persistent Content Memory(PCM): 받아들여진 Mamba recurrent matrix를 풀링한 state summary $\bar s_t$와 직전 윈도우 대비 차이 $d_t$, 텍스트 조건을 합쳐 후보 콘텐츠를 만들고, 쓰기 비율 상한 $\eta=0.25$인 게이트로 slot을 점진 갱신. attention이 sink/sliding-cache 외에 이 slot까지 읽음.
- 읽기 쪽 안전장치: PCM 기여 스칼라 $\rho_\ell$을 0으로 초기화하면 slot이 있어도 PCM 적용 전과 출력이 정확히 동일(slot 값 자체를 0으로 초기화하는 것과는 다름, attention 정규화가 slot 유무에 따라 달라지기 때문).
- Diffusion sampling과 history commit의 분리: 디노이징 중간 후보는 읽기 전용 스냅샷만 참조하고, clean window가 accept된 뒤에만 cache·Mamba state·PCM slot이 원자적으로 커밋됨.
- 추론 가속은 모델 가중치를 바꾸지 않는 실행 레벨 최적화(실행 흐름 단순화 + Mamba A/DT 전처리 커널 퓨전 + stack-level CUDA Graph replay)로 분리 측정. CUDA Graph 단독 기여가 가장 커서(host launch 83,777→5,519회), "커널 퓨전보다 호스트 dispatch 오버헤드 제거가 지배적"이라는 결론.

## 한계
- 저자 인정 한계: object manipulation 미지원(로코모션/동작 생성에 국한, whole-body loco-manipulation은 future work).
- Mamba-3의 trapezoidal recurrence가 어떤 수학적 이점을 주는지 명시적 설명 없이 "경험적으로 평가된다"고만 서술 — 설명이 아쉬움.
- PCM 쓰기 비율 상한 $\eta=0.25$의 민감도 분석(다른 값과의 ablation) 부재.
- 모든 베이스라인이 원래 사전학습 체크포인트가 아니라 동일 G1 데이터·100,000-update 예산으로 재학습됨 — 공정 비교를 위한 선택이지만 원 설계 조건에서의 격차와는 다를 수 있음.
- 추론 가속(276ms)과 실제 명령-반응 지연(handoff/physical-response latency, 246~360ms)은 서로 다른 측정 조건이라 혼동 주의 — 논문도 명시적으로 구분.
- 장거리 목표 비교(ARDY 대비 Fig.9)는 단일 정성적 사례이며 통계적 일반화 증거로 제시되지 않음.
