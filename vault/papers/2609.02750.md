# 리플렉션에는 왜 심판이 필요한가 — Bilevel Coordinated Reflection: A Game-Theoretic Approach to Multi-Agent LLM Systems

> 원제: 리플렉션에는 왜 심판이 필요한가 — Bilevel Coordinated Reflection: A Game-Theoretic Approach to Multi-Agent LLM Systems
> 리뷰: [블로그 전문](https://rina-oo.github.io/posts/2609.02750/)

## TL;DR
오케스트레이터-워커 멀티에이전트 LLM 협업을 bilevel coordination game으로, 텍스트 메모리 갱신(reflection)을 확률과정 drift로 정식화한다. 디컴포지션 품질(coupling κ, d_max)이 워커 서브게임의 근사 내시균형 slack을 결정한다는 걸 증명하고, free-form reflection이 상황에 따라 수렴하거나 양의 오차 바닥에 갇힌다는 걸 상하한으로 조인다. 핵심은 텍스트만 보는 self-contained gate가 텍스트-동일·의미-반대인 두 환경을 원리적으로 구별 못 해 동시에 개선할 수 없다는 impossibility theorem이고, 이를 근거로 verifier risk가 실제로 감소할 때만 커밋하는 SRMA(Stochastic Reflective Memory Ascent)를 제안해 기하/다항 수렴을 증명한다. SWE-bench에서 게이팅 없는 멀티에이전트(58.4%)가 단일 에이전트(70.8%)보다 낮고 SRMA(72.2%)가 이를 회복하는 결과로 이론을 뒷받침한다.

## 핵심 기여
- 워커 디컴포지션을 약결합 게임으로 모델링: coupling 상한 κ와 최대 이웃 수 d_max로 근사 포텐셜 게임 slack η_c ≤ 2 d_max κ를 도출, 오케스트레이터의 디컴포지션 품질과 워커 균형 품질을 직접 연결
- free-form reflection의 두 얼굴: one-sided drift로 유한시간 상한과 최악-타이트성을 증명하고, persistent harmful commitment 조건 하에서는 별도로 양의 하한(오차 바닥)을 증명 — 상한만으로는 수렴을 보장 못 함을 명시
- self-contained gate의 불가능성 정리: 텍스트 생성 법칙은 동일하지만 의미가 반대인 두 환경을 구성해, 텍스트만 보는 어떤 게이트(이상적 LLM judge 포함)도 두 환경을 동시에 개선할 수 없음을 증명 — 판사의 능력과 무관한 정보이론적 한계
- SRMA: verifier risk가 엄격히 감소할 때만 메모리 갱신을 커밋하는 알고리즘. calibration + non-degenerate corrective mass 하에서 기하(β=0)/다항(β>0) 수렴을 증명하고 두 rate 모두 order-tight함을 보임. 확률적 verifier용 confidence gating, 환경 변화 대응용 re-anchoring 확장 포함
- Resource Contest·Overcooked·SWE-bench 세 환경에서 이론이 예측한 "no-memory < free-form < self-gate < grounded SRMA" 순서를 확인, SWE-bench에서는 게이팅 없는 멀티에이전트가 단일 에이전트보다 저조하다는 반직관적 결과로 grounding의 필요성을 입증

## 한계
- verifier calibration(V_i(m) ≤ L R_i(m))과 non-degenerate corrective mass 가정은 정확한 오라클/BFS 검증기가 있는 이상화된 환경(RC, Overcooked)에서만 검증됨; 불완전한 테스트 스위트에서는 verifier risk의 단조 감소만 보장되지 실제 task utility의 개선은 보장 안 됨 — SWE-bench처럼 테스트가 불완전한 real-world 세팅에서 리스크가 더 커질 수 있음
- SWE-bench의 핵심 비교(72.2% vs 70.8%)가 저자들이 인정하듯 통제된 ablation이 아니라 외부 공개 리더보드 값과의 비교; 같은 조건에서 단일 에이전트와 Bilevel SRMA를 직접 비교한 통제된 행이 없어 "이중 레벨 구조 자체의 이득"과 "게이팅의 이득"이 완전히 분리되지 않음
- bounded coupling, 유한 행동 집합 등 핵심 가정이 열린 형태(open-ended)의 실제 에이전트 태스크에서 성립하는지, κ·d_max·β 같은 양을 실제 배포 환경에서 어떻게 추정할지는 논문에 구체적으로 제시되지 않음
- drift 파라미터들의 검증이 관측된 궤적 범위 내에서만 이루어짐; re-anchoring도 구간별(per-segment) 수렴만 보장하고 일반적인 switching-regret 보장은 없음
