# WeVisForensics: Self-Evolving Agent for Omni AI-Generated Video Detection

> 원제: WeVisForensics: Self-Evolving Agent for Omni AI-Generated Video Detection
> 리뷰: [블로그 전문](https://rina-oo.github.io/posts/2611.21373/)

## TL;DR
AI 생성 영상 탐지를 2단 에이전트(investigator + 6종 inspector)로 재구성. 기존 에이전트형 탐지기는 라우터(투자관)만 학습하고 하위 전문가(감식관)는 고정했는데, 이 논문은 DTPO(Dual-Timescale Policy Optimization)로 투자관은 매 배치(fast, GRPO+CLUE), 감식관은 H=20스텝마다(slow, EMA 증류+skill card)를 동시에 학습시켜 서로를 위한 커리큘럼이 되게 만듦. ForenCue-30K(역할별 증거 3만 영상)와 AgenticCue(정답뿐 아니라 invocation precision까지 평가) 벤치마크를 신규 구축. in/out-domain·agentic 평균 95.2%로 최강 기존 탐지기 대비 +9.0%p.

## 핵심 기여
- 투자관(무엇을·어디를 볼지 계획)과 감식관(appearance/physical/common sense/OCR 4종 trainable + voice/ASR 2종 fixed, 해당 역할의 유무만 판단)을 역할 분리한 2단 agentic 구조.
- CLUE: 투자관·감식관과 독립된 reference 모델이 호출 전/후 정답 로그확률 변화를 측정하는 call-level 신용 할당 신호. 결과(0/1) 보상만으로는 어느 조사가 기여했는지 알 수 없다는 문제를 해결.
- 감식관 자가진화: 투자관이 실제로 호출하고 annotated artifact 구간과 겹치는(grounded) call만 모아 EMA teacher(특권 정보 포함)→student 증류, 모노톤 수용 테스트를 통과한 Report/Ignore 규칙만 skill card에 반영.
- Ablation(Table 6)으로 "라우팅만 학습(frozen FSL)"은 in-domain만 오르고 OOD(MintVid)는 거의 안 오르는 반면, 감식관 자체를 진화시켜야 unseen generator 일반화가 따라온다는 것을 수치로 분리 입증. Table 9에서 투자관·감식관 동시 개선이 단순 합보다 +1.3%p 더 오르는 초가산 효과도 확인.
- OCR 감식관: PaddleOCR 후보 검출 → 텍스트 존재 여부 라우팅 → crop 단위 glyph 판정의 3단 파이프라인, "최소 하나의 crop이 실제 생성형 손상을 보여야" 위조 판정이 유지되는 게이트로 오탐 억제.

## 한계
- AgenticCue의 Visual(외형) 카테고리에서는 BusterX++(87.3)에 밀림(85.6) — 다른 범주에서 압도적이라 묻히지만 원인 분석 없음.
- Qwen3.5-397B가 Qwen3.5-4B보다 거의 전 영역에서 낮은 역설적 결과가 있는데 논문은 이를 논의하지 않음.
- 투자관+4개 감식관이 전부 같은 Qwen3.5-4B 백본 위 LoRA 어댑터만 다름 — 서빙 효율은 좋지만 감식관들의 표현력 상한이 결국 하나의 백본에 묶임. 다른/더 큰 백본과의 비교 없음.
- 오디오 도구(PaddleOCR/ASR/voice profile)는 의도적으로 고정 — 설계상 합리적이나 이 고정 도구들의 실패 사례 분석은 없음.
- 투자관 SFT 데이터(agentic trajectory)가 VLM 플래너가 생성한 합성 궤적이라 결국 다른 VLM의 조사 전략을 모방하는 구조. 품질 검증이 100개 trajectory 샘플(96.0% 적절) 기반이라 33,896개 전체를 담보하기엔 표본이 작음.
