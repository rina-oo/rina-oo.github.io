# 말하는 도중 옷 색깔을 바꿔달라고 하면 — 실시간 영상 생성 모델 37개의 동시다발 실패 (StreamEval: Evaluating Interactive Streaming Video Generation Models)

> 원제: 말하는 도중 옷 색깔을 바꿔달라고 하면 — 실시간 영상 생성 모델 37개의 동시다발 실패 (StreamEval: Evaluating Interactive Streaming Video Generation Models)
> 리뷰: [블로그 전문](https://rina-oo.github.io/posts/2610.28402/)

## TL;DR
StreamEval은 디지털 휴먼 대화, 아바타 퍼포먼스, 월드 생성, 지시어 편집, 레퍼런스 편집 다섯 과제를 하나의 틀로 묶은 실시간 스트리밍 비디오 생성 벤치마크다. 300개 스크립트화 세션(15~300초)에 시간차를 둔 멀티모달 입력과 "무엇을 바꾸고 무엇을 보존해야 하는가"를 명시한 오라클을 부여하고, 과제 수행·상태 일관성·시각 품질·오디오-비디오 동기화 4축 10개 지표로 채점한다. 37개 모델 47개 과제 구성을 평가한 결과, Quality·Identity 같은 외형 지표는 높아도 Following/Edit Success 같은 "요청을 실제로 실행했는가" 지표는 전 영역에서 낮다(레퍼런스 편집 최고 Edit Success 15.00/100). 외형 품질과 지시 실행이 별개의 축이라는 걸 체계적으로 입증한 벤치마크 논문이다.

## 핵심 기여
- 아바타 상호작용·월드 생성·실시간 비디오 편집을 하나의 평가 프로토콜로 통합, 세션 도중 도착하는 입력에 대해 실행 시점·범위·보존 요구사항을 명시적 오라클로 정의
- Qwen3.8-Max 기반 모델 보조 저작 + 모달리티별 자동 스크리닝(ASR WER≤0.25, VLM 결함 심사)으로 벤치마크 제작, judge 자체를 위양성 5%/위음성 10% 기준으로 사전 보정
- Following(요청 인식)과 Edit Success(완전한 이행)를 분리한 지표 설계로 "지시를 알아들었지만 끝까지 수행하지 못함"을 구분해 포착
- 37개 모델 비교에서 Quality/Stability와 Following/Continuity 간 상관관계가 거의 없음을 다섯 과제 전역에서 일관되게 관측 (예: HappyOyster 1.0 Adventure는 Quality 1위, Following/Continuity는 최하위권)
- 레퍼런스 편집에서 레퍼런스 전환 이벤트에 대한 실제 반응 실패 사례를 프레임 단위로 시각화해 "소스 보존은 되지만 지시 반영은 안 된다"는 실패 모드를 구체적으로 제시

## 한계
저자가 인정한 한계는 편집 과제가 아직 레퍼런스 전환·다중 타깃 보존·소스 복원 수준에 머물러 있고 전역 리셋이나 동시 편집 중 선택적 복원 같은 시나리오는 다루지 않는다는 점, 그리고 포트레이트/신원이 합성 성인·가상 캐릭터로 제한되어 있다는 점이다. 리뷰어로서 추가로 짚을 부분은 세 가지다. 첫째, 전체 채점이 Qwen 계열 VLM judge에 의존하는데 judge-모델 계열 간 편향 가능성에 대한 검증이 없다. 둘째, Overall 산출 시 Quality/Stability와 Following/Edit Success를 균등 가중치로 평균하는 설계가 "요청 실행"의 실무적 중요도를 과소평가할 수 있는데 이에 대한 근거 제시가 없다. 셋째, 사람 평가와의 상관관계가 아직 공개되지 않아 현재 리더보드를 judge 신뢰도 이상으로 받아들이기엔 이르다.
