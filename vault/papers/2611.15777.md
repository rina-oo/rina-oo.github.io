# 잘 맞히는 것과 믿을 수 있는 것은 다르다 — SO-Arena: System One 모델의 능력과 신뢰성을 나눠서 재다

> 원제: 잘 맞히는 것과 믿을 수 있는 것은 다르다 — SO-Arena: System One 모델의 능력과 신뢰성을 나눠서 재다
> 리뷰: [블로그 전문](https://rina-oo.github.io/posts/2611.15777/)

## TL;DR
System One(추론 토큰 없이 한 번의 forward pass로 바로 결정하는) 모델 21종을 11개 도메인·2,919개 과제로 평가하는 벤치마크 SO-Arena. 정확도 기반 능력 점수(C)와는 별도로 옵션 순서 안정성(S)·정답없음 인식(N)을 묶은 신뢰성 점수(R)를 도입해, 능력과 신뢰성이 서로 다른 축임을 보인다. 능력 1위 모델(GLiDE, 70.2점)이 신뢰성에서는 7위로 밀리고, 능력 11위 JevAny-27B가 신뢰성 1위를 차지한다.

## 핵심 기여
- 40개 공개 데이터셋·환경에서 수집/파생한 2,919개 과제를 11개 도메인·5개 능력군(의미 이해, 지식·추론, 안전·정책, 증거 평가, 에이전트 과제 수행)으로 구성. 참조 라벨을 모델이 보는 입력과 대조해 수동 검증.
- 9개 도메인에 도메인별 난이도 계층(easy/medium/hard, Math는 very hard 추가)을 둬서 평균 정확도로는 안 보이는 모델 간 변별력 확보. 능력 점수 C는 도메인별 최고 난이도 구간만 평균, 도메인 가중치는 균등.
- 정적 판단(2,300개)과 환경 기반 과제(619개: 웹 단일/다단계, 툴 사용 인터랙티브 에피소드)를 하나의 결정 인터페이스(choice/noul/score)로 통합.
- 신뢰성을 능력과 분리된 축으로 정의: 옵션 12가지 재배열에도 같은 답을 유지하는 정도(S, chance-corrected), 정답 선택지를 제거했을 때 "정답 없음"을 알아채는 AUC 기반 지표(N). 둘 다 양수일 때만 기하평균(R)으로 결합 — 한쪽이 0이면 전체도 0.
- 21개 모델(0.4B~31B 오픈소스, 자동 System1/2 전환 모델, 비공개 결정 API 2종, GPT-6 Sol/Luna 참조) 평가로 도메인을 세 범주(직접 의미 판단/세밀한 근거기반 결정/다단계 유도)로 구분: 백본 확장은 둘째 범주에서, 추론(thinking)은 셋째 범주(특히 수학)에서 효과가 크고 첫째 범주에서는 둘 다 거의 무의미.

## 한계
- 안전성 분류 과제에서 모델이 아예 답을 거부(refusal)하면 0점 처리됨 — 안전 정렬이 잘 된 모델일수록 중립적인 하위 과제(분류)에서도 거부해 불이익을 받을 수 있는데, 거부율을 능력 점수와 분리해서 별도로 집계하지 않음.
- Math 영역을 객관식으로 변환할 때 오답 선택지를 "베이스 모델의 오답"으로 구성했다고만 명시, 어떤 모델인지·오답 패턴이 평가 대상과 얼마나 겹치는지 불명시 — 선택지가 쉽게 배제되는 구조라면 수학 점수가 부풀려질 위험.
- 비교 모델 다수가 생소한 회사(Fastino, PelaAI, Sthanika AI, StartLux, TypeSafe 등)의 제품이라 학습 레시피 검증 불가. "문서화된 추론 경로"를 그대로 따르는 평가 방식이라 서빙 스택 최적화 정도 차이가 지연시간 비교(Fig.3)에 섞여 있을 수 있음.
- 난이도 티어가 "도메인 간에 보정되지 않음"을 저자도 인정 — 벤치마크 내 상대 순위는 유효하나 절대 점수의 도메인 간/타 벤치마크 간 비교는 주의 필요.
