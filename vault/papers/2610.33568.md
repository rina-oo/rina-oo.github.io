# Trajectory2Gym: Decision-Grounded Compositional Interaction Synthesis for Tool-Use Agents

> 원제: Trajectory2Gym: Decision-Grounded Compositional Interaction Synthesis for Tool-Use Agents
> 리뷰: [블로그 전문](https://rina-oo.github.io/posts/2610.33568/)

## TL;DR
Westlake University와 Ant International 연구진이 tool-use 에이전트 SFT 데이터로 흔히 쓰는 "성공한 trajectory"가 좋은 교재가 아닐 수 있다는 문제를 지적한다. task 완료나 호출 실행 성공만으로 trajectory를 거르면, 다단계 의존 관계가 충분히 대표되지 않거나(compositional coverage 부족) 수집자만 아는 정보로 정당화된 행동이 학습 대상에 섞인다(decision grounding 부재). 이 두 조건을 분리해 정식화하고, 부족한 구조를 직접 합성한 뒤 결정 단위로 grounding을 검증하고 스케일별로 반복 노출을 할당하는 3단계 파이프라인 Trajectory2Gym을 제안한다. Qwen3 1.7B~30B-A3B 다섯 스케일 전부에서 일반 SFT만으로 Tau1+Tau2 평균 +20.0~+40.9점, BFCL Overall +3.4~+11.9점을 올리며, 8B 모델은 재평가한 RL 기반 32B 체크포인트까지 세 벤치마크 평균에서 앞선다.

## 핵심 기여
- decision context $c_t=(x,\mathcal T_t,V(H_{<t}))$를 명시적으로 정의해, 수집 시점에만 보였던 정보와 학생이 실제로 볼 수 있는 정보를 분리. 실행 유효성 $e_t$와 결정 시점 grounding $v_t$를 곱한 local eligibility $g_t=e_tv_t$, 여기에 trajectory 성공과 워크플로 순서 제약을 더한 최종 mask $m_t=R_\tau\mathbf 1[q_\tau\preceq A_\tau]g_t$로 "어떤 결정을 학습 대상으로 삼을지"를 형식화.
- compositional interaction synthesis: capability vocabulary 기반 경로(path) 중 support가 부족한 것을 타깃으로 teacher가 네이티브 환경에서 직접 실행해 합성. 실행 로그에 의존 관계가 실제로 나타나야만 "certified" 처리되어 이후 합성 라운드의 기준이 됨.
- structural-support learning: 스케일별 목표 반복 깊이 $d_s$(1,2,3,4,8)로 과소 대표된 경로에 반복 지원을 할당. 단, depth를 늘린다고 성능이 단조 증가하지 않음을 민감도 실험으로 직접 보임(8B에서 depth 2일 때 평균 72.28점으로 최고, depth 4는 69.44점).
- parent-normalized SFT: 하나의 trajectory가 여러 렌더링 예시로 쪼개져도 trajectory(parent) 단위로 동일 가중치를 주도록 loss를 재정규화. 렌더링 예시 단위 평균 대비 매칭 ablation에서 가장 큰 단일 개선폭(+8.04점, 주로 Tau2 52.50→74.17)을 만들어냄.
- 다섯 스케일(1.7B~30B-A3B) 전부에서 Tau1/Tau2/BFCL 동시 개선을 매칭 비교로 검증. 4B 후학습 모델이 Tau2에서 28.33점짜리 public 30B-A3B 초기화보다 69.17점으로 더 높은 성능을 내 데이터 구성이 모델 크기보다 크게 작용할 수 있음을 보임.

## 한계
- 비교 대상(재평가 RL 체크포인트, closed-source 모델)이 matched comparison이 아님. 학습 데이터·모델 패밀리·context 예산이 달라 "Trajectory2Gym이 RL보다 우월하다"는 식의 방법론 간 직접 귀속은 저자들 스스로도 경계함.
- BFCL Live Simple 카테고리가 4/5 스케일에서 6~13점 하락. "즉시 단일 호출로 끝나는 질의에서 정보 수집 쪽으로 편향된 것 같다"는 가설만 제시되고 원인 분석이나 구체 사례 없이 넘어감.
- grounding 판정이 capability vocabulary·도구 접근 등급(read/write/irreversible-write/handoff) 같은 수작업 규칙 기반. 식별자와 스키마가 명확한 고객지원·여행·통신 도메인에는 잘 맞지만, 웹·소프트웨어·터미널 에이전트처럼 구조가 느슨한 환경으로의 확장은 논문도 향후 과제로 남김.
- ablation 각 arm이 단일 실행(single run)이고 Tau2 Airline이 20개 task뿐이라 "task 하나가 평균을 0.56점 움직인다"고 저자들이 직접 명시. +2~3점대 ablation 수치는 추세 확인 수준이지 통계적으로 엄밀하지 않음.
- depth 민감도 실험은 depth와 데이터 총량이 동시에 변해 "반복 자체의 악영향"과 "특정 구간의 과적합"을 분리하지 못함. 저자들도 "sensitivity test이지 체크포인트 선택은 아니다"로 선을 그음.
