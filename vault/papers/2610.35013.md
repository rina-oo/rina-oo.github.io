# 가치함수는 토큰이 아니라 턴 단위로 움직인다 — Multiscale Policy Optimization for Long-Horizon LLM Agents

> 원제: 가치함수는 토큰이 아니라 턴 단위로 움직인다 — Multiscale Policy Optimization for Long-Horizon LLM Agents
> 리뷰: [블로그 전문](https://rina-oo.github.io/posts/2610.35013/)

## TL;DR
2,048개 trajectory·16,323개 턴 분석에서 critic 값이 턴 경계에서 대부분 변하고(턴 간 분산이 median 89.5% 차지, 93.8% trajectory에서 턴 간 변동이 턴 내부보다 큼) 턴 내부에서는 평평하다는 사실을 확인. 이를 근거로 턴을 매크로 행동으로 보는 정책개선 이론을 세우고(토큰 단위 surrogate가 턴 단위 대비 within-turn distribution-shift penalty를 추가로 지불한다는 bound 포함), 턴 단위 GAE로 장거리 credit을 전파한 뒤 턴 평균을 보존하며 토큰별로 centered local correction을 더하는 MAE와, forward pass는 턴 전체 중요도비로 클리핑하되 backward pass는 stop-gradient로 토큰별 gradient를 보존하는 turn-level importance correction을 결합한 MPO 제안. Qwen3-4B-Thinking·30B-A3B-Instruct 두 스케일, BrowseComp-Plus/GAIA/HLE/Claw-Eval/Automation Bench 9개 지표 전부에서 GRPO/GSPO/PPO/VAPO/SAO 대비 최고 점수.

## 핵심 기여
- 턴 단위 TD residual을 턴 안에서 합산하면 내부 critic 예측이 전부 상쇄되고 경계값만 남는다는 항등식(δ_t^turn)으로, 턴 단위 GAE가 턴 길이와 무관하게 credit을 전파함을 보임.
- MAE: A_{t,i}^MAE = A_t^turn + β(A_{t,i}^intra − 평균intra). 제약 있는 최소제곱 투영의 닫힌 해로, 턴 평균은 A_t^turn에 고정하고 토큰 간 상대적 차이만 local trace 모양대로 재배치.
- turn-level importance correction: ρ̃_{t,i} = ρ_{t,i}·sg[∏_{j≠i}ρ_{t,j}]. forward 값은 턴 전체 비율 ρ_t와 같아 클리핑이 턴 스케일에서 작동하지만, backward gradient는 ρ_t(θ)·∇log π(a_{t,i}|h_{t,i})만 남아 토큰별 credit이 보존됨.
- 이론: 턴 단위 policy improvement bound(Theorem 1)와, 토큰 단위 surrogate로 바꿀 때 추가되는 within-turn distribution-shift penalty(Theorem 2, L_max(L_max−1)에 비례)를 유도.
- ablation으로 턴 간 전파(λ)와 턴 내부 trace(λ_intra)에 서로 다른 최적값(0.80 vs 0.95)이 필요함을 확인 — 한 trajectory의 턴 수가 토큰 수보다 훨씬 적어 같은 감쇠율이 다른 유효 범위를 가지기 때문. β=0(턴 평균만 broadcasting)도 PPO보다 우세해 턴 단위 전파 자체의 기여를 분리 확인.

## 한계
- 동기 부여 통계(턴 간 분산 89.5%, 93.8%)가 단일 MPO 4B 검색 에이전트 run에서만 수집됨. 다른 시드·다른 도메인(Claw-Eval, Automation Bench)에서 같은 패턴이 성립하는지는 미확인.
- 모든 ablation이 single run(seed 1개)이라 λ/λ_intra/β 표의 0.1~2점대 차이의 통계적 안정성을 판단할 수 없음.
- Claw-Eval·Automation Bench는 둘 다 2026년 제안된 신규 벤치마크로, 외부 커뮤니티 검증이 아직 부족함.
- 이론적 bound(Theorem 1, 2)는 worst-case 상한이라 실제 학습에서 얼마나 타이트한지 정량 확인이 없음 — 정성적 동기 부여로만 기능.
- 공개 코드 저장소를 확인하지 못함(GitHub 링크 없음), stop-gradient trick 등 구현 세부사항 재현 어려움.
