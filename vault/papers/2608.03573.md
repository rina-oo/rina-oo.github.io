# SFT는 싸우고 RL은 공존한다 — 멀티태스크 후처리 학습의 기울기 기하학

> 원제: SFT는 싸우고 RL은 공존한다 — 멀티태스크 후처리 학습의 기울기 기하학
> 리뷰: [블로그 전문](https://rina-oo.github.io/posts/2608.03573/)

## TL;DR
Multi-stage 멀티태스크 학습에서 SFT는 태스크 간 충돌로 성능이 붕괴하지만(base 대비 -23.1%), RL(GRPO)은 안정적으로 누적 개선된다(+24.9%). 저자들은 이를 파라미터 업데이트 $\Delta W$ 수준에서 실증한다: RL 업데이트는 SFT보다 두 자릿수 이상 작고 sparse하며(20% vs 93% 파라미터가 유의미하게 변화), 태스크 간 코사인 유사도가 거의 0(orthogonal)이다. GRPO의 group-normalized advantage가 zero-sum 성질을 갖는다는 점을 이용해, SFT의 태스크 간 간섭은 gradient의 절대 크기(norm)에, RL의 간섭은 rollout 그룹 내 분산(variance)에 상한이 걸린다는 걸 증명한다. 이 통찰을 실용화한 Parallel-RL은 태스크별로 독립적으로 RL을 학습한 뒤 업데이트를 단순히 더하기만 해도 single-task 성능의 93~95%를 보존하고, 5%만 post-merge adaptation을 하면 102~103%까지 올라간다.

## 핵심 기여
- Multi-stage SFT는 태스크 충돌로 붕괴(-23.1%)하지만 multi-stage RL은 누적 성장(+24.9%)한다는 현상을 실증 — "SFT Conflicts, RL Coexists"
- 단일 태스크 학습이 다른 태스크에 미치는 영향을 비교: SFT는 목표 태스크 +4.0% / 타 태스크 -5.1%, RL은 목표 +6.8% / 타 태스크도 +2.3%
- 파라미터 업데이트 $\Delta W$의 L2 norm과 태스크 간 코사인 유사도를 직접 측정: RL은 SFT 대비 norm이 두 자릿수 작고(0.02~0.09 vs 6.5~8.9), 코사인 유사도도 $10^{-5}$ 대 $10^{-1}$로 차이
- GRPO의 advantage zero-sum 성질($\sum_k \hat A_{i,k}=0$)로 gradient 내적을 분해해, 그룹 평균 성분이 advantage 가중합에서 소거되고 잔차(residual) 성분만 남는다는 걸 증명
- 상한 정리: SFT 간섭은 norm-limited($M_i \cdot M_j$), RL 간섭은 variance-limited($V_i \cdot V_j$, rollout 그룹 내 분산)
- Parallel-RL 제안: 태스크별 독립 RL 학습 → $\Delta W_i$ 단순 합산(또는 TIES/SVD/소량 재학습)으로 병합. Naive sum만으로 93~95% 성능 보존, Adapted(5% 재학습)는 102~103%까지 상회
- Ablation: 특정 태스크의 $\Delta W_i$를 제거하면 해당 태스크만 하락(-7.1%)하고 나머지는 오히려 소폭 개선(+0.6%) — 태스크별 업데이트가 독립적 모듈처럼 작동함을 시사

## 한계
- Orthogonality가 모든 태스크 쌍에서 성립하지 않음: SynLogic(퍼즐/게임 로직) 태스크는 Math·Code와 score function 분포가 겹쳐, 병렬 학습 시 각 태스크 단독 성능보다도 낮아지는 반례가 부록에 있음(예: Math+Game 병합 후 SynLogic 점수가 base model보다도 낮음)
- 태스크 호환성 판별이 t-SNE 시각화 같은 정성적 휴리스틱에 머물러 있고, 정량적 판별 기준은 제시되지 않음
- 이론 전개(zero-sum 소거)가 GRPO의 group-normalized advantage 구조에 특화되어 있어, PPO나 다른 정규화 방식(GSPO 등)에도 동일하게 성립하는지는 미검증(부록에서 "대부분의 성질이 다른 RL 알고리즘에도 성립한다"고만 언급)
- 실험이 4개의 명확히 구분되는 reasoning 태스크(수학/과학/논리/코드)에 국한되어, 미묘하게 겹치는 태스크(예: 같은 도메인의 난이도 차이)에서의 일반화는 확인되지 않음
