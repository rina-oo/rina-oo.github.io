# 끝나지 않는 세계, 유한한 메모리로 — Alaya-EVOKE: From Linear-Scaling Supervision to Endless World

> 원제: 끝나지 않는 세계, 유한한 메모리로 — Alaya-EVOKE: From Linear-Scaling Supervision to Endless World
> 리뷰: [블로그 전문](https://rina-oo.github.io/posts/2608.13546/)

## TL;DR
인터랙티브 세계 모델은 지속적 기억, 응답 지연시간, 장기 생성을 동시에 요구하는데 이 셋이 서로 상충한다. Evoke는 장면 기하를 denoiser 컨텍스트가 아니라 카메라 pose로 색인된 외부 world state bank에 저장해 매 스텝 컨텍스트를 고정시키고, distillation teacher 자체를 chunk-wise sparse attention과 chunk별 텍스트 조건으로 재설계해 긴 호라이즌 supervision(약 30초)이 가능하게 만든 뒤 3-step CFG-free student에 전달한다. WBench에서 few-step 시스템 중 다수 그룹 1위, VBench-2.0 1위를 기록했고 H200 한 장에서 1.5초 청크를 2.11초에 생성하며 2시간 연속 롤아웃을 보였다.

## 핵심 기여
- 세션을 $r_k=\mathrm{Read}(M_k,\mathcal P_k),\ x_k\sim p_\theta(\cdot\mid r_k,h_k,c_k),\ M_{k+1}=\mathrm{Write}(M_k,x_k,\mathcal P_k)$ 형태의 고정 크기 반복 호출로 공식화 — 세션 길이가 늘어도 개별 호출의 컨텍스트·positional span은 불변
- degradation drift(국지적으로 보임)와 content drift(넓은 윈도우에서만 보임)를 구분하고, supervision window $W$가 학습 가능한 드리프트 종류 자체를 결정한다는 논리로 30초 长 teacher horizon을 정당화
- teacher에 chunk-wise sparse attention(sink+로컬+압축 근접+선택된 원거리+linear-attention 전역 상태) 도입해 attention을 시퀀스 길이에 선형으로 만들고, 같은 chunk 구조로 chunk별 텍스트 조건화(evocation)까지 확보
- self-forced rollout 189프레임(31.4초) 전체를 teacher/critic이 채점하되 청크 간 history를 detach해 backward graph는 청크 단위로만 유지 — supervision horizon과 gradient horizon을 분리
- monocular depth로 청크별 독립 unprojection → point cloud 저장, 현재 pose 기준 co-visibility 상위 8뷰를 z-buffer 렌더링해 warp 관측값+visibility mask로 읽는 world state bank(90초 보관, 유한 recall)

## 한계
저자가 인정: 현재 world state bank는 정적 기하만 저장해 물체 움직임·상태 전이 같은 동적 세계 상태를 다루지 못함. 리뷰어 지적: (1) 긴 teacher horizon의 효과 메커니즘이 "윈도우 길이 자체는 아니다"까지만 반증되고 진짜 원인은 뭉뚱그려짐, (2) anchored 콘텐츠 evocation 반영률이 4%로 매우 낮아 트레이드오프이자 동시에 사용성 제약, (3) VBench 우위 폭(~0.05점)이 저자 스스로 밝힌 프로토콜 편차 분산과 동일 자릿수, (4) 코드 저장소가 리뷰 시점 비공개.
