# 2시간을 끊김 없이 — Evoke: 외부 기억으로 컨텍스트를 묶어둔 실시간 월드 모델

> 원제: 2시간을 끊김 없이 — Evoke: 외부 기억으로 컨텍스트를 묶어둔 실시간 월드 모델
> 리뷰: [블로그 전문](https://rina-oo.github.io/posts/2608.13546/)

## TL;DR
Interactive world model은 영속 기억과 few-step 반응성을 동시에 디노이저 하나에 요구해왔다. Evoke는 장면 기하를 카메라 포즈로 색인되는 외부 world state bank로 빼내 디노이저 컨텍스트를 세션 길이와 무관하게 고정하고, teacher를 chunk-wise sparse attention + per-chunk conditioning으로 재설계해 30초 self-forced 롤아웃 전체를 distribution matching으로 채점한다. 그 결과 3-step CFG-free student가 세션 길이에 무관한 고정 비용(H200에서 청크당 2.11초)으로 2시간급 연속 생성을 지탱하며, WBench few-step 부문에서 품질·설정·물리성 1위, VBench-2.0 1위(66.77)를 기록한다.

## 핵심 기여
- Bounded recurrent 공식화: $r_k=\text{Read}(M_k,\mathcal{P}_k)$, $x_k\sim p_\theta(\cdot\mid r_k,h_k,c_k)$, $M_{k+1}=\text{Write}(M_k,x_k,\mathcal{P}_k)$ — 영속 상태($M_k$, world state bank)와 디노이저 컨텍스트($h_k$, 고정 크기 국소 히스토리)를 분리해 세션이 길어져도 스텝당 비용이 고정됨
- 장기 supervision 설계: 롤아웃 오류를 degradation drift(짧은 창에서도 감지되지만 원인은 그 이전 조건화 편이)와 content drift(먼 순간을 함께 봐야만 드러남)로 구분하고, 약 30초 window로 두 문제를 동시에 겨냥. supervision horizon은 늘리되(teacher/critic이 전체 궤적을 채점) gradient horizon은 청크 단위로 detach해 activation memory를 우회하는 DMD 손실
- Chunk-wise sparse attention teacher: 각 쿼리 청크가 first-frame sink·local chunk·압축된 근접 프레임·importance-selected 원거리 프레임·linear-attention global state 다섯 소스만 참조해 attention 비용을 시퀀스 길이에 선형으로. 같은 청크 구조로 텍스트 조건을 청크마다 독립 부여해 mid-rollout 프롬프트 전환(evocation)을 teacher 단계에서부터 노출
- 카메라 포즈 색인 world state bank: 매 청크 depth 추정으로 관측을 world-space geometry로 unproject해 저장, 읽을 때는 co-visibility 기준 최대 8개 소스 뷰를 z-buffer 렌더링. visibility mask로 커버된 영역은 낮은 노이즈로 강하게 조건화, 미커버 영역은 σ=1로 사실상 생성에 위임
- 3-step 추론에서 기하 조건화는 coarse-to-fine 피라미드의 가장 거친 단계에만 주입되고 unsupported 토큰은 pruning되어, 추가 비용이 세션 길이가 아니라 world state bank의 커버리지에 비례

## 한계
- Hour-scale 안정성 주장의 표본이 8세션(상세 분석은 사실상 n=1)에 그쳐 장르·카메라 패턴에 따른 일반성은 확신하기 어려움. 저자들도 "안정성 주장이지 fidelity 주장이 아니다"라고 스스로 한정
- Evocation에서 anchored 콘텐츠(이미 world state bank가 고정한 내용)를 텍스트로 덮어쓰는 성공률이 4%(83%→17% 천장 대비)에 그쳐, 기하 기억과 텍스트 조건이 충돌하면 기하 기억이 압도적으로 우선함 — 설계 의도(장면은 고정)이자 동시에 실사용 한계
- WBench에서 Navigation·Perspective가 중하위권으로, world state bank가 카메라 제어 정밀도와 상충하는지에 대한 직접 ablation이 없음
- Teacher horizon 효과는 광도(photometric) 안정성에서만 유의미하게 확인되고 content drift 지표·선명도에서는 short-teacher와 유의한 차이가 없어, "장기 teacher가 모든 장기 일관성을 개선한다"고 일반화할 수 없음
- 코드 저장소가 리뷰 시점 기준 공개 여부 미확인 (논문 소스에는 arXiv 게재와 함께 공개 예정이라고 명시)
