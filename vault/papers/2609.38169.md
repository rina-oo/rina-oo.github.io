# STEPQuant: When and Where Errors Matter in Delta-Rule Recurrent State Quantization

> 원제: STEPQuant: When and Where Errors Matter in Delta-Rule Recurrent State Quantization
> 리뷰: [블로그 전문](https://rina-oo.github.io/posts/2609.38169/)

## TL;DR
Gated Delta-rule linear attention(GDN, KDA)의 recurrent state를 저비트로 양자화하면 에러가 매 디코딩 스텝마다 재귀적으로 전파되어 정확도가 급락한다. 에러 전파식 $E_t = A_t E_{t-1} + \varepsilon_t$을 분석해 retention gate가 강한(기억 수명이 긴) 유닛일수록 에러가 오래 잔존함(Spearman $\rho_S \approx 0.80$)을 보이고, key row별로 readout에 미치는 영향력이 다르며 state 크기도 row·column 양쪽에 outlier가 있음을 보인다. 이 두 축(시간·공간)을 반영해 비트를 차등 배분하고 row/column 스케일을 따로 맞추는 STEPQuant를 제안, Qwen3.8-27B와 Kimi-Linear-48B에서 6비트로 FP32급 정확도를 유지하며 SGLang 서빙 메모리를 최대 68.7% 절감했다.

## 핵심 기여
- 에러 전파 분석: $E_t = A_t E_{t-1} + \varepsilon_t$으로 recurrent state 양자화 에러가 재귀를 타고 전파됨을 증명하고, gate half-life와 누적 에러의 강한 상관(Qwen 전체 2,304 head, $\rho_S \approx 0.80$)을 실측.
- Lifetime-aware Bit Allocation: 유닛별 평균 로그 보존율 $\ell_u$로 lifetime 가중치 $L_u=\sum_j \exp(2j\ell_u)$를 구해, 고정 비트 예산 내에서 $\sum_u L_u d_u(b_u)$ 최소화로 비트 배분. 고위험 유닛(Qwen head의 1.39%)은 FP16 pivot으로 별도 보호.
- Key-Row-Aware Dual-axis Fitting: row-impact score $\omega_i = \mathbb E_{\rm cal}[g_{t,i}^2]$를 계산해 row 스케일 $r_i = m_i^{1/2} w_i^{-1/2}$에 반영하고, column 스케일은 $w_i^2$ 가중 최소제곱으로 별도 적합. 기존 LLM 양자화가 단일 축 outlier를 가정하는 것과 달리 recurrent state는 key row·value column 양쪽에 구조화된 outlier(RMS 비율 각 10.3배, 19.4배)가 있음을 보임.
- 서빙 통합: SGLang에 packed-state 커널로 통합, 6비트에서 recurrent-state 메모리 5.03~5.08배 압축, state 갱신 시간 2.91배 단축, 전체 서빙 메모리 최대 68.7% 절감(배치 512, W4 가중치 기준).
- Ablation으로 두 축의 상보성 입증: Qwen 4비트에서 spatial만 73.95%, temporal만 12.87%인데 결합 시 84.72%(FP32 84.61%)로 FP32를 상회.

## 한계
- 저자 인정: lifetime 가중치는 gate decay로만 에러 잔존을 근사해 key 방향에 따른 시간 변화 state transition은 완전히 포착하지 못함. KDA는 4비트에서 long-generation 정확도 손실 존재, Qwen은 평균 정확도는 유지하나 출력 길이가 FP32보다 다소 김.
- 리뷰어 지적: 평가가 Qwen3.8-27B·Kimi-Linear-48B 두 대형 모델에 국한되어 더 작은 모델이나 Mamba 등 비-Delta-rule 계열로의 일반화는 미검증. Calibration이 WikiText-2 32세그먼트로 고정되어 서빙 트래픽 분포가 크게 다를 때 pivot 선택의 sensitivity가 불명확. DAMP와의 비교는 재현이 아닌 원 논문 수치 인용에 기반한 간접 비교라 평가 설정 차이를 감안해야 함.
