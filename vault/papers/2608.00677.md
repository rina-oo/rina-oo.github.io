# 프롬프트가 아니라 '환경'을 공격한다 — OpenART: Scaling Agent Red Teaming via Open-Ended Environment Evolution

> 원제: 프롬프트가 아니라 '환경'을 공격한다 — OpenART: Scaling Agent Red Teaming via Open-Ended Environment Evolution
> 리뷰: [블로그 전문](https://rina-oo.github.io/posts/2608.00677/)

## TL;DR
기존 에이전트 안전성 벤치마크(InjecAgent, AgentDojo 등)는 median tool call 1~4개 수준의 짧고 정적인 과제로 프롬프트 인젝션 한 종류만 측정한다. OpenART는 과제 목표와 평가기(evaluator)를 고정한 채 워크스페이스·메모리·플랜 상태 같은 target-visible 환경만 진화시키는 것을 red-teaming 단위로 삼는다. 50개 도메인, 10K 검증 시나리오, 15개 배포 에이전트 × 5개 모델(75 조합) 규모에서 black-box 공격 정책 EMHA로 pooled Strict ASR 85.0%를 달성했고, 복잡한 워크플로우일수록 instruction-only 공격 대비 우위가 커진다는 것과, 안전 실패가 오염된 상태를 읽은 시점으로부터 median 37 액션(지연 41%p) 뒤에야 발현된다는 long-horizon safety drift를 실증했다.

## 핵심 기여
- 프롬프트가 아니라 실행 가능한 환경을 red-teaming 단위로 정의: 시나리오 = 양성 과제 목표 + 환경 + 숨겨진 안전 계약(safety contract)의 3중 구조로, 과제/평가 기준을 안 건드리고 환경만 바꿔치기할 수 있게 분리
- target-agnostic 시나리오를 15개 배포 에이전트(Claude Code, Codex, Aider 등)의 네이티브 인터페이스로 투영하는 어댑터 계층 Π_r로 8개 공격 벡터(워크스페이스/지시문/Skill/Tool/MCP/단기·장기메모리/플랜상태)를 이종 런타임에 걸쳐 통제 비교 가능하게 만듦
- EMHA: 공격을 개별 프롬프트 최적화가 아니라 서브골 간 의존관계를 표현하는 하이퍼그래프 경로 탐색으로 정식화. quality-diversity archive + 지연 보상 재분배(credit redistribution)로 파라미터 업데이트 없이 in-context로 적응
- ablation 결과 instruction-only(81.6%) 대비 워크스페이스 단독 진화만으로 92.5%, 나머지 6개 벡터도 전부 50% 이상 — 지시문을 안 건드려도 대부분의 벡터에서 이미 절반 이상 뚫림. 조율된 Full EMHA(94.7%)는 최강 단일 벡터보다 2.2%p 우위에 그쳐, ASR 상승분의 대부분은 "환경을 건드릴 수 있다"는 사실 자체에서 나오고 정교한 탐색 알고리즘의 추가 기여는 상대적으로 작음
- long-horizon safety drift 정량화(propagation distance D_i, 정규화 위치 R_i/S_i/L_i): median 37 액션, 41%p 지연 — "의심 상태 직후 도구 호출만 감시"하는 가드레일로는 못 잡는 실패 패턴을 수치로 제시

## 한계
- Strict ASR의 LLM judge가 GLM-5.2인데 GLM-5.2 자신도 5개 평가 대상 모델 중 하나 — 자기 자신의 트레이스를 자기가 판정하는 잠재적 편향을 논문이 검증하지 않음. 실제로 GLM-5.2의 ASR(87.9%)이 평균(85.0%)보다 높게 나오는데 취약점인지 판정 편향인지 확인 불가
- EMHA를 Related Work에 인용된 다른 적응형 공격(AutoDAN-Turbo, X-Teaming, DTap-Red, AgentLAB)과 동일 조건 head-to-head로 비교한 실험이 없음. 제시된 비교 우위는 EMHA vs EMHA의 instruction-only ablation뿐이라 "EMHA가 좋은 탐색 알고리즘"이라기보다 "환경 조작 자체가 강력하다"를 보여주는 논문으로 보는 게 정확
- Figure 6(복잡도별 ASR)은 절대 ASR이 복잡도 증가에 따라 오히려 하락하고 EMHA와 instruction-only 사이 상대 격차만 벌어지는 구조라, "복잡할수록 더 위험하다"는 헤드라인 문구가 그래프를 오독하게 만들 여지가 있음
- 10K 시나리오·99.3% 평가기 정확도가 전부 저자 자체 파이프라인(Planner LLM + 자동 프로브 + 10% 샘플 human audit)에서 나온 수치이며, 외부 독립 재현·검증은 아직 없음
