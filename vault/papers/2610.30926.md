# MLLM 잠재표현이 생성 모델에 무시당하는 문제 — Making MLLM Latents Matter: Factor-Aware Predictive Learning for Cinematic Video Generation

> 원제: MLLM 잠재표현이 생성 모델에 무시당하는 문제 — Making MLLM Latents Matter: Factor-Aware Predictive Learning for Cinematic Video Generation
> 리뷰: [블로그 전문](https://rina-oo.github.io/posts/2610.30926/)

## TL;DR
MLLM-conditioned Video DiT(UniVideo, Omni-Video 2 등)는 텍스트 인코더·VAE 레퍼런스라는 지름길 때문에 MLLM 잠재표현을 실제로는 우회(bypass)하는 경향이 있다. FAPL(Factor-Aware Predictive Learning)은 이 문제를 3단계 학습으로 해결한다: (I) MLLM·connector를 프리즈하고 MLLM 잠재표현만을 유일한 조건으로 써서 DiT를 강제 적응시킴, (II) 캐릭터/장면/행동/카메라 4개 구간으로 구조화한 쌍 데이터에서 한 구간만 교체(factor-span replacement)해 선택적 제어를 지도, (III) 반대로 DiT를 프리즈하고 텍스트만/텍스트+비디오 두 관측 모드가 같은 타깃을 공유하도록 MLLM·connector를 적응. UniVideo(13B) 기준 sparse-to-video, factor-aware editing, multi-shot 세 과제 전반에서 베이스라인 대비 일관된 개선(Motion Order 48→61%, ∩-Acc 42→58%, FaceSim-Arc 0.451→0.523).

## 핵심 기여
- MLLM 조건이 "연결은 되어 있지만 실제로 쓰이지 않는다"는 bypass 문제를 명시적으로 지적하고 측정 가능한 형태로 제시
- Stage I: 텍스트/VAE 경로를 비활성화하고 MLLM 잠재표현만 조건으로 남겨 DiT가 강제로 의존하게 만드는 grounding 학습
- Stage II: 표현을 완전히 disentangle하려 하지 않고, 구조화된 프롬프트의 구간(span) 단위 교체 → 타깃 비디오 매칭이라는 약한 지도 신호로 factor-aware 제어를 학습 (factor swap 유무 ablation에서 ∩-Acc 48%→57%로 입증)
- Stage III: Stage I과 대칭적으로 DiT를 프리즈하고 MLLM·connector를 적응시킴. text-only와 text+video 두 관측 모드가 같은 비디오 타깃을 공유하게 해 sparse input으로부터의 예측 능력을 학습
- 세 단계가 서로 다른 지표를 책임지는 역할 분담 확인: Stage II는 주로 ∩-Acc(factor 제어), Stage III는 주로 Motion Order·카메라 오차(시간적 추론)를 개선

## 한계
- 메인 비교표에서 FAPL(UniVideo 13B 기반)과 Omni-Video 2(1.3B/14B, 다른 아키텍처)가 한 테이블에 섞여 있어 베이스 모델 차이와 FAPL 기여를 완전히 분리하기 어려움. Omni-Video 2에 대한 Stage I 적용은 Fig. 6에서 정성적으로만 확인됨(정량 수치 없음)
- 평가 벤치마크 CineFactor-10K가 저자들이 직접 구성한 held-out 셋으로, 제3자 독립 벤치마크가 아님 — 학습-평가 분포가 서로 맞춰 설계됐을 가능성 배제 못함
- 코드/가중치 공개 언급이 본문에 전혀 없어 현재 재현 불가
- 저자 스스로 인정: 현재 MLLM은 3D blockout 해석이나 복잡한 카메라 모션 추론에 한계가 있고, 사전학습된 DiT 자체의 시각적 충실도·연기 재현력이 상한선으로 작용 — FAPL은 학습 기법이지 베이스 모델의 표현력 한계를 돌파하는 방법은 아님
