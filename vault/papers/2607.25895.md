# 로봇 없이 로봇을 가르친다 — HiFi-UMI: 고정밀 UMI 데이터만으로 배포 가능한 조작 정책 학습하기

> 원제: HiFi-UMI: Deployable Manipulation Policies from High-Fidelity UMI Data
> 리뷰: [블로그 전문](https://rina-oo.github.io/posts/2607.25895/)

## TL;DR
헤드마운트 스테레오 SLAM + 마이크로초 하드웨어 트리거로 3mm급 정밀도를 내는 핸드헬드 데이터 수집 장치. 이 UMI 데이터만으로 post-training한 정책이 실로봇 원격조작 데이터로 학습한 정책과 대등함을 3개 백본·960회 실로봇 롤아웃으로 검증했다. "로봇 없는 데이터가 못 쓰였던 건 로봇 부재가 아니라 센서 정밀도 문제였다"는 것이 요지.

## 핵심 기여
- 궤적 정확도·상대 자세·동기화·시야각을 하드웨어로 해결한 고정밀 UMI 장치 (SLAM 드리프트·소프트 동기화 지연 제거)
- UMI-only vs teleoperation post-training 성공률 차이 ±3%p 이내 — 3개 정책 백본(StarVLA-QwenPI, OpenPI-π0.5, LingBot-VA)·4개 태스크에서 일관
- 4,000시간 UMI 사전학습 추가 시 미공개 태스크 action error 41% 감소, 실로봇 성공률 +18.1%p
- 2,000시간 데이터셋(HiFi-UMI-2K) 공개 — 새 모델이 아니라 데이터 파이프라인이 기여

## 한계
UMI 3,200개 vs 텔레오퍼레이션 300개로 샘플 수 불균형(동일 샘플 비교 아님). fidelity 4요소의 기여 분해 ablation 없음(future work). 태스크당 40회 평가라 태스크 단위 우열은 잡음 수준. 단일 로봇·단일 그리퍼 검증이라 다른 embodiment 일반화 미확인. 전체 2만 시간 중 2천 시간만 공개된 이유 미설명.
