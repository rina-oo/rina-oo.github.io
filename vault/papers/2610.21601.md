# Waypoint-OPD: Transferring RL-Induced Policy Shifts via Gated On-Policy Distillation

> 원제: Waypoint-OPD: Transferring RL-Induced Policy Shifts via Gated On-Policy Distillation
> 리뷰: [블로그 전문](https://rina-oo.github.io/posts/2610.21601/)

## TL;DR
Direct-OPD는 교사의 RL 학습 전후(Initial→Final) 로그확률 차이를 학생 distillation 신호로 쓰는데, 같은 끝점 변화가 일관된 변화에서 나왔는지 서로 상쇄되는 변화에서 나왔는지 구분하지 못한다. Waypoint-OPD는 RL 중간 체크포인트를 하나 더 써서 초반(Initial→Waypoint)·후반(Waypoint→Final) 변화의 방향 일치도를 코사인 유사도로 측정하고, 일치하지 않으면 끝점 신호를 0으로 깎는 게이트 $g_t=\max(0,c_t)$를 곱해 전달한다. 추가 비용은 frozen teacher scoring 1회뿐이며, Qwen3-4B 교사·Qwen3-8B/14B/30B-A3B 학생·수학+코드 6개 조합 전부에서 Direct-OPD를 능가했다.

## 핵심 기여
- RL 중간 체크포인트(Waypoint)를 "모방 목표"가 아니라 "끝점 신호의 신뢰도를 판단하는 증거"로만 사용 — telescoping($\delta_t=\delta^{(1)}_t+\delta^{(2)}_t$)으로 전달 신호 자체는 바뀌지 않음
- 학생 top-k 후보에 가중한 코사인 유사도 $c_t$로 초반·후반 변화의 방향 일치도를 측정, $g_t=\max(0,c_t)$ 게이트로 끝점 신호를 스케일링
- 배치 단위 정규화 $\kappa_B$로 평균 게이트 크기를 목표치 $\tau$에 맞춰 안정화
- ablation: 게이트 제거(53.50)는 Direct-OPD(53.96)보다 낮고, 게이트 값을 prefix 간에 무작위로 섞으면(51.20) 더 나빠짐 — 게이트의 절대적 분포보다 prefix-신호 매칭이 더 중요함을 시사
- 학습이 진행될수록 평균 게이트가 낮아지고 zero-gate 비율이 높아짐(0.83→0.68, 7%→17%) — 학생이 좋아질수록 교사의 초반·후반 변화가 더 자주 어긋남
- 부수 효과로 Direct-OPD 대비 학습 시간 단축(8h21m→8h2m)과 응답 truncation율 감소(14.83%→11.97%)

## 한계
- Waypoint 위치 민감도 분석이 600스텝 기준 ±100스텝(500/700)으로 좁게만 이루어짐 — 훨씬 이르거나 늦은 지점에서의 거동은 미확인, 수학 도메인에서만 테스트
- 교사 RL 학습의 중간 체크포인트 보관이 전제 조건 — 최종본만 공개되는 오픈웨이트 reasoning 모델에는 적용 불가 (Direct-OPD보다 한 단계 더 비싼 요구사항)
- Qwen3-8B 학생만 Final 교사를 넘어서지 못함(56.14 vs 56.13), 14B/30B-A3B는 각각 +3.07/+1.72점 — 모델 크기와 관련된 패턴으로 보이나 원인 분석 없음
- 효율성(학습시간·truncation율 감소)의 인과관계(게이팅이 장황한 응답을 줄였다는 가설)를 논문이 직접 검증하지 않음
