# GroundingPI: A Grounding Foundation Model towards Physical Intelligence with Visual Primitives

> 원제: GroundingPI: A Grounding Foundation Model towards Physical Intelligence with Visual Primitives
> 리뷰: [블로그 전문](https://rina-oo.github.io/posts/2609.39601/)

## TL;DR
VLA/world-action 모델이 범용 VLM·영상생성 백본을 그대로 쓰면서 정밀한 grounding에 약하다는 문제를 지적하고, 포인트/박스를 1,000개 양자화 좌표 토큰으로 표현하는 4B 전용 grounding 파운데이션 모델 GroundingPI를 제안한다. Base VLM 사전학습 → SFT → GRPO 3단계로 학습하며, 34개 벤치마크 평균 73.68%로 더 큰 GPT-6 Astra(71.54%)를 넘고, RoboTwin2.0/RoboCasa-GR1 로봇 조작과 nuScenes 자율주행으로의 전이에서도 이득을 보인다는 것이 핵심 주장이다.

## 핵심 기여
- MoonViT-V2(Kimi K3 비전 인코더) + Qwen3-4B 디코더 구조에서, 좌표를 텍스트 숫자가 아닌 `<0>`~`<999>` 양자화 토큰으로 어휘집에 통합해 디텍션/레퍼링/포인팅/OCR/GUI/레이아웃을 전부 동일한 다음 토큰 예측 문제로 환원.
- SFT(teacher forcing cross-entropy) 이후 GRPO 강화학습을 적용: grounding은 completeness 보상 $R_{\mathrm{set}}$(reference-wise max-IoU coverage)과 precision 보상 $R_{\mathrm{strict}}$(multi-threshold F1/위치/포맷/개수/순서)을 0.7:0.3으로 섞은 advantage로, OCR은 Hungarian 매칭 기반 단일 보상으로 최적화.
- 양자화 좌표 토큰 설계 덕에 박스당 토큰 수가 COCO 7.6/Dense200 5.1로 SEED1.5-VL(148.8/74.5) 대비 15~20배 압축되어 자기회귀 디코딩 지연시간을 크게 줄임.
- Action DiT·액션 데이터·학습 예산을 고정한 통제 비교에서 RoboTwin2.0 Full과 4개 OOD 세팅 전부 1위, RoboCasa-GR1에서는 50% 데모만으로 타 백본의 75% 데모 성능을 넘어서는 데이터 효율성 확인.
- 데이터 구성 ablation: dense grounding 제거 시 손실이 가장 크고, OCR은 단독으로는 로봇 조작에 거의 도움이 안 되지만(단독 사용 시 ID 24.42%) 제거하면 전체 성능 손실이 가장 커서(ID -5.33pp) 다른 과제의 시각 표현을 정교화하는 촉매 역할을 한다는 가설 제시(미검증).

## 한계
- 평균 점수(73.68 vs 71.54)로는 GPT-6 Astra를 넘지만, 로봇/공간 포인팅(RefSpatial)과 GUI 그라운딩(ScreenSpot-Pro)에서는 Astra가 여전히 10~30점 차로 앞섬. 평균 우위가 전 영역 우위를 의미하지 않음.
- 물리 지능 전이의 "controlled comparison"은 Action DiT·데이터·예산만 고정했을 뿐, 비교 대상 백본들의 파라미터 수·아키텍처(DeepStack, Gated DeltaNet 유무)·사전학습 데이터는 통제되지 않아 성능 차이의 아키텍처적 원인은 입증되지 않음(저자도 인정).
- nuScenes 자율주행 개선폭이 0.296m vs Qwen3-VL-4B 0.301m로 미미하며 open-loop 평가라 실제 폐루프 성능·지연시간은 미측정.
- LVIS(롱테일), VisDrone(드론 소형 물체)에서는 7B MoT 모델 SenseNova-Vision에 밀려, 밀집 장면 대응 능력과 희귀 카테고리 인식 능력이 서로 다른 축임을 시사.
- OCR의 "촉매" 메커니즘은 leave-one-out 결과로부터의 추론일 뿐 직접 검증된 바 없음.
