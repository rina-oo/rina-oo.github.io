# Sage S2.1 Flash Technical Report

> 원제: Sage S2.1 Flash Technical Report
> 리뷰: [블로그 전문](https://rina-oo.github.io/posts/2611.21072/)

## TL;DR
GLM-5.3-Flash를 백본으로 쓰는 320B MoE 모델. 분자 그래프·단백질/DNA/RNA 서열·스펙트럼을 전용 인코더+수치 패칭으로 읽어 프로젝터로 LM 임베딩 공간에 투영하는 Sage Sci-Perception과, 도구 사용·검색·코딩·ML 실험·과학 소프트웨어 전반의 대규모 verifiable 환경 학습을 결합. 과학 인터페이스(프로젝터)만 GRPO로 추가 RL. 33개 벤치마크 중 OfficeQA Pro·MLE-bench Lite·Harvey LAB·SpreadsheetBench 2에서 5개 베이스라인 대비 1위.

## 핵심 기여
- Sage Sci-Perception: 분자(MoleculeSTM)/단백질(ESM-2)/DNA(DNABERT-2)/RNA(RNA-FM) 전용 인코더 + 스펙트럼 수치 패칭(Diffspectra 방식)으로 지역 표현 $H_m$을 얻고, ID 임베딩과 concat한 뒤 LN-Linear-GELU-Linear 프로젝터로 LM 입력 공간에 투영. 위치/정체성 보존이 핵심.
- ToolSpace: 실제 MCP/웹 실행 트레이스에서 도구 호출 패턴 노드 + 데이터/상태/재시도 의존성 엣지로 도구 그래프 구성 → 상태 인식 랜덤워크로 워크플로 생성 → 역방향 합성으로 과제·검증 스크립트 동시 생성 → replay 통과만 채택. 77,760 노드, 804 환경, 평균 18.86 tool call/trajectory.
- 범용(도구/검색/코딩) + 과학(ML 실험, 과학 SW 조작) 과제를 같은 verifiable 환경 프레임워크로 묶어 후속 학습. 코딩 쪽은 정답 유출/verifier 악용 방지를 위한 Hacking Detection 단계 포함(하네스 의존성을 통한 우회 접근 사례도 자체 보고).
- 과학 인터페이스 적응: 인코더·백본은 frozen, 프로젝터만 GRPO로 RL. 보상은 분류/부위예측/수치오차/화학적 동등성 등 과제별 verifier.
- 사람-개입 반복 트레이젝토리 분석 시스템(Coordinator-Analyzer-Counterreview-Cycle synthesis)으로 48쌍 정성 비교: 점수가 같아도 "찾은 정보를 다루는 방식"(매핑·검증 범위 보존)에서 차이가 난다는 패턴 확인.

## 한계
- 벤치마크별 평가 하네스가 모델마다 다름(Claude Code vs OpenHands vs Codex 혼용) — 공정성 판단 어려움.
- 본문에 Cybersecurity 환경 구축(CWE 분류, 차등 검증, 격리 평가)은 상세히 서술하지만 CyberGym/ExploitGym 결과 행은 Table 2에서 주석 처리되어 실제로 빠짐. 이유 불명.
- ToolSpace 규모(노드/환경 수)와 데이터 통계가 전부 내부 집계라 외부 검증 불가.
- Sage Sci-Perception의 과학적 정확도를 보여주는 정량 벤치마크가 없음. CT/3D모델링/EEG 등은 정성적 데모만 제시, 분자 속성 예측 등 수치 결과는 부재.
- 저장소 단위 코딩(SWE-bench Pro)과 웹 검색(DeepResearch Bench II, BrowseComp)에서는 1위를 못함 — verifiable 환경으로 환원되는 능력과 그렇지 않은 능력 사이 격차가 성능에도 반영.
