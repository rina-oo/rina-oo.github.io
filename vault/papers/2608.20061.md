# 학습률 스윕 없이 1550억 MoE 학습하기 — 폭은 μP로, 토큰은 회귀로 나눠 전이하는 법

> 원제: 학습률 스윕 없이 1550억 MoE 학습하기 — 폭은 μP로, 토큰은 회귀로 나눠 전이하는 법
> 리뷰: [블로그 전문](https://rina-oo.github.io/posts/2608.20061/)

## TL;DR
모델 폭 스케일링은 μP로, 토큰 스케일링은 로그-로그 선형 회귀로 분리해 2차원 하이퍼파라미터 스윕을 1차원 탐색으로 줄이고, 이 방법만으로 155B MoE 모델의 학습률을 예측해 10조 토큰을 사전학습한 논문.

## 핵심 기여
- MLA(Multi-head Latent Attention) + Muon optimizer 조합의 MoE 아키텍처에 μP(Maximal Update Parameterization)를 적용. 파라미터를 vector-like/matrix-like로 분류하고(expert FC2는 vector-like, router·FC1은 matrix-like), matrix-like hidden weight에만 fan-in 비율 기반 학습률·초기화 분산 스케일링을 적용. depth는 고정, width만 스케일링 대상.
- 폭(width)과 sparsity(전문가 총 개수)를 함께 늘리는 스케일링 경로에서 최적 학습률이 0.6B→30.7B(약 50배)까지 전이됨을 실증(SP에서는 전이 실패, μP에서는 전이 성공). 다만 width와 sparsity를 항상 함께 늘리므로 sparsity 단독 효과는 분리 불가.
- 토큰 축 확장을 위한 2단계: (1) decay 없이 학습하며 EMA(α=0.6)로 가중치를 스무딩해 한 런에서 여러 토큰 구간의 "사실상 decay 완료" 체크포인트를 추출, 학습률-loss를 2차 포물선으로 피팅해 각 토큰 예산의 최적 학습률(포물선 꼭짓점) 추정 (2) 여러 토큰 예산의 최적 학습률을 로그-로그 공간에서 선형 회귀해 10T 토큰까지 외삽. 배치 크기는 전이 대상에서 의도적으로 제외(시스템 변수로 취급).
- 255B~502B 구간 R²=0.95로 10T 토큰 최적 학습률 3.85×10⁻⁴ 예측. Held-out 검증(255B~350B로 피팅 → 462B~502B 예측)에서 평균 오차 약 4.4%, 다섯 지점 모두 예측값이 실측값보다 큰 방향으로 일관되게 치우침.
- 이 방법으로 155B(활성 17B) MoE 모델을 10T 토큰 사전학습. Loss spike 없이 안정적으로 수렴, 영어/다국어(Ko·Ja·Vi·Zh)/수학/코드 벤치마크에서 고른 성능 확인. 예측 학습률의 최적성을 실규모에서 직접 검증하는 것은 비용상 불가능해 안정적 수렴과 벤치마크 결과를 간접 증거로 제시.

## 한계
- Width와 sparsity가 스케일링 경로에서 항상 결합되어 있어 sparsity 단독의 μP 전이 효과는 검증되지 않음. 저자도 인정하며 sparsity 축만 통제한 후속 실험을 future work로 명시.
- Held-out 검증에서 예측값이 다섯 구간 모두 실측값보다 크게(과대추정) 나오는 일관된 편향이 관찰되나, 원인(회귀 모델의 구조적 편향인지 우연인지) 논의 없음.
- 학습률 전이 규칙이 배치 크기 변화에 얼마나 강건한지 직접 검증하는 ablation 부재. 배치 크기 독립성은 선행 연구 간 결론 불일치를 근거로 한 가정에 가까움.
- MLA + Muon이라는 단일 아키텍처·optimizer 조합에서만 검증. 다른 attention 구조·optimizer로의 일반화는 저자도 향후 과제로 명시.
- 목표 스케일(155B, 10T 토큰)에서 학습률 스윕을 직접 돌 수 없어 예측의 최적성 자체는 실규모에서 직접 검증되지 않음(구조적 제약이며 저자도 인정).
