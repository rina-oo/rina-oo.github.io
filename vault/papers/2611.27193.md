# cmHC: Balancing Stream Mixing in Hyper-Connections via Geometric Contraction

> 원제: cmHC: Balancing Stream Mixing in Hyper-Connections via Geometric Contraction
> 리뷰: [블로그 전문](https://rina-oo.github.io/posts/2611.27193/)

## TL;DR
mHC-lite(퍼뮤테이션 행렬의 볼록결합으로 이중확률 잔차행렬을 구성하는 기존 방법)는 학습 중 softmax가 하나의 퍼뮤테이션 행렬로 수렴해버려 스트림이 거의 섞이지 않는 under-mixing에 빠진다. 반대로 혼합을 억지로 강하게 걸면 스트림들이 균일 혼합(barycenter)으로 수렴해 서로 구분 불가능해지는 over-mixing이 발생한다(Banach 고정점으로 증명). 이 논문은 퍼뮤테이션 기저 행렬 자체를 계수 λ로 뭉개는 geometric contraction을 제안해 모든 성분이 0보다 크다는 하한을 구조적으로 보장하고, 조임을 얕은 K개 층에만 적용해 트레이드오프를 관리한다. 새 파라미터 없이 45M~300B 스케일에서 일관된 개선을 보이고 Ascend NPU fused 커널로 지연시간을 최대 44.8% 줄인다.

## 핵심 기여
- mHC-lite의 under-mixing이 identity뿐 아니라 초기화가 선호하는 임의의 퍼뮤테이션 근방에서도 발생함을 관찰하고, softmax 기반 볼록결합 파라미터화의 근본적 한계로 규명
- Geometric contraction P'_m = λP_m + (1-λ)/(n-1)(11^T - P_m): 퍼뮤테이션 기저를 precompute 단계에서 교체하는 것만으로 모든 잔차행렬 성분이 min(λ, (1-λ)/(n-1)) > 0임을 보장 (추가 파라미터 없음, Birkhoff 제약 exact 유지)
- Dobrushin's ergodicity coefficient로 누적 혼합을 정량화: 전 층에 조임을 걸면 L에 대해 지수적으로 over-mixing(균일 혼합)에 수렴함을 증명 (Banach 고정점), 작은 λ 편차도 층이 쌓이면 증폭되는 "butterfly effect"
- 누적 혼합 하한이 prefix 층의 λ에만 의존한다는 따름정리를 근거로, 얕은 K개 층에만 조임을 적용하는 전략 제안 — nanoGPT 45M~0.36B 전 구간 avg loss rank 1위(λ=0.97, K=2), 동일 조건에서 깊은 층 조임(K=-10)은 그래디언트 폭주(0.38→1.38) 유발
- 6B/300B MoE(DeepSeek 스타일) 프리트레이닝까지 스케일 검증 + Ascend 910C fused Pre/Post 커널로 하이퍼커넥션 연산 지연 최대 44.8% 절감

## 한계
- λ, K가 그리드서치로 고른 수동 하이퍼파라미터. 데이터셋·모델 크기별로 최적값이 다름(OpenWebText는 K=2, FineWeb-Edu nanoGPT-M은 K=10이 더 나음) — 원칙적 선택 규칙 부재
- "얕은 층=일반 특징, 깊은 층=전문화" 근거가 비전 모델 계열 일반론 차용이며 하이퍼커넥션 스트림 구조에서 직접 검증되지 않음. 중간 층 조임과의 비교 부재
- Dobrushin τ의 지수적 붕괴와 실제 downstream 성능 저하 사이의 연결이 집계된 train/val loss 숫자로만 뒷받침됨 — 세밀한 능력별 진단 없음
- Ascend NPU(CANN 9.1.0, 910C) 전용 커널이라 NVIDIA GPU 환경에는 직접 이전 불가
- 6B/300B 대규모 비교가 mHC/mHC-lite로만 한정, shc/ohc/gomhc 등 다른 interior-exploration 계열과는 소규모 nanoGPT 표에서도 비교 없음
