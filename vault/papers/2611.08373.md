# SLA: Scaling Spatial-Language-Action Model via Continual Pre-training

> 원제: SLA: Scaling Spatial-Language-Action Model via Continual Pre-training
> 리뷰: [블로그 전문](https://rina-oo.github.io/posts/2611.08373/)

## TL;DR
2D VLM 위에 지어진 VLA는 3D 공간 구조를 명시적으로 배운 적이 없다는 가설을, 얼린 VLA에 DPT 헤드만 달아 깊이맵을 복원하는 linear probing으로 직접 확인했다(정렬 없이는 복원 불가, 정렬 후엔 GT에 근접). 이 문제를 센서 입력 추가나 처음부터 3D-aware 구조를 새로 짜는 대신, 직전 연구 Spatial Forcing(후속학습에서만 공간 정렬)의 핵심 메커니즘을 continual pre-training 단계로 끌어올려 해결한다. $\pi_{0.5}$를 초기화 지점으로 삼아 VLA의 중간 시각 토큰을 고정된 외부 3D 모델(OmniVGGT) 표현과 코사인 유사도로 정렬시키되, 어느 레이어를 정렬할지는 토큰·채널별 게이트가 학습으로 결정한다(adaptive layer selection). 6개 공개 데이터셋(170만 에피소드, 14,330시간)을 좌표계·회전 표현까지 통일해 하나의 사전학습 코퍼스로 구성했고, 추론 시엔 teacher·프로젝터·게이트를 전부 버려 원래 VLA와 동일하게 동작한다.

## 핵심 기여
- 공간 정렬을 후속학습이 아니라 continual pre-training 단계부터 적용해, 특정 태스크에 종속된 부가 기능이 아니라 기초 모델 수준의 전이 가능한 3D 이해로 격상시킴 (RoboTwin Clean2Random에서 사전+후속 동시 적용이 73.2%, 후속만 57.1%, 사전만 63.2% — 두 단계 모두 필요함을 scaling 실험으로 입증).
- 토큰·채널별 게이트로 여러 VLA 레이어의 시각 토큰을 자동 가중합하는 adaptive layer selection. 고정 레이어 중 최고(layer 12, Clean2Random 67.3%)보다 adaptive(72.3%)가 더 높아, 도메인마다 최적 정렬 깊이가 다르다는 가설을 뒷받침.
- state dropout(학습 중 일정 확률로 state 토큰 전체 마스킹)으로 state 지름길 학습을 억제. 0%/100%보다 25% 확률이 최적(79.2% vs 38.1%/56.7%)인 비단조 패턴.
- rotation vector + SO(3) 합성으로 상대 회전을 계산해 Euler angle 직접 뺄셈의 wrap-around 이상치(±2π 근처) 문제를 회피. q01/q99 정규화 구간이 이상치에 늘어나 정상 값이 압축되는 현상을 방지.
- 이질적 로봇 데이터 통합 파이프라인: EEF pose 좌표계 원점/축 통일, 스크립트 생성 데이터 다운샘플링(3~15%), 다지 핸드·비정상 속도·정지 프레임 필터링, 다운스트림 벤치마크와 겹치는 데이터 사전 제외.

## 한계
- RoboDojo-Real/Sim 결과에는 SLA의 공간 정렬 외에 메모리 메커니즘(과거 메인 카메라 프레임 9장 추가 입력)이 함께 적용돼 있는데, 이 둘의 기여를 분리하는 ablation이 없음. Memory 차원에서만 유독 크게 뛴 수치(26.2/25.8%)를 공간 정렬의 공로로 단정하기 어려움.
- RoboTwin·RoboCasa-Panda 비교 대상 숫자 다수가 공식 리더보드/타 논문에서 그대로 인용한 값이라 평가 시드·trial 수·하드웨어 조건의 동일성이 보장되지 않음. 직접 재현한 π0.5·Spatial Forcing과의 격차가 더 신뢰할 만함.
- 실환경 평가가 조건당 50개 인스턴스, 반복 없이 1회 측정이라 분산/신뢰구간 정보가 없음. 조건 간 20%p 차이의 통계적 견고성을 판단하기 어려움.
- LIBERO-Plus에서 Robot·Language 축은 1위가 아니어서, 공간 정렬의 이득이 시각적 축(카메라·배경·노이즈)에 편중돼 있을 가능성.
