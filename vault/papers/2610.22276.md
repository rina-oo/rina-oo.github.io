# 생성하지 말고 고르기만 하라 — VLM의 공간 판단을 분류 문제로 바꾸기 (MJev-Spatial: System One Spatial Intelligence via Native Attention Matching)

> 원제: 생성하지 말고 고르기만 하라 — VLM의 공간 판단을 분류 문제로 바꾸기 (MJev-Spatial: System One Spatial Intelligence via Native Attention Matching)
> 리뷰: [블로그 전문](https://rina-oo.github.io/posts/2610.22276/)

## TL;DR
공간 이해 질문에 답하려고 텍스트를 생성하는 대신, 사전학습된 attention의 Q/K 프로젝션을 그대로 재사용해 후보를 분류하는 MJev-Spatial을 리뷰합니다. 거리·각도·좌표까지 coarse-to-fine 분류로 풀어내며 기반 모델 대비 5.6배 빠릅니다.

## 핵심 기여
- 선택(choice)·수치 추정(numerical)·포인팅(point) 세 공간 과제를 "유한 후보 집합에서 하나를 고른다"는 단일 softmax 분류 규칙으로 통일. 수치는 coarse→fine 2단계, 포인팅은 3×3 grid를 3번 좁히는 3단계 refinement로 정밀도 확보.
- 분류 헤드를 새로 얹지 않고 백본 마지막 full-attention 레이어의 사전학습된 $W_Q$, $W_K$를 그대로 재사용해 candidate scoring. 추가 학습 파라미터 없음. linear classifier, KEV pointer와 비교해 파라미터·학습비용이 가장 낮으면서 경쟁력 있는 성능.
- 거리 코드북은 로그 간격(log1p spacing)으로 설계해 1cm~16km를 상대오차 일정하게 커버(DORN의 ordinal regression과 유사한 발상을 공간량 전반에 확장).
- 포인팅은 선택될 때마다 원본 이미지에서 새로 크롭·재인코딩(이전 크롭 위에 또 크롭하지 않음)해 refinement에 필요한 로컬 디테일 확보. crop 제거 시 RefSpatial 51.00%→9.00%로 폭락해 이 설계의 기여가 큼을 확인.
- 멀티포인트는 추가 학습 없이 단일 포인팅 분류기의 조건부 확률을 트리로 전개 + peak 그룹화로 확장. continue/stop 방식 대비 Point-Bench 카운팅 성공률 19.39%→38.78%.
- 학습 시엔 전 refinement 스테이지를 teacher forcing으로 한 forward pass에 묶고, 길이 기반 글로벌 배칭+GPU 간 워크로드 밸런싱으로 처리량 30.8% 향상(패딩 35.17%→1.77%).
- Qwen3.5-4B 기반, 12개 벤치마크 평균 1위(65.64%), base 모델 대비 전 벤치마크 성능 향상, 추론 지연시간은 base 대비 5.6배, 최速 베이스라인 대비 2.5배 빠름(B200, 160.6ms).

## 한계
- 메인 비교에서 공간 특화 추가학습 모델(Spatial-SSRL, SenseNova-SI 등)과 범용 VLM이 섞여 있어, "분류 프레임워크 자체의 이득"과 "전용 데이터 학습 이득"이 분리되지 않음. Qwen3.5-4B(동일 백본, 미세조정 전) 대비 비교만 상대적으로 깔끔함.
- Head intervention 실험에서 16개 헤드 모두 사전 설정한 near-zero 기준을 통과하지 못해 전부 유지하기로 결론. 헤드 간 코사인 유사도가 0.985 이상으로 매우 높아(방향은 거의 동일, 크기만 다름) redundancy를 시사하지만, 헤드 축소 가능성에 대한 후속 실험은 없음.
- Visual-token 기반 단일 단계 포인팅과의 비교에서, 디코딩 규칙(argmax vs 연결요소)을 "첫 비교 실험 이후" 과제별로 사후 설정 — 저자도 "탐색적 비교"로 명시한 한계.
- 멀티포인트 트리 디코딩은 "정답 개수 일치 + 모든 점이 정답 영역 내"만 평가 기준이라, 물체당 점 하나를 보장하지 못함(한 물체 주변에 점이 몰려도 통과 가능).
- 수치 추정 ablation에서 fine cell 960개(32bin)보다 216개(4/8bin)가 오히려 낮은 예측 MAE를 보임 — 후보 수 증가가 분류 난이도를 높여 이론적 정밀도 이득을 상쇄하는 사례. 역설적이지만 추가 분석 없이 결론만 제시.
