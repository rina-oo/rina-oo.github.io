# FuseReg: Regularizing Layer Fusion Mitigates the Reconstruction-Generation Gap in Representation Autoencoders

> 원제: FuseReg: Regularizing Layer Fusion Mitigates the Reconstruction-Generation Gap in Representation Autoencoders
> 리뷰: [블로그 전문](https://rina-oo.github.io/posts/2609.31620/)

## TL;DR
Representation autoencoder는 인코더의 어느 레이어를 합쳐 latent로 쓸지 고정된 규칙으로 정합니다. 문제는 얕은 레이어와 깊은 레이어 중 어느 쪽을 고르느냐에 따라 복원 품질과 생성 품질이 서로 반대로 움직인다는 것입니다. FuseReg는 이 선택 자체를 고정하지 않고 학습 때마다 무작위 레이어 부분집합을 섞어 넣는 방식으로 이 트레이드오프를 정면 돌파합니다.

## 핵심 기여
- 레이어 fusion을 고정된 규칙이 아니라 학습 시점의 확률 분포로 취급. 매 샘플마다 Bernoulli(1-p) 마스크로 레이어 부분집합을 뽑고 정규화된 평균 $z_m$을 latent로 사용.
- 부분집합 평균이 전체 레이어 평균 $\bar h$를 기댓값으로 정확히 보존하면서($\mathbb E_S[z_S]=\bar h$), 분산은 레이어 간 불일치 공분산 $V(x)$ 방향으로만 생김을 증명(정보 손실이 아니라 불일치 방향 노출).
- 선형 모델·제곱손실 하에서 디코더/DiT 손실이 원 손실 + $c_K(p)\Omega(D)$ 형태로 정확히 분해됨을 증명 → 무작위 fusion 학습이 곧 명시적 레이어-불일치 정규화항과 동치.
- 고정 fusion 가중치의 2차 모멘트는 랭크 1을 못 넘지만 무작위 fusion은 랭크 $K$ → 학습 가능한 게이트가 결국 단일 레이어로 붕괴하는 현상(실측)을 이론적으로 설명.
- 디코더 교체만으로 생성기 불변 상태에서 DiT-XL unguided gFID 27%↓(3.01→2.21), 디코더+생성기 동시 정규화로 DiT-Base unguided gFID 29%↓(13.96→9.93). 하나의 디코더가 $k{=}7$/$k{=}23$/단일레이어 세 fusion 모두에서 전용 디코더와 동등 이상.

## 한계
- ImageNet-256, DINOv3-L, 고정 학습 예산 내에서만 검증. 다른 인코더 계열, 고해상도, 텍스트 조건부 생성으로의 전이는 미검증.
- 이론(디코더/DiT 손실 분해, 랭크 논증)은 homogeneous linear predictor + 제곱손실 조건에서만 정확. 실제 GAN/LPIPS/디퓨전 같은 비선형 모델에서는 정성적 설명일 뿐 정량 예측은 아님.
- DiT-XL 스케일에서 gFID 최적 드롭률($p_{\mathrm{dit}}{=}0$)과 IS 최적 드롭률($p_{\mathrm{dit}}{=}0.9$)이 어긋남 → 지표별로 별도 튜닝 필요, 단일 권고값 없음.
- 무작위 레이어 드롭이 학습 속도/메모리에 미치는 오버헤드가 정량 보고되지 않음.
- 내부 가이던스와의 교차항 상호작용(REPA 예측 vs 전체 예측)은 수식으로만 제시되고, 가이던스 스케일 재튜닝 문제는 열린 채로 남김.
