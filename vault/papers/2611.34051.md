# Stable Gated DeltaNet-2: Understanding and Mitigating Recurrent State Instability

> 원제: Stable Gated DeltaNet-2: Understanding and Mitigating Recurrent State Instability
> 리뷰: [블로그 전문](https://rina-oo.github.io/posts/2611.34051/)

## TL;DR
GDN-2(Gated DeltaNet-2)는 erase와 write를 채널별 독립 게이트로 분리해 표현력을 높였지만, erase 게이트가 "읽는 방향"($\mathbf{b}_t\odot\mathbf{k}_t$)과 "지우는 방향"($\mathbf{k}_t$)을 다르게 쓰는 비대칭 구조 때문에 recurrent state가 write 없이도 지수적으로 폭주할 수 있음을 이론·실측 양쪽에서 규명했다. 실제 64K 사전학습에서 8회 중 3회가 NaN으로 실패했고, 성공한 run에서도 상태값이 $10^{36}$까지 치솟은 사례가 관측됐다. 해법으로 erase 게이트를 제곱근으로 대칭 분배하는 symmetric erasure와, decay가 허용하는 만큼만 추가 쓰기를 허용하는 residual write를 결합한 Stable GDN-2를 제안해 안정성과 성능을 동시에 확보했다.

## 핵심 기여
- erase 연산자 $\mathbf{A}=\mathbf{I}-\mathbf{k}(\mathbf{b}\odot\mathbf{k})^\top$의 스펙트럴 노름을 정확히 유도($\|\mathbf{A}\|_2=1 \iff \gamma=0$, 즉 읽기·쓰기 방향 collinear일 때만 non-expansive)하고, write 없이도 상태가 무한히 발산하는 구성적 반례를 증명
- 실제 학습 run을 replay하여 NaN 발생 직전 state norm이 로그 스케일로 선형 증가함을 확인하고, effective rank가 1로 수렴하는 표현 붕괴 현상도 함께 관측 — loss 곡선만으로는 감지 불가능함을 보임
- $\mathbf{u}_t=\sqrt{\mathbf{b}_t}\odot\mathbf{k}_t$로 erase를 대칭화한 $\mathbf{A}_t^{\mathrm{sym}}=\mathbf{I}-\mathbf{u}_t\mathbf{u}_t^\top$ 제안, non-expansive 전파를 증명(Proposition 1)
- decay로 조절되는 residual write $\mathbf{r}_t=\sqrt{1-\mathbf{d}_t^2}\odot(\mathbf{k}_t-\mathbf{u}_t)$를 추가해 symmetric erasure가 억제하는 쓰기 유연성을 보완, 상태 노름 bound를 $O(T)\to O(\sqrt{T})$로 개선
- chunkwise parallel 학습 구조(DPLR, WY representation)를 그대로 유지하면서 위 변경을 구현 가능함을 보임
- 1.6B 규모 recurrent/hybrid 모델 실험에서 GDN-2 대비 128K RULER 평균 +6.80점(recurrent), 9-task 평균 정확도 +0.62점(hybrid) 개선

## 한계
- Hybrid 설정 64K·128K RULER에서는 $\beta$-Guard에 근소하게 뒤짐 — recurrent 설정에서만 전 구간 1위
- WikiText/LAMBADA perplexity는 KDA·GDN-2보다 대체로 높음 — 안정성과 언어모델링 품질 사이 트레이드오프 가능성, 논문은 분석하지 않음
- 메인 비교가 단일 seed(init 42, data-order 2026) 기준 — GDN-2 자체가 seed 민감성이 큰 모델임을 저자들이 보였음에도 비교 기법들의 분산은 보고하지 않음
