# ABSeeker: Training Long-Horizon Search Agents via Answer-Backtracked Credit Assignment

> 원제: ABSeeker: Training Long-Horizon Search Agents via Answer-Backtracked Credit Assignment
> 리뷰: [블로그 전문](https://rina-oo.github.io/posts/2608.05102/)

## TL;DR
장기 호흡 검색 에이전트 학습에서 트래젝토리 단위 보상(정답 일치 0/1)은 성공 궤적 속 나쁜 스텝과 실패 궤적 속 좋은 스텝을 구분하지 못한다는 문제에서 출발. 정답을 알고 있다는 전제 하에 정답에서 거꾸로 웹 검색을 수행해 중간 증거 단서 집합을 복원(Answer-Backtracked Clue Recovery)하고, 이 단서 대비 각 스텝의 기여/오류를 채점(Clue-Anchored Step Scoring)해 조밀한 스텝 보상을 만든다. 이 보상을 SFT 손실 재가중(ABC-SFT)과 GRPO 스텝 어드밴티지(ABC-GRPO)에 사용해 Qwen3.5-4B 기반 ABSeeker를 학습, BrowseComp/BrowseComp-ZH/xbench/GAIA-text에서 4B 모델 중 1위, 다수의 30B급 에이전트를 능가.

## 핵심 기여
- Answer-Backtracked Clue Recovery: 정답을 아는 상태에서 LLM이 실제 ReAct 루프(웹 검색·방문)를 돌며 정답에 이르는 중간 증거 단서(엔티티·사실·관계)를 역추적해 복원. 단서 자체가 웹 문서로 실증됨.
- Clue-Anchored Step Scoring: 복원된 단서 집합에 각 트래젝토리 스텝을 대조해 기본점수 1.0에서 가감(정답 단서 발견 +0.8, 오답 후보 배제 +0.4, 정답 단서 오기각 −0.8, 정답 제출 +1.0, 오답 제출 −1.0)한 뒤 [0,2.0]로 클리핑하는 조밀한 스텝 보상 $r_t$ 생성. 궤적의 최종 성패와 무관하게 스텝 단위로 독립 채점.
- ABC-SFT: 스텝 보상을 시그모이드로 변환한 가중치 $w(r_t)=\sigma(\alpha(r_t-\beta))$로 SFT 손실을 재가중, 표준 SFT 대비 특히 xbench-2510·GAIA-text에서 큰 개선.
- ABC-GRPO: 스텝 보상을 낮은 할인율($\gamma=0.25$)로 앞선 스텝에 전파하는 할인된 스텝 어드밴티지를 GRPO에 대입, 5개 벤치마크 전부에서 표준 GRPO 대비 일관된 개선.
- 8.5K개(정답 5.5K/오답 3.0K)의 소규모 데이터로 학습해 4B 모델임에도 여러 30B급 검색 에이전트(Tongyi-DeepResearch, OpenSeeker 등)와 경쟁·능가하는 데이터 효율.

## 한계
- 논문이 인정: 4B 모델로만 검증(계산 자원 제약), 더 큰 백본에서의 효과는 미확인. 프레임워크가 "정답을 역추적 가능한" 검색 과제에 특화되어 있어 다른 장기 호흡 에이전트 과제(코딩, 로보틱스 등)로의 일반화는 별도 검증 필요.
- 리뷰어 지적: (1) Clue Recovery·Step Scoring이 DeepSeek-V4-Flash 단일 채점자에 전적으로 의존하는데 오류율·사람 검수 정합률에 대한 정량 분석 부재. (2) 채점 루브릭의 가감점·클리핑 구간이 고정값으로 주어질 뿐 근거나 민감도 분석 없음. (3) 베이스라인 간 컨텍스트 관리 적용 여부 표기가 벤치마크마다 다소 일관되지 않아 완전 동일 조건 비교인지 불분명. (4) BrowseComp 스타일 데이터로만 학습했는데 xbench·GAIA-text로도 잘 전이되는 이유(공통된 "정보 탐색" 과제 구조 때문인지, 진짜 일반화인지)가 논문에서 충분히 규명되지 않음.
