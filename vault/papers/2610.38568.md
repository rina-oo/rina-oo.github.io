# 데이터가 바닥났다는 걸 모델 스스로 알게 하기 — A-RSI: Adaptive Task Refresh for Zero-Data Multimodal Self-Improvement

> 원제: 데이터가 바닥났다는 걸 모델 스스로 알게 하기 — A-RSI: Adaptive Task Refresh for Zero-Data Multimodal Self-Improvement
> 리뷰: [블로그 전문](https://rina-oo.github.io/posts/2610.38568/)

## TL;DR
외부 라벨이나 평가 점수 없이, 학습 로그에 남는 advantage 신호만으로 "이 문제 풀은 이제 배울 게 없다"는 걸 판단해 새 태스크 풀로 교체하는 자기개선(RSI) 기법 A-RSI를 리뷰합니다. Qwen3-VL-8B 기준 800개의 새 태스크만으로 11개 벤치마크 평균을 57.77에서 61.05로 끌어올립니다.

## 핵심 기여
- 학습 로그 기반 풀 교체 규칙 제안. GRPO 그룹 내 advantage가 0이 아닌 프롬프트 수 $U_w$와 평균 정답률 $a_w$를 윈도우마다 계산하고, $U_w$가 과거 대비 임계비율(0.85) 이하로 떨어지거나 $a_w$가 충분히 오르면 풀 전체를 교체. 검증셋/테스트 점수는 전혀 참조하지 않음.
- 태스크 생성·정답 산출을 모두 프로그램이 담당. 템플릿 $\tau$에서 파라미터 $z$를 뽑으면 이미지·질문·정답이 같은 설정에서 동시에 나옴($(I,q,a)=G_\tau(z)$) — self-consistency/다수결 투표 라벨링과 달리 모델 자신의 오답이 다음 학습 라벨이 되는 구조를 피함.
- 난이도 기반(Frontier)·적응형(Continuous)·주기적(Periodic) 선택 전략과 매칭된 학습량에서 비교. 무작위 선택 + 로그 트리거(A-RSI)가 4분의 1의 새 태스크(800개)만으로 매 윈도우 교체(3,200개, Continuous)보다 높은 점수(61.05 vs 60.64).
- 점수 상승을 "응답이 짧아져 완결된 효과"와 "실제로 답이 고쳐진 효과"로 분리해서 분석. 출력 토큰 예산을 4096→8192로 늘렸을 때 학습 이득 유지율이 A-RSI 80% vs 비교 대상 MM-Zero v5 59% — 경쟁 방법 이득의 상당 부분이 완결 효과였음을 재현 실험으로 지적.
- 자기 reward/정답 체커에 대한 스트레스 테스트 수행(1,000개 태스크 × 7 응답 변형, 16,000건 체커 검사). 정답>오답 순위는 항상 보장되지만 오답 내에서 형식·종료만으로 보상이 오를 수 있음을 확인(reward hacking 가능성 인정).

## 한계
- 타이밍과 선택 전략이 ablation에서 동시에 바뀌어 효과가 뒤섞임. 선택을 Frontier로 고정하고 타이밍만 비교하면 로그 트리거가 오히려 0.30점 뒤처짐. 실제 실행된 교체 시점도 공교롭게 고정 3윈도우 스케줄과 일치해, "로그 기반 타이밍이 고정 스케줄보다 낫다"는 주장은 아직 대조군 부재로 미입증.
- 각 arm을 1회씩만 학습(시드 반복 없음) — 0.4~1점대의 작은 차이에 유의성 검정 없음.
- MiMo 모델에 쓰인 교체 풀이 Qwen 기준 난이도로 선정되어 모델 간 전이가 완전히 독립적으로 검증되지 않음.
- 태스크 생성기가 기하·차트·표·카운팅으로 한정(함수 그래프·수치 추정·공간 추론 미포함), 다른 추론 유형으로의 일반화는 미확인.
- 정답 체커에서 16,000건 중 220건 실패(객관식 파싱 취약점), 1,927건 감사 중 5건 "동률" 라벨 모호성 — 파이프라인이 완전하지 않음을 저자 스스로 보고.
