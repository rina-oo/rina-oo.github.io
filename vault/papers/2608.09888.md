# 말로 하지 않는 추론 — BDH-CQ: 문맥 학습과 잠재공간 추론을 결합한 ARC 리즈너

> 원제: 말로 하지 않는 추론 — BDH-CQ: 문맥 학습과 잠재공간 추론을 결합한 ARC 리즈너
> 리뷰: [블로그 전문](https://rina-oo.github.io/posts/2608.09888/)

## TL;DR
Pathway(BDH 아키텍처 팀)가 발표한 BDH-CQ는 in-context learning과 recurrent latent reasoning을 결합한 ARC 리즈너다. 데모를 순환 메모리 $S_t$에 순차적으로 흡수하고, 쿼리를 별도의 잠재 워크스페이스 $H_r$에서 $R$번 반복 연산해 답을 디코딩한다(토큰으로 중간 추론을 verbalize하지 않음). 150M 파라미터 모델이 ARC-AGI-1 public eval에서 pass@2 29.5%를 task당 $0.00070에 달성해 기존 비용-정확도 Pareto 프런티어를 갱신했다고 주장한다. 다만 $U_\theta$, $E_\theta$, $F_\theta$, $G_\theta$의 구체적 연산과 차원, 학습 레시피는 전부 proprietary로 남아 재현 불가능하다.

## 핵심 기여
- 데모를 순환 메모리로 흡수(in-context learning)하고 쿼리는 별도의 잠재 워크스페이스에서 반복 연산(latent reasoning)하는 2단 구조 — task identifier도, 평가 task 데모로 하는 gradient 최적화도 없음 (HRM/TRM의 transductive 방식과 대비됨)
- ARC-AGI-1 public eval에서 task당 $0.00070에 pass@2 29.5% — GPT-5.6 Luna(Low, 34.2% @ $0.008 원가 기준)보다 약 11배(가격 인하 미반영 시 57배) 저렴하다고 주장
- ConceptARC 16개 개념 영역별 프로파일링: 국소적 시각 판단(FilledNotFilled, TopBottom2D)은 9/10, 전역적 구성/순서(Copy, Order)는 2/10 — 능력이 개념 유형에 따라 크게 갈림
- 통제된 확장 실험으로 실패 유형을 구분: 정렬(ordering) 실패는 출력 구조 자체가 무너지는 유형, 중첩(nesting) 실패는 구조는 유지한 채 국소 오류가 나는 유형. 중첩 실패는 데모에 목표 깊이 예시 하나만 추가해도 19/24→24/24로 해소되어 외삽 실패에 가까움을 시사; 정렬은 보강해도 완전히 회복되지 않아 실행 병목이 남아있음을 시사
- 연산 합성 실험: 원래 완벽히 학습된 연산(회전)은 합성해도 안 무너지지만(72/72), 절반만 학습된 연산(색 교환, 26/72)은 합성 시 완전히 붕괴(0/72) — 합성 성능이 단일 연산의 학습 견고성에 비례

## 한계
- 아키텍처 핵심($U_\theta$/$E_\theta$/$F_\theta$/$G_\theta$의 정확한 연산, 상태 차원, 학습 레시피)이 전부 proprietary — 학술 논문 형식이지만 재현 불가능. GitHub에 공개된 저장소(pathwaycom/arc-task-gen)는 평가용 task 생성기일 뿐 모델 코드/가중치는 비공개
- "독립 감사"가 논문 공저자(Bielik, NYU 소속)에 의해 수행됨 — 저자 목록 바깥의 제3자 재현은 아직 없음
- 비용 비교 기준 혼재: BDH-CQ는 측정된 자체 하드웨어 원가, 비교 대상 다수는 공개 API 가격. 헤드라인 "57배 저렴"은 경쟁사 구 가격 기준이며 최신 가격 반영 시 11배로 저자 스스로 정정
- ConceptARC 개념 영역당 10 task로 표본이 작아 Wilson 신뢰구간이 넓게 겹침(9/10과 2/10의 CI가 겹침)
- 부록의 mechanic-stratified 생성셋은 GPT-5.6이 프롬프트로 생성해 mechanic별 정확도가 모델 능력보다 "GPT-5.6이 그 mechanic을 얼마나 잘 구현했는가"에 좌우됨(손으로 만든 gravity task 80~100% vs 생성 2.9%) — 저자들도 이 confound를 인정
- 정렬/중첩에서만 유독 급격한 성능 붕괴가 나타나는 근본 원인(순차적 구성이 잠재 워크스페이스 구조와 근본적으로 안 맞는지 여부)은 아키텍처 비공개로 검증 불가
