# OneStreamer: Unifying Perception, Memory, and Proactive Response in Streaming Video Interaction

> 원제: OneStreamer: Unifying Perception, Memory, and Proactive Response in Streaming Video Interaction
> 리뷰: [블로그 전문](https://rina-oo.github.io/posts/2610.01762/)

## TL;DR
스트리밍 비디오 LLM이 '나중에 뭐가 중요할지 모르는 채로' 지금 본 것을 기록해두고, 충분한 증거가 쌓였을 때만 응답하게 만드는 OneStreamer를 리뷰합니다. 캡션을 재사용 가능한 기억으로 쓰는 PHCM과, 침묵 토큰에 학습이 쏠리는 문제를 완화하는 PSTL이 핵심입니다.

## 핵심 기여
- Proactive Hierarchical Caption Memory(PHCM): 모델이 스스로 생성하는 `</Observe>`(짧은 구간 세부 캡션)와 `</Summary>`(완료된 사건 요약)를 텍스트 히스토리에 누적해 Recent-N 시각 윈도우 밖으로 밀려난 과거 정보를 재사용 가능한 기억으로 대체. 별도 retriever·메모리 인코더 없이 모델 자신의 생성 행위가 곧 메모리 쓰기.
- Proactive State Transition Learning(PSTL): 상태 토큰(`</Silence>`/`</Standby>`/`</Response>` 등) supervision에서 출력-개시 전이($\mathcal{A}_\tau$)의 빈도로 quota $q=\max_X\max_a n_{X\to a}$를 정하고, 각 전이 그룹에서 $\min(n_{X\to Y},q)$개만 무작위 샘플링해 state loss에 포함. 선택되지 않은 토큰은 시퀀스·다른 loss에는 그대로 남고 state loss에서만 제외됨 — 반복되는 침묵 라벨이 loss를 지배하는 문제를 완화하면서 상태 유지(persistence)도 일부 학습.
- 두 메커니즘 모두 "증거 기록"과 "과제 응답"을 하나의 인과적 생성 과정(같은 제어 토큰 예측 문제)으로 통일 — 별도 모듈 설계 없이 공유 인터페이스로 처리.
- 오프라인 비디오를 스트리밍 학습 시퀀스로 바꾸는 합성 파이프라인(캡션 브랜치: Gemini/Seed로 다단계 캡션 생성 후 시점 정렬, QA 브랜치: 증거 구간 대략 위치 → 슬라이딩 윈도우로 "가장 이른 신뢰 가능 시점" 역산)으로 OneStreamer-1M(100만+ 레코드) 구축.
- Qwen3-VL-4B 초기화, 4B 모델이 OVOBench/StreamingBench/OVBench/ODVBench/ProactiveVQA/OmniMMI/OVO-Timing/ViSpeak 8개 벤치마크 전부에서 비교 모델(11B MOSS-VL-Realtime 포함) 대비 최고점. PHCM ablation에서 Recent-16 윈도우 유지한 채 캡션 기록만 추가해도 OVOBench Backward ASI가 63.5→71.6, 효율은 Full-history 대비 컨텍스트 토큰 93.1%·GPU 메모리 60.4% 절감.

## 한계
- 자가 수정 메커니즘 부재: 부록 실패 사례에서 모델이 한 번 잘못 기록한 캡션(프린터를 "닫는다"고 오인)을 이후 프레임에서 명백한 반증이 나와도 정정하지 않음. 캡션 메모리가 누적되는 구조상 오류 전파 위험이 있으나 본문에 체계적 Limitations 섹션 없이 부록 말미에만 짧게 언급됨.
- 데이터 합성 전체가 Gemini·Seed라는 폐쇄형 모델의 판단(캡션 사실성, 증거 구간, 응답 타이밍 신뢰도)에 의존 — 특정 사건 유형에서의 체계적 편향 가능성 미검증.
- 코드 저장소는 평가·추론 스크립트만 공개, 4B 체크포인트는 "공개 예정" 상태로 리뷰 시점 재현 불가.
- Table 1 비교 대상 다수가 특정 벤치마크 칸이 공란 — 미평가인지 저조한 성능 생략인지 구분 불가, "전 벤치마크 1위" 주장 해석 시 유의 필요.
- PHCM이 EPM(OVOBench Backward) 지표에서는 Full-history(63.0)보다 낮은 62.6에 머무름 — 완전한 우위는 아님.
