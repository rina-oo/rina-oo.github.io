# 문제집이 아니라 교과서를 가르친다 — TOME-Math: 구조를 보존한 수학 증명 지도학습 데이터

> 원제: 문제집이 아니라 교과서를 가르친다 — TOME-Math: 구조를 보존한 수학 증명 지도학습 데이터
> 리뷰: [블로그 전문](https://rina-oo.github.io/posts/2610.40394/)

## TL;DR
수학 SFT 데이터는 대부분 문제-풀이 쌍으로 평평하게 펴지는데, 이 논문은 2,118권의 대학 수학 교과서를 OCR·장 구조 복원·증명 추출 파이프라인에 통과시켜 장 순서·정리-증명 의존 관계·출처를 보존한 380,292개 QA(TOME-Math)를 만든다. Qwen3-30B-A3B-Base를 이 데이터로 파인튜닝하면 6개 벤치마크 평균이 29.17%→45.83%로 오르고, 4.8배 큰 OpenMath1보다도 전 벤치마크에서 앞선다. 구조가 실제로 기여하는지는 추론 시점 검색, 커리큘럼 순서, 출처 다양성 세 축의 통제 실험으로 따로 검증한다.

## 핵심 기여
- 교과서 PDF → DeepSeek-OCR → 상태머신 기반 장 분할 → 정리/보조정리/정의-증명 추출(Proof QA)까지 구조를 잃지 않는 파이프라인 구축. 완전성·정확성·LaTeX 서식·자기완결성·원자성 5축 LLM 심사로 품질 통제.
- 증명에서 암묵적으로 생략된 중간 추론 단계를 LLM이 탐지해 독립적인 명제+증명으로 재작성하는 Gap QA 스트림 추가(후보 918,235개 중 19.00% 생존, 174,431개).
- 추론 시점 구조-검색: 같은 토큰 예산에서 "같은 책 무작위 발췌"보다 "정리 의존 관계를 따라 고른 근거"가 pass@1을 13.25%→17.38%로 끌어올림(파라미터 업데이트 없음).
- 커리큘럼 실험: 정방향 장 순서가 역방향/셔플보다 전 18개 과목-스케일 조합에서 일관되게 우세(최대 +8.50점), Gap-우선 배치가 추가로 +1.5~2.4점.
- 출처 다양성: 같은 토큰 예산을 8권에 몰아주는 것보다 16권에 분산하는 쪽이 전 과목에서 +1.6~4.8점. 과목별 특화 체크포인트의 교차-과목 전이 계수 평균 0.92로, 증명 패턴이 과목을 가로질러 재사용됨을 시사.
- 비관적 검증기($y_{ij}=\prod_{r=1}^{8}\mathbf{1}[e_{ijr}=-1]$, 8회 리뷰 중 1표라도 오류면 기각)와 600개 응답 대상 수학 박사급 2인 블라인드 재채점으로 자동 평가의 신뢰도를 별도 검증.

## 한계
- 전체 코퍼스 비교(OpenMath1/MetaMath/MathInstruct 대비)는 출처·생성방식·품질검증 수준이 전부 달라, "구조 보존이 원인"이라고 단정할 수 없음을 저자도 인정. 구조 자체의 인과는 통제 실험에서만 분리됨.
- Gap QA는 생성도 LLM, 심사도 LLM(gpt-oss-120b)이 담당해 생성·심사 모델이 공유하는 편향이나 맹점은 걸러지지 않을 가능성. 평가 단계의 사람 검증과 달리 데이터 생성 단계의 이 위험은 논문에서 다뤄지지 않음.
- 코퍼스는 "공개 예정"이라고만 명시되어 있고 이 시점 기준 실제 저장소 링크는 확인 불가.
- 6개 벤치마크 단순 평균이라 AIME-26처럼 점수대가 낮은(8~12%) 벤치마크와 MATH-500처럼 점수대가 높은(68~77%) 벤치마크가 같은 가중치로 평균에 반영됨. TOME-Math가 유일하게 2위에 그친 벤치마크가 AIME-26(최종 답만 채점, 증명 과정 불필요).
