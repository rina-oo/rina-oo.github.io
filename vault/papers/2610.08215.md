# LLM 에이전트는 정말 '경험에서' 배우는가 — Learn2Play Bench

> 원제: LLM 에이전트는 정말 '경험에서' 배우는가 — Learn2Play Bench
> 리뷰: [블로그 전문](https://rina-oo.github.io/posts/2610.08215/)

## TL;DR
반복 과제에서 에이전트 점수가 오를 때 그게 "경험에서 새로 배운 것"인지 "사전학습 지식을 재활용한 것"인지 기존 벤치마크로는 구분할 수 없다는 문제의식에서 출발. 사전지식이 통하지 않는 반직관적 숨은 규칙을 가진 텍스트 게임 20개(고정 10 + 재셔플 10)로 Learn2Play Bench를 설계하고, 11개 백본·6개 self-evolving 방법·3개 배포형 하네스·사람 참가자를 Max/Mean/Learning Gain/Learning Slope 네 지표로 동시 비교. "더 정교한 메서드일수록 더 잘 배운다"는 암묵적 가정이 보편적으로 성립하지 않음을 보여줌.

## 핵심 기여
- 사전지식으로 풀 수 없는 숨은 규칙(일부는 상식과 반대)을 가진 텍스트 게임 20개 설계, 고정/재셔플 인스턴스 분리로 "학습"과 "전이"를 따로 측정 가능하게 함
- Max(도달 성능)·Mean(일관성)·Learning Gain(초반-후반 평균 차)·Learning Slope(선형 회귀 기울기)로 "학습"을 다면적으로 정의. 정규화는 게임별 기준점수 $C_g$로 환산($z=100x/C_g$), $C_g$의 신뢰도는 exact/partial/estimated 세 등급으로 구분됨
- 가공하지 않은 원본 상호작용 기록을 그대로 쌓는 Memory가 reflection·규칙추출·워크플로 유도 기법(Reflexion/ReasoningBank/AWM/EvoTest)을 제치고 Kimi K3 기준 4개 지표 전부 1위 — 단 Opus 5에서는 EvoTest가 1위라 백본에 따라 최적 방법이 다름을 확인
- 같은 백본에 하네스만 바꿔도(OpenCode→Claude Code/Codex) 성능과 비용이 동시에 개선됨을 확인(Opus 5: Max 74.5→81.8, 비용 2.57→0.647달러/에피소드)
- 사람 Top-1이 모든 평가 대상 에이전트·방법을 통틀어 가장 높은 Max(84.3) 기록. 행동 통계로 사람이 더 다양한 전략을 시도하고(연속 행동 유사도 0.54 vs 에이전트 0.66) 실패 후 더 잘 회복함(재도전 성공률 33% vs 22%)을 정량화
- 재셔플 게임에서 Learning Slope 하락폭이 모델마다 다름(Sonnet 5·Gemini 계열은 크게 하락, Opus 5·Kimi K3는 작게 하락) — "규칙 자체"를 학습했는지 "인스턴스 특화 정답"만 암기했는지의 차이로 해석

## 한계
- 트라이얼 3개, 에피소드 5~10개뿐이라 분산 추정이 약함. Kimi K3에서 Memory(LG +16.9)와 EvoTest(LG +1.8)의 큰 격차가 통계적으로 얼마나 안정적인지 본문만으로는 확신하기 어려움
- 게임별 기준점수 $C_g$의 신뢰도(exact/partial/estimated)가 다른데도 가중 평균에서 동일 가중치로 합산됨 — 일부 게임의 100점이 다른 게임의 100점과 같은 수준을 보장하지 않음
- 벤치마크의 핵심 전제(모델이 규칙을 모른다는 것)가 시간이 지나 플레이 기록·공략이 쌓이면 무너질 수 있는 구조적 유통기한 문제가 있음. 유지보수·갱신 계획은 논문에 명시되지 않음
- GitHub 코드(20개 게임 템플릿 + play.py)는 실제로 공개·실행 가능하나, README상 "익명 리뷰용 스냅샷"이라 사람 플레이어 기록이나 전체 평가 하네스까지 공개됐는지는 확인되지 않음
