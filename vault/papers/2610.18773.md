# Jeva: System One Models from First Principles

> 원제: Jeva: System One Models from First Principles
> 리뷰: [블로그 전문](https://rina-oo.github.io/posts/2610.18773/)

## TL;DR
"system one" 결정(도구 선택, 문서 식별, 분류, 점수 매기기)을 질문+후보를 통째로 이어붙여 답 토큰 logit으로 읽는 기존 설계는 순서에 민감하고, 후보 재사용이 안 되고, 후보 수가 고정되고, null을 표현하지 못한다는 네 가지 구조적 결함을 가진다고 주장. Jeva는 요청과 각 후보를 공유 인코더로 독립 인코딩해 후보 벡터를 요청·순서 무관하게 고정하고, 가벼운 1-블록 디코딩 모듈이 요청 상태만 후보 메모리를 읽어 갱신하도록 분리. 대칭 집계(순서 불변), 공유 스코어링(후보 수 확장), 별도 coverage 게이트(최댓값 기반, 후보 수 로그항 오염 없음), 후보별 K/V 캐싱(요청 간 재사용)을 각각 수학적으로 증명하고 실험으로 검증. Qwen3.5-4B + rank-64 LoRA(13.37M) 구성으로 8개 벤치마크 슬라이스 중 7개 1위, null 탐지 AUROC 98.66%, 순서 바꿔도 플립율 0%, 2048개 후보까지 커버리지 100% 유지, 캐시 적중 시 최대 27.86배 지연시간 단축.

## 핵심 기여
- 독립 인코딩(요청 $z_0$, 후보 $u_i$를 공유 백본으로 분리 인코딩) + 요청 상태만 갱신하는 1-블록 attention 디코더. 후보 벡터는 질문·순서·다른 후보에 무관하게 고정되어 캐싱의 전제 조건이 됨.
- Proposition 1: 독립 스코어러는 로그-오즈 식에서 정규화 상수가 소거되어 집합이 바뀌어도 두 후보의 상대 우열을 절대 못 뒤집는다는 것을 증명하고, 단일 결정 블록이 집합 변화에 따라 우열을 뒤집는 구체적 구성(벡터 예시)으로 반증.
- Coverage 게이트: $\rho=\sigma((\max_i s_i-b_{\mathrm{cov}})/\tau_{\mathrm{cov}})$로 "답 존재 확률"을 경쟁(competition, $q=\mathrm{softmax}(s/\tau_{\mathrm{dec}})$)과 분리. 기존 flat-softmax 방식은 $p_\bot^{\mathrm{flat}}=\sigma((b_0-s)/\tau-\log K)$처럼 후보 수 $K$에 비례해 null 확률이 체계적으로 오염되는데, Jeva는 기존 최댓값보다 낮은 후보 추가 시 $\rho$ 불변(Proposition 2).
- Proposition 3(대칭·재사용): 순열해도 $z_L$·null 확률·Noul/Score 출력 불변, 캐시된 엔트리를 재계산 값으로 대체해도 모든 출력 불변 — 증명 + 실측(플립율 0%, 캐시 조건 간 확률 차 최대 0.00736)으로 이중 확인.
- 2,048개 후보까지 전체 집합을 한 번의 디코딩 헤드 패스로 스코어링(재귀적 선택 대비 커버리지·정확도·속도 동시 우위), 후보별 K/V 캐싱으로 재사용 시 최대 27.86배 지연시간 단축.

## 한계
- 비교 베이스라인(Jev-1.13.0, JevK5, Intern-Decision, ReFlex, SemiF, KEV, CLM, Valen, Laya 등)의 정체를 공개 모델 목록에서 독립적으로 확인하기 어려움. 인용 키도 비표준적(`almeida2026jev`, `localllama2026typed`) — 실제 공개 베이스라인인지 재명명/익명화된 것인지 논문만으로 불명확.
- 학습 커리큘럼이 단계별 대략적 예시 수(~80k, ~500k 등)만 보고되고 구체적 데이터 출처는 미공개 — 재현성 제한.
- 배포 모델은 $L=1$ 블록만 사용하나 $L$을 늘렸을 때의 ablation 부재. 이론은 일반 $L$을 가정하지만 실증은 단일 블록에 그침.
- Score RMSE에서는 InternDecision-4B(0.3208)에 근소하게 밀림(Jeva 0.3222) — 전 지표 싹쓸이는 아님(저자가 그대로 보고한 점은 긍정적).
- 텍스트 기반 결정에 한정, 이미지·도구 출력 등 멀티모달 후보로의 확장 가능성은 논문 범위 밖.
