# Can MiniMax-H3 Reason About the Physical World? An Evaluation of Omni-Modal Generative Model

> 원제: Can MiniMax-H3 Reason About the Physical World? An Evaluation of Omni-Modal Generative Model
> 리뷰: [블로그 전문](https://rina-oo.github.io/posts/2609.18323/)

## TL;DR
텍스트 프롬프트에는 정답을 담지 않고 이미지·오디오·비디오 등 다른 모달리티에 정답 정보를 분산시킨 "암묵적 프롬프트" 평가 프레임워크를 제안. 옴니모달 생성모델 MiniMax-H3를 대상으로 4개 시나리오(MSR/ADR/VDR/AVIR)·29개 서브카테고리·517개 인스턴스에 대해 사람이 직접 성공 여부를 판정. 전체 정답률 41.97%로, 멀티모달 입력을 "지원"하는 것과 그 정보를 종합해 "추론"하는 것 사이에 큰 간극이 있음을 보임.

## 핵심 기여
- 정답에 필요한 정보를 텍스트 프롬프트에서 제거하고 이미지/오디오/비디오에 분산시켜, 모델이 실제로 모달리티를 종합해야만 풀 수 있는 평가 세트를 설계 (기존 벤치마크는 프롬프트에 정답이 이미 명시되어 있어 이 구분이 불가능했음).
- MSR(다중 시점 공간 추론), ADR(오디오 기반 모호성 해소), VDR(비디오 기반 의사결정), AVIR(시청각 통합 추론) 4개 시나리오로 공간·시간·청각 축을 분리해 평가.
- 소스 수집 → 과제별 인스턴스 구성 → 10회 반복 전문가 검토(장면 복잡도/추론 필요성/조건 정합성/프롬프트 암묵성)를 거쳐 517개 인스턴스 구축, 3인 교차검증으로 정답 판정.
- MiniMax-H3 전체 정답률 41.97%, VDR 56.00%(최고) vs ADR 27.40%(최저)로 28.6%p 격차. 오디오를 시각적 사건으로 변환하는 능력이 가장 취약함을 정량적으로 드러냄.
- 실패 유형을 4가지로 분류: 증거-개체 오연결, 사건 미구현, 물리/구조 위반, 시간적 상태 불일치. 이 패턴이 ADR·VDR 전반에 반복됨을 정성 분석으로 확인.

## 한계
- 사람 3인 교차검증 방식이라 확장성이 떨어지고 재현 기준이 불명확함 (논문도 인정).
- 모달리티 하나씩 제거하거나 오디오만 치환하는 통제실험이 없어, 실패가 "모달리티 이해 실패"인지 "생성 단계의 실패"인지 원인 분리가 안 됨 (논문도 향후 과제로 인정).
- 평가 대상이 MiniMax-H3 단일 모델뿐이라 다른 옴니모달 모델과의 비교가 없음 — 결과가 이 모델 고유의 약점인지 옴니모달 생성모델 전반의 한계인지 이 논문만으로는 판별 불가 (리뷰어 지적).
- VDR의 Cartoons(N=5), Memory(N=6), Puzzles(N=6), Traffic(N=9)처럼 표본이 매우 작은 서브카테고리가 다수 존재해 해당 수치의 통계적 신뢰도가 낮음 (리뷰어 지적).
- 평가 데이터 상당수가 ChatGPT Voice/Seedance 2.0으로 만든 합성 오디오·비디오라, 실제 환경 녹음보다 신호가 깨끗해 모델에 유리하게 작용했을 가능성이 검토되지 않음 (리뷰어 지적).
