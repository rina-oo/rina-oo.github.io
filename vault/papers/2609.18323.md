# 여러 감각을 준다고 다 쓰는 건 아니다 — MiniMax-H3의 물리 세계 추론 평가

> 원제: 여러 감각을 준다고 다 쓰는 건 아니다 — MiniMax-H3의 물리 세계 추론 평가
> 리뷰: [블로그 전문](https://rina-oo.github.io/posts/2609.18323/)

## TL;DR
Omni-modal 생성 모델이 여러 모달리티를 입력으로 받을 수 있다는 것과 그것들을 종합해 실제로 추론한다는 것은 다르다는 문제의식에서 출발한다. 텍스트 프롬프트에는 목표 이벤트를 명시하지 않고 그 정보를 이미지·오디오·비디오 등 다른 모달리티에 분산시키는 implicit generation 평가 프레임워크를 제안하고, MiniMax-H3를 테스트베드로 517개 인스턴스(4과제 29서브카테고리)에서 측정한다. 전체 성공률은 41.97%로, 비디오 기반 연속 추론(VDR, 56.00%)은 상대적으로 낫지만 오디오 기반 모호성 해소(ADR, 27.40%)는 크게 뒤처진다.

## 핵심 기여
- 프롬프트에서 목표 추론을 의도적으로 숨기고 관측(이미지/오디오/비디오)에만 단서를 배치하는 implicit generation 평가 패러다임 제시. 기존 벤치마크(VBench, WorldModelBench 등)는 프롬프트가 정답을 명시해 모델이 관계를 파악하지 않고도 그럴듯한 출력을 낼 수 있었다는 점을 지적.
- Multi-view Spatial Reasoning(MSR)·Audio-based Disambiguation Reasoning(ADR)·Video-based Decision Reasoning(VDR)·Audiovisual Integrated Reasoning(AVIR) 4개 과제로 공간·청각·시간·시청각 통합 추론을 분리해 측정.
- 10회 반복 전문가 리뷰(장면 복잡도, 추론 필요성, 조건-목표 정합성, 프롬프트 암묵성 4기준)를 거친 517개 인스턴스 구축, 실제 로봇조작/비디오/음향 데이터셋과 합성 데이터(ChatGPT Voice, Seedance 2.0)를 혼합.
- 정량 결과(과제별 SR)와 정성 실패 유형 분류(증거 오귀속, 이벤트 미완성, 물리/구성 위반, 시간적 상태 불일치)를 함께 제시해 "multimodal input support ≠ multimodal reasoning" 결론을 뒷받침.

## 한계
- 실패 라벨이 성공/실패 이진값 하나뿐이라 원인(오디오 오분류 vs 비주얼 생성 실패)을 분리하지 못함. 평가자 간 일치도(inter-annotator agreement) 수치도 미보고.
- MiniMax-H3 단일 모델만 평가해 41.97%가 벤치마크 난이도 때문인지 이 모델의 특이한 약점인지 판별 불가. 타 omni-modal 모델과의 비교 없음.
