# 라벨 하나만 맞히던 tabular AI, 이제 표 전체를 함께 배운다 — LimiX-2 (LimiX-2: A Contextual Mechanism Network Towards General Structured-Data Intelligence)

> 원제: 라벨 하나만 맞히던 tabular AI, 이제 표 전체를 함께 배운다 — LimiX-2 (LimiX-2: A Contextual Mechanism Network Towards General Structured-Data Intelligence)
> 리뷰: [블로그 전문](https://rina-oo.github.io/posts/2609.17488/)

## TL;DR
기존 tabular PFN은 $p(y\mid x, D_{ct})$, 즉 지정된 타겟 컬럼 하나만 맞히도록 프리트레이닝된다. LimiX-2는 이를 $p(x,y\mid D_{ct})$로 넓혀 표의 임의 컬럼을 가리고 맞히는 Context-Conditional Masked Modeling(CCMM)으로 학습시키는 Contextual Mechanism Networks(CMN) 패러다임을 제안한다. cell-level 표현을 유지하는 dual-axis transformer(feature축/target축 분리, K=4 target 슬롯)와 SCM 기반 합성 데이터 생성 엔진으로 구현했고, TabArena(1935)·TALENT(1506)·BCCO(1432) 세 벤치마크 Elo 전부 1위, 4배 큰 TabFM보다도 우위. 부산물로 feature attention 점수만으로 causal skeleton을 복원해 causal discovery 전용 기법들과 경쟁하는 수준(평균 F1 0.7972)을 보였다는 게 핵심.

## 핵심 기여
- 라벨 예측을 일반화한 CMN 패러다임: 지도학습을 "표의 임의 컬럼을 조건부로 맞히는" 더 넓은 문제의 특수 사례로 재정의(CCMM 목적함수).
- feature/target 경로를 분리한 asymmetric dual-axis transformer: feature는 target을 attend할 수 있지만 target은 다른 target을 못 봄 — 이 비대칭성이 causal skeleton 복원의 근거가 됨.
- 회귀 head를 MSE에서 5000-bin 분포 예측으로 교체, 임베딩 차원 192→256, low-rank DFE로 컬럼 정체성 인코딩.
- SCM(causal motif 기반 DAG + 다양한 edge function/aggregation) 기반 합성 데이터 생성 엔진 확장 — 실데이터 없이 프리트레이닝.
- 12.5M~406.2M 파라미터 구간에서 로그-선형 스케일링 법칙 확인(TabArena $\beta=34.68$, $R^2=0.98$), 4배 작은 크기로 TabFM 추월.

## 한계
- 아키텍처 변화(임베딩 차원, 회귀 head, attention 구조)와 파라미터/데이터 스케일 증가가 LimiX-16M→LimiX-2 사이에 동시에 일어나, CMN 패러다임 자체의 기여와 순수 스케일 효과를 분리하는 ablation이 없음.
- 비교 리더보드가 전부 자체 색상 강조(gold/silver/bronze)로 자사 우위를 부각하는 방식이며, TabArena 점수는 공개 리더보드를 그대로 인용.
- causal skeleton 평가에서 attention 점수를 skeleton으로 변환하는 threshold 선정 기준이 불명확 — ground truth 그래프 밀도를 참고했는지 불분명.
- BCCO multiclass 카테고리에서는 AutoGluon 1.6 Extreme에 밀려 1위가 아님(전체 결과의 예외 사례).
- 모델 가중치 공개 여부가 리포트 본문에 명시되지 않음.
