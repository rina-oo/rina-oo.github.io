# 센서가 달라도 '만졌다'는 사실은 같다 — LingBot-Touch: 이질적인 촉각 센서를 위한 통합 표현 학습

> 원제: 센서가 달라도 '만졌다'는 사실은 같다 — LingBot-Touch: 이질적인 촉각 센서를 위한 통합 표현 학습
> 리뷰: [블로그 전문](https://rina-oo.github.io/posts/2611.12806/)

## TL;DR
피에조저항·자기·시각 촉각 센서의 taxel을 공통 손가락-끝 좌표계(canonical fingertip space)로 투영하고 5D RoPE로 인코딩한 뒤, V-JEPA 계열의 잠재공간 예측 목적함수(Tactile-JEPA)로 5,000시간 규모 멀티소스 코퍼스에서 사전학습한 촉각 인코더. 사전학습에 없던 센서(XHand1)에서도 파라미터 추가 없이 기존 최고 수준 모델(FTP-1)을 앞서고, frozen 토큰을 네 가지 정책 패밀리에 꽂는 것만으로 실제 로봇 26개 과제 평균 성공률을 13.9~24.8%p 끌어올렸다. 핵심 주장은 "스케일할수록 좋아지는 건 특정 트랜스듀서가 아니라 접촉 자체의 표현"이라는 것.

## 핵심 기여
- 센서별 taxel 인덱스 대신 손가락 위의 연속 3D 위치 + 손가락 식별자 + 시간으로 구성된 5차원 토큰 주소를 RoPE에 태워, 센서 레이아웃이 달라도 같은 백본(Haptic Transformer)이 처리 가능하게 만듦.
- 신호 복원 대신 마스킹 위치의 잠재 표현을 예측하는 Tactile-JEPA 목적함수 채택. 희소 신호 특성상 마스킹 비율을 처음부터 80%로 주면 학습이 발산해서, 40%→80% 선형 warm-up(300 step)으로 안정화.
- 레이아웃 암기를 막기 위해 다중 해상도 샘플링 + taxel 위치 jitter(이웃 간격 비례)로 augmentation.
- 사람이 낀 촉각 장갑(2/3)과 로봇 원격조작(1/3)을 합쳐 5,000시간/464K episode/13.3억 frame 규모 코퍼스 구축.
- Frozen encoder로 접촉력·접촉중심·접촉면적·미래힘·촉각-영상 검색 5개 probing 과제, 26개 실제 로봇 과제(4개 정책), 시뮬레이션 12개 과제(RL)에서 검증. VAE/MAE 복원 목적함수와 직접 비교해 latent prediction의 우위도 별도로 확인.

## 한계
- 손가락 끝 중심 설계라 손바닥·손가락 옆면 접촉은 다루지 못함(저자 인정). 실험 로봇 손 종류도 아직 적고, 용량성(capacitive) 센서는 데이터 품질 문제로 사전학습에서 제외.
- 고정 예산 비교에서 멀티소스가 단일소스 대비 공간 정밀도(접촉 중심 추정)를 상당폭 희생함(0.34→0.68mm). 이 트레이드오프가 실제 로봇 과제 성능에 미치는 영향은 probing 수치로만 보여줄 뿐, 통제된 정책 비교는 없음.
- FTP-1 비교 시 두 방법의 사전학습/적응 예산이 동일 조건인지 불명확해 절대적 격차 크기는 다소 유보적으로 봐야 함.
- Ablation에서 context loss가 target-only 대비 사실상 중립(일부 지표는 오히려 약간 나쁨)인데도 본문 전체에서 계속 사용 — 유지 근거가 명시되어 있지 않음.
