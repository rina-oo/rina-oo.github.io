# 돈을 접어 거북이를 만들라 했더니 — 비디오 생성 모델의 '결과 달성' 능력을 재는 SemComp-Bench

> 원제: 돈을 접어 거북이를 만들라 했더니 — 비디오 생성 모델의 '결과 달성' 능력을 재는 SemComp-Bench
> 리뷰: [블로그 전문](https://rina-oo.github.io/posts/2608.17426/)

## TL;DR
비디오 생성 모델에게 과정이 아니라 결과물만 요구하는 새로운 평가 축(SemComp-Bench)을 제안한 논문. 최고 모델도 결과 달성률(OA Score)이 37.8%에 그쳐, 화면은 그럴듯해도 지시받은 결과에는 도달하지 못하는 경우가 대부분이라는 걸 보여준다.

## 핵심 기여
- Semantic Task Completion Video Generation 태스크 정의: 중간 과정 재현이나 참조와의 외형적 일치 대신, 결과 달성(Outcome Achievement)과 참조와의 의미적 정합(Semantic Grounding)만 요구
- SemComp-Data: Koala-36M의 실제 촬영 영상에서 참조/결과 프레임을 직접 추출하는 4단계 파이프라인(Candidate Filtering → State Mining → Video Extension → Instruction Structuring)으로 1,273개 image-text-video triplet 구축. 실제 영상에서 뽑았으므로 결과 달성 가능성이 데이터 구축 단계에서부터 보장됨
- State Mining의 Quality Checking: 라벨을 가린 참조/결과 프레임 쌍을 VLM에게 다시 보여주고 구분시켜, 애매한 쌍을 자동으로 걸러내는 자기 검증 장치
- SemComp-Bench 평가 프로토콜: OA는 4개 이진 기준의 곱(conjunctive, 하나라도 실패하면 0)으로, GR은 5개 이진 기준의 평균으로 집계 — "결과 도달 여부"와 "생성 품질"의 성격 차이를 점수 집계 방식에 반영
- 7개 대표 모델 평가에서 OA Score 최고값이 37.8%(HunyuanVideo-1.5-720P-I2V)에 그침을 확인. GR 1위(Seedance 2.0, 91.8%)와 OA 1위가 다른 모델이라는 점에서 "화면 품질"과 "결과 달성"이 별개 축임을 실증

## 한계
- 정식 평가는 전체 1,273개 중 60개(SemComp-Core, 도메인당 10개)로만 수행 — 21개 세부 카테고리 대비 샘플 수가 적어 카테고리별 신뢰도가 불확실. 60개로 축소한 이유(비용 등)가 논문에 명시되지 않음
- 큐레이션과 채점 전 과정이 단일 VLM(Doubao-Seed-1.8)에 의존. VLM judge와 사람 판단의 일치율 등 신뢰도 검증 수치가 없음
- OA Score의 곱셈(conjunctive) 집계가 최종 수치(37.8%)에 미치는 영향에 대한 ablation(예: 기준 개수를 줄였을 때 비교) 없음 — "결과 달성이 어렵다"는 결론이 지표 설계에서 기인하는 정도를 분리하기 어려움
- 논문이 스스로 인정: SemComp-Data를 실제 task-specific 파인튜닝에 활용해 성능이 개선되는지는 검증되지 않음
