# 주사위는 한 번 던져서는 모른다 — PAWBench: How Far Are We from Probabilistically Aligned World Modeling?

> 원제: 주사위는 한 번 던져서는 모른다 — PAWBench: How Far Are We from Probabilistically Aligned World Modeling?
> 리뷰: [블로그 전문](https://rina-oo.github.io/posts/2608.27345/)

## TL;DR
비디오 생성 모델을 "월드 모델"로 볼 때, 영상 한 편의 그럴듯함(plausibility)과 반복 rollout의 확률 분포 정합성(probabilistic alignment)은 별개 축이라고 주장. 이를 support alignment(가능한 결과를 다 만드는가)와 probability-mass alignment(올바른 비율로 만드는가)로 분리 정의하고, 50개 물리 시나리오·8개 메커니즘 그룹으로 구성된 PAWBench와 VLM 루브릭 채점 프로토콜 PAWEval을 제안. 11개 최신 비디오 생성 모델(HappyHorse, Veo3.1 Fast, Kling 3, Seedance 2, Wan2.x, LTX-2.x, Cosmos 3, LingBot, MiniMax H3) 벤치마킹 결과 모든 모델이 정확도·커버리지·안정성 중 최소 하나에서 실패. rollout 예산을 K=100까지 늘려도 calibration TVD는 거의 개선되지 않아 유한 샘플링 문제가 아님을 확인.

## 핵심 기여
- probabilistic alignment를 $p_M(y\mid x,a) = \Pr_{\tau\sim P_M}[g(\tau)=y]$ 형태로 정식화하고, support alignment(유효 결과 집합 커버) vs probability-mass alignment(정확한 확률 비율)로 분리
- PAWBench: PAW-Calibration(25개, 참조 확률분포 $q$ 존재 — 동전/룰렛/라우팅/드로우류)와 PAW-Coverage(25개, 유효 결과 집합만 정의 — 충돌/안정성/에이전트/재료류)로 이분
- PAWEval: Gemini 3.5 Flash 루브릭 판독으로 rollout→결과 라벨 매핑, outcome-readout 실패를 별도 집계(Scene Pass Rate)하여 판독 실패가 통계를 왜곡하지 않도록 설계
- 인과적 개입(연필 기울기)에는 둔감, 비인과적 개입(문구 힌트)에는 과민 반응한다는 것을 paired intervention으로 실증 — 표면적 단서에 의존한 결과 생성 가능성 시사
- 언어(프롬프트/Oracle PE)·초기 노이즈 커플링(C2C)·LoRA 파인튜닝 세 지점에서 교정 시도. Oracle PE도 요청 결과 실현율 37.6~58.1%에 그침. LoRA 학습 비율 조정은 장면별 조건부 확률을 못 잡고 전역적으로만 이동(한 장면 교정하면 다른 장면이 깨짐)

## 한계
- 논문이 인정: (1) 결과를 terminal outcome으로 압축해 궤적 중간 동역학은 미평가, (2) 유한 rollout 예산이라 비용-신뢰도 트레이드오프 존재, (3) 통제된 단문 시나리오만 다뤄 장기·상호작용적 환경으로 미확장
- 리뷰어 지적: 채점이 단일 VLM(Gemini 3.5 Flash)에 의존하며, 사람과의 일치율 81.3%는 "판독 가능한" 888개에 한정 — outcome-readout 실패로 아예 제외된 애매한 케이스의 모델별 편향 여부는 불명
- 참조 분포 $q$는 물리적 대칭성에서 유도한 규범적 정답이지, 모델이 실제로 학습한 인터넷 비디오 데이터의 분포와 같다는 보장이 없음 — 편향이 모델 결함인지 데이터 반영인지 분리 어려움
- 평가 비용이 큼(모델당 2,500개, 11개 모델 총 27,500개 영상 생성) — 신규 모델마다 재현하기 부담스러운 규모
