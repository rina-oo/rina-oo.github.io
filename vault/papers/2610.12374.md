# AgentGarten: Code Worlds for Evolving Agents

> 원제: AgentGarten: Code Worlds for Evolving Agents
> 리뷰: [블로그 전문](https://rina-oo.github.io/posts/2610.12374/)

## TL;DR
시뮬레이터/게임 엔진이 들고 있는 명시적 상태·규칙과, 사전학습 비디오 모델이 만드는 사실적 화면을 depth·normal 조건으로 연결하는 "code world" 프레임워크. 렌더러는 Adversarial Forcing(distribution matching + exact replay + 실데이터 adversarial loss)으로 증류해 H100 한 장에서 35fps대 실시간 생성을 달성. hide-and-seek을 포함한 5개 코드월드에서 사전학습 에이전트가 시각 관찰만으로 라운드를 거듭하며 playbook(텍스트 경험)을 쌓아 shelter 구축·ramp 사용 같은 행동을 몇 라운드 만에 획득함을 보임.

## 핵심 기여
- Code world 정식화: 상태 전이 $f_p$는 렌더링된 관찰을 입력으로 받지 않아 렌더링 오류가 상태에 누적되지 않음. 같은 상태 궤적을 다른 외형/카메라로 재렌더링 가능.
- Adversarial Forcing: (1) DMD로 bidirectional 교사 분포에 맞춤, (2) exact replay — SGF의 full-sequence FlexAttention 대신 롤아웃과 동일한 블록 단위 SDPA로 재계산해 replay 오차를 3.99%(상대 L2)에서 0(bitwise)으로 제거, (3) backbone 고정을 이용해 R1/R2를 근사 없이 정확한 그래디언트로 계산(double backward 불필요, APT의 랜덤 섭동 근사보다 정밀).
- 코딩 에이전트가 이미지/텍스트에서 scene program을 작성(Perceive→Write→Inspect→Extend 루프, rollout 검증 기반 self-repair). 외형은 렌더러가 책임지므로 scene program은 coarse geometry만 있으면 됨.
- Hide-and-seek 재현: 사전학습 에이전트가 object state 없이 순수 1인칭 렌더링만 보고 playbook(스킬 파일, markdown)을 라운드마다 갱신. shelter 구축 4라운드, ramp 사용 10라운드 — 단, 2019년 self-play RL(2500만/1억 에피소드) 대비는 저자도 인정하듯 직접적 샘플효율 비교가 아니라 "사전학습 지식을 센서모터 행동에 접지하는 속도" 비교.
- 4개 추가 world(강아지, 다리, 양몰이, 쇼벨카)에서도 같은 4단계 루프(Read→Play→Write→Archive)로 라운드 간 점수 개선 확인.

## 한계
- 라운드당 1 에피소드, world당 4라운드뿐 — 통계적 유의성 없음. playbook 유무에 대한 ablation 부재로, 개선이 "경험을 글로 남겨서"인지 "같은 과제에 반복 노출돼서"인지 분리 안 됨.
- hide-and-seek 샘플효율 비교(에피소드 수 vs 라운드 수)가 서로 다른 패러다임 비교라 액면 그대로 읽으면 오도될 수 있음.
- depth/normal 조건은 회전 대칭 물체의 회전처럼 기하가 안 변하는 상태 변화를 표현 못함(저자도 Future Work에서 인정, 구체적 해법은 없음).
- 쇼벨카 world는 라운드 2에서 점수가 0으로 역행 후 회복 — 비단조적 학습 곡선의 원인 분석 없음.
- GitHub 저장소에 렌더러 코드·체크포인트는 공개돼 있으나(placeholder 아님), 이 논문의 핵심인 code worlds·agent practice loop는 "추후 공개 예정"으로 아직 재현 불가.
- "엔진 상태 + 신경망 렌더러" 결합 자체는 OmniDreams, Magpie, Code2Worlds 등과 방향이 겹쳐 프레임워크 차원의 독창성은 제한적. 실질 기여는 Adversarial Forcing의 공학적 디테일(exact replay, exact R1/R2)에 더 가까움.
