# 판정관도 후해요 — OSReward: VLM 판정관은 컴퓨터 쓰는 에이전트를 얼마나 믿을 수 있나

> 원제: 판정관도 후해요 — OSReward: VLM 판정관은 컴퓨터 쓰는 에이전트를 얼마나 믿을 수 있나
> 리뷰: [블로그 전문](https://rina-oo.github.io/posts/2607.28609/)

## TL;DR
CUA(computer-using agent) trajectory의 성공 여부를 VLM judge가 판정하는 관행이 표준이 되었지만, 그 신뢰도를 정면으로 측정한 연구는 없었다. 4개 플랫폼에서 직접 수집한 1,019개 사람-검증 trajectory로 27개 VLM judge를 평가했더니, 전부 "실패를 성공으로 오판"하는 관대함(leniency) 편향을 공유했다. 어려운 부분집합(OSReward-Hard)에서는 최고 judge도 69.7%, 평균은 52%(동전 던지기 수준)까지 떨어진다. 원인은 judge가 화면보다 에이전트 자신의 완료 서술 텍스트에 의존하는 데 있다. 이를 교정한 오픈 reward model OS-Shepherd(9B/35B)는 30~60배 싼 비용으로 상용 judge 수준에 근접한다.

## 핵심 기여
- OSReward: 재사용 trajectory가 아니라 4개 플랫폼(웹·Windows·Ubuntu·모바일) 전용 데이터 인프라를 직접 구축해 만든 judge 평가 벤치마크. 3인 독립 라벨링 + meta-review로 800시간 투입해 1,019개 gold trajectory 확보
- OSReward-Hard(284개, 실패 70%)와 OSReward-Multi(성공 440개에 alignment/efficiency 세분 라벨) 두 파생 세트로 judge의 한계와 세밀 채점 능력을 별도로 진단
- 27개 VLM judge의 역대 최대 규모 비교: 모든 judge가 "task incomplete인데 accept"를 최소 48% 이상의 비중으로 공유하는 leading error로 갖는다는 발견
- Input ablation으로 편향의 메커니즘을 특정: 스크린샷 구성(개수·순서·마커)은 정확도에 거의 영향이 없는 반면, 사고·행동 텍스트를 제거하면 평균 7.2pp(최대 10pp+) 하락 — judge가 화면이 아니라 에이전트의 자기 서술에 의존한다는 증거
- 앙상블 무효화 진단: 상위 judge 간 pairwise κ≈0.71로 서로 같은 실수를 공유(herd)하기 때문에 다수결이 거의 개선을 못 만듦(oracle 정확도는 99%로 정답 자체는 풀 안에 있음)
- OS-Shepherd-100K(32만+ judge instance 중 강한 judge들의 만장일치만 채택해 9.66만 건 구성) + SFT→RL(GRPO, false-success 채굴) 2단계 학습으로 관대함 편향을 직접 교정한 오픈 judge 공개, held-out 벤치마크(OSWorld/AndroidWorld/WebArena)에서 de-biasing 전이 확인

## 한계
- OSReward-Multi(품질 세분 채점)에서는 모든 judge가 약함: 이진 판정 90%대 judge도 60%대 초반으로 하락, 특히 alignment 축에서 "일단 최고점" 경향. OS-Shepherd-9B는 사실상 상수 예측 수준
- 관대함 편향을 교정할 처방으로 "완료를 명시적으로 검증하라"는 프롬프트 방향을 제시하지만 논문 내에서 직접 검증하지 않음(future work로 남김)
- 판정관 간 herd 현상(κ≈0.71)이 구조적 습관(학습 데이터의 공통 편향)에서 온다면 스크린샷/프롬프트 개선만으로는 해결이 안 될 수 있는데, 이 가능성은 논문이 깊이 파고들지 않음
- OS-Shepherd-100K 라벨 자체가 "강한 VLM judge들의 만장일치"로 만들어져, judge들이 공유하는 편향이 코퍼스에 잔존할 가능성을 완전히 배제하기 어려움(다만 held-out 전이 결과로 어느 정도 상쇄)
- 오픈 모델 가격은 2026년 5월 시장가 추정치로, 실제 자체 호스팅 비용과 괴리가 있을 수 있음
