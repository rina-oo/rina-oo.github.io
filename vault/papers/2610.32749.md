# 입모양 보고 목소리 골라내기 — Falcon과 RealSSA, 실시간 Audio-Visual 화자 추출

> 원제: 입모양 보고 목소리 골라내기 — Falcon과 RealSSA, 실시간 Audio-Visual 화자 추출
> 리뷰: [블로그 전문](https://rina-oo.github.io/posts/2610.32749/)

## TL;DR
Tsinghua·칭하이대 공동 연구로, 두 화자 고정·조용한 환경이라는 기존 벤치마크의 비현실성과, 가벼운 모델이 반복 호출로 성능을 메꾸다 보니 오히려 느려지는 문제를 함께 짚습니다. 근/원거리 화자와 돌발 소음을 섞은 RealSSA 벤치마크와, 단일 인코더-디코더 패스로 다중 스케일 분리를 하는 Falcon을 제안해 AV-TF-GridNet 대비 파라미터 91.9%, 연산량 20.2배, 지연 11.1배를 줄였습니다.

## 핵심 기여
- RealSSA-Sim: 근/원거리 화자 수(2~6명), 잔향(RT60), 환경소음, 돌발소음을 4개 장면 유형(소규모 회의실/중간 실내/대형 공공장소/야외)에서 동시에 샘플링하는 시뮬레이션 벤치마크. LRS2/LRS3/VoxCeleb2-2Mix류가 화자 수 2명 고정·조건 통제인 것과 대비됨.
- RealSSA-Real: 아이폰으로 8개 실환경(스터디룸~야간 거리)에서 10명을 녹음한 held-out 평가셋. 시뮬레이션 학습 모델의 실환경 일반화를 평가하는 용도.
- Falcon Separator: 비대칭 U-Net에서 인코더는 다운샘플링만 하고 TFRB(freq-LSTM → time-LSTM → 2D self-attention)는 bottleneck과 디코더 네 레벨에서만 수행. 단일 encoder-decoder pass로 4개 TF 스케일을 확보해 SwiftNet의 반복(iterative) 방식을 대체.
- Global Context Injection(GCI): bottleneck 전역 컨텍스트 G를 게이팅(σ(φ_gate(G)))으로 각 skip connection에 주입. 인코더·디코더 양쪽에 각각 적용.
- Encoder-space speaker contrastive loss: 같은 audio encoder로 쿼리·positive(깨끗한 타겟)·negative(근거리 간섭화자)를 인코딩해 대조 손실 적용. softmax 가중 hard-negative 집중 + margin(m=0.5)으로 이미 분리된 negative는 무시. 추론 시 비활성화되어 inference cost 0. 원거리 화자는 거리감쇠·후기잔향으로 신호가 약해 negative에서 제외.
- 결과: AV-TF-GridNet 대비 파라미터 91.9%↓, MACs 95.0%↓, GPU 지연 91.0%↓. 4개 공개 벤치마크(RealSSA-Sim/LRS2-2Mix/LRS3-2Mix/VoxCeleb2-2Mix) 전부 SI-SNRi 1위. 같은 파라미터(0.5M)의 SwiftNet-12 대비 MACs 76.6%↓, GPU 지연 70.2%↓.
- 대조 손실은 아키텍처 독립적: Falcon(+0.4dB), SwiftNet-12(+0.2dB), Dolphin(+0.3dB) 모두에서 SI-SNRi 개선.

## 한계
- Figure 10 PCA 시각화는 "화자 판별력 향상" 주장에 비해 근거가 약함. 대조 손실 적용 후 대부분 임베딩이 한 지점(PC1 98.6% 분산)으로 수렴하는 형태라 클러스터 분리인지 단순 collapse인지 그림만으로 불명확. t-SNE나 실루엣 스코어 같은 정량 지표 부재.
- RealSSA-Real은 84분·10명·54세션으로 소규모. 저자도 한계로 인정. 이 규모에서 나온 WER·화자 유사도 수치(Falcon이 AV-Mossformer2에 WER 0.74%p 뒤짐)의 통계적 안정성은 논문에 명시 안 됨.
- 4-element 마이크 어레이까지 시뮬레이션해놓고 본 논문 실험은 전부 1채널만 사용. 멀티채널 확장은 향후 과제로 미룸.
- 대조 손실은 근거리 간섭화자의 깨끗한 개별 파형을 요구해 시뮬레이션 데이터에서만 적용 가능. 실제 녹음 데이터로 직접 학습하는 길은 아직 열리지 않음(저자 인정).
