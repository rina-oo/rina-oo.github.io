# LLMRouter: Unified Infrastructure for Developing, Evaluating, and Deploying LLM Routers

> 원제: LLMRouter: Unified Infrastructure for Developing, Evaluating, and Deploying LLM Routers
> 리뷰: [블로그 전문](https://rina-oo.github.io/posts/2608.06867/)

## TL;DR
LLM 라우팅을 $s_t=(q,u,h_t)$ 상태 위의 순차적 의사결정 과정으로 공식화하고, 라우터를 $E_q$(context encoder), $E_m$(model encoder), $g$(scoring function), $d$(decision rule), $\mathcal{L}$(learning signal) 다섯 부품으로 분해한다. 이 공식화 위에 라우팅 supervision을 자동 구축·평가하는 파이프라인을 만들어 xRouteBench(generic/memory/vision/time-series/personalized 5트랙, 4,767쿼리)를 구성하고, 16개 이상의 기존 라우터를 `MetaRouter` 인터페이스 하나로 재구현한 오픈소스 라이브러리를 공개한다. 목적은 파편화된 라우터 연구를 하나의 코드베이스·평가 프로토콜 위에서 비교 가능하게 만드는 것.

## 핵심 기여
- 라우팅을 5개 컴포넌트($E_q, E_m, g, d, \mathcal{L}$)로 분해하는 통일 공식화. single-turn/multi-turn/personalized의 차이를 $E_q$가 상태의 어느 부분(쿼리/히스토리/페르소나)을 관찰하는지로 환원
- 쿼리 수집→응답 수집→채점/가격 산정 3단계로 라우팅 supervision을 자동 구축하고, 동일 후보 풀·쿼리·지표로 모든 라우터를 평가하는 파이프라인
- xRouteBench: generic LLM tasks(13개 서브태스크)·memory(LoCoMo, LongMemEval)·vision(이미지+영상)·time-series·personalized(PersonaHub 200 페르소나) 5트랙, 총 4,767쿼리. 비전/시계열은 고정 VLM 캡셔너로 텍스트화해 라우팅과 지각을 분리
- 16개 이상 라우터를 `MetaRouter`/`BaseTrainer` 인터페이스로 재구현한 오픈소스 라이브러리(MIT, GitHub 2.3k stars). OpenClaw 기반 Slack 배포, ComfyUI, 멀티에이전트 노드별 라우팅까지 지원
- 실증 결과: quality-only 설정에서 학습형 라우터가 최강 고정 모델 대비 평균 14.6% 상대 향상. 비용 가중치 $\beta$가 커질수록 라우터 순위가 크게 역전(quality-first 하위권 라우터가 cost-heavy 구간 1위로). 개인화 라우터는 페르소나 judge와 실사용자(234건) 양쪽에서 user-agnostic 라우터를 앞서지만 두 설정의 1위가 다름(GMTRouter vs PersonalizedRouter)

## 한계
- multi-turn 라우터(Router-R1 등) 세 개 모두 rule-based baseline보다도 낮은 평균 성능(22~23% vs 37~39%). 논문은 고정 베이스 모델(Qwen2.5-3B-Instruct)의 역량 부족 탓으로 돌리지만, 더 큰 베이스 모델로의 ablation이 없어 "multi-turn 라우팅 자체의 한계"인지 "실험 설정의 한계"인지 분리되지 않음
- 5개 컴포넌트 공식화를 직접 검증하는 ablation(컴포넌트 mix-and-match 등)이 없음. 실질 기여는 "통일 이론의 실증"보다 "16개 라우터의 공정 비교 인프라"에 가까움
- 후보 풀이 18개 오픈웨이트 모델(Together/NVIDIA NIM)로만 구성되어 프론티어 프로프라이어터리 API(GPT-5, Claude, Gemini)가 빠짐. 실무에서 라우팅이 가장 절실한 "고가 프론티어 vs 저가 오픈웨이트" 시나리오가 검증되지 않음
- 라우터 자신의 추론 비용/지연(그래프 메시지 패싱 vs 무연산 EloRouter 등)이 목적함수 $c(\tau)$에 포함되는지 불명확
- 개인화 트랙의 실사용자 검증이 15명·40세션·234건으로 규모가 작아 시뮬레이션-실사용자 격차(GMTRouter 1위→6위)의 통계적 안정성이 제한적
