# Training Object Permanence in World Models

> 원제: Training Object Permanence in World Models
> 리뷰: [블로그 전문](https://rina-oo.github.io/posts/2609.28654/)

## TL;DR
발달심리학의 object permanence(가림-재등장 시 정체성·개수 유지)와 object solidity(고체는 서로 통과 불가, 지지 제거 시 낙하) 개념을 video-to-video 생성 모델 평가·학습에 그대로 옮긴 논문. 150개 Blender 생성기(OP 3종 + OS 3종 패밀리)로 1.5M 학습 샘플과 300문항 고정 시험을 만들고, Cosmos3-Nano를 이 데이터로 파인튜닝한 PWM-WROP(16B)를 공개. 14개 모델(true-continuation / reference-to-video / edit-transfer 세 인터페이스 클래스) 블라인드 페어와이즈 인간 평가(Bradley-Terry, 20명 rater, 361 judgments)에서 PWM-WROP는 전체 3위, true-continuation 클래스 내 1위(Elo 1679.5, 320×192 저해상도 출력에도 불구하고). VLM 채점자의 core knowledge 결함을 우회하기 위해 판정을 전적으로 인간에게 맡긴 것이 방법론적 핵심.

## 핵심 기여
- 150개 생성기를 구조적 파라미터(난이도 결정, 샘플마다 체계적 변화)와 표면적 파라미터(시각적 다양성만, 물리 문제는 불변)로 분리 설계 — 표면 단서로 정답을 유추하는 shortcut을 차단.
- rigid-body solver 없이 전 궤적을 Blender 키프레임으로 수작업 저작 — occlusion/contact 타이밍을 프레임 단위로 정확히 통제.
- 평가에서 인터페이스 클래스(true-continuation / reference-to-video / edit-transfer)를 명시적 팩터로 구분해 순위 해석의 혼동을 방지. reference-to-video 클래스가 "자기 타임라인으로 재생성"하는 자유 덕에 상위권을 장악하지만 정체성·배치 보존에서는 취약함을 정성 분석으로 함께 제시.
- 실패 양상을 representation dropout(가려진 동안 상태 유지 실패)과 causal decoupling(개별 사건은 그럴듯하나 사건 간 인과 연결 실패)의 두 축으로 정리.
- 자동 지표(LPIPS/SSIM/FID 등)와 인간 판정의 괴리를 직접 보여줌 — 정적 장면을 리페인트하는 edit 모델이 사건을 안 그리고도 구조적 지표에서 고득점 가능함을 지적.

## 한계
- PWM-WROP만 WROP 데이터로 파인튜닝됨 — 다른 아키텍처를 동일 데이터로 학습시킨 대조군이 없어 "아키텍처 효과 vs. 데이터 효과"를 분리하지 못함(저자도 인정).
- PWM-WROP의 자동 지표 우위가 자신의 네이티브 저해상도(320×192)에서 측정됨; 720p 스케일 재계산 시 순위 하락 — 해상도가 결함을 가리는 효과 가능성은 논문에서 미검토.
- 20명 rater, 361 judgments로 14개 모델을 비교하기엔 신뢰구간이 넓어 5~11위 구간은 통계적으로 구분 불가; "3위"라는 단일 순위보다 "상위 4개 그룹" 정도로 읽는 것이 더 정확.
- OS-3(충돌) 패밀리에서 PWM-WROP가 8위로 급락 — occlusion 추적 능력은 파인튜닝으로 잘 전이됐으나 접촉 동역학(운동량 전달)은 상대적으로 덜 개선됨.
