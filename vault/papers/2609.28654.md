# 가려진 공을 기억하는가 — Training Object Permanence in World Models

> 원제: 가려진 공을 기억하는가 — Training Object Permanence in World Models
> 리뷰: [블로그 전문](https://rina-oo.github.io/posts/2609.28654/)

## TL;DR
비디오 생성 모델이 object permanence(가림 뒤 물체 존속)와 object solidity(고체 충돌·낙하 제약)를 내재화했는지 검증하는 WROP 벤치마크를 제안한다. 150개 Blender 생성기(OP 3종, OS 3종)로 150만 샘플 학습 코퍼스와 300문항 고정 exam을 생성하고, VLM 채점자의 core-knowledge 결함을 피하기 위해 20명 사람 평가의 blind pairwise Elo를 primary metric으로 쓴다. 이 데이터로 Cosmos3-Nano를 파인튜닝한 PWM-WROP(16B)이 true-continuation 계열 1위, 전체 3위를 기록해, domain-specific 합성 데이터로 물리 추론을 학습시킬 수 있다는 증거를 제시한다.

## 핵심 기여
- OP(occlusion 추적) 3종·OS(고체성) 3종 총 150개 태스크 생성기. 구조 파라미터(난이도 결정)와 표면 파라미터(시각적 다양성)를 분리해 표면 단서로 정답을 맞히는 걸 방지.
- 150만 샘플 학습 코퍼스 + 300문항 exam, input/target을 사건의 temporal midpoint에서 절단하는 V2V 프로토콜.
- true-continuation·reference-to-video·edit-transfer 세 인터페이스 클래스로 14개 모델을 나눠 분석 — reference-to-video가 자유도 덕에 유리하다는 설명틀 제공.
- Cosmos3-Nano 파인튜닝 모델 PWM-WROP: true-continuation 1위(Elo 1679.5), 전체 3위. OP-2에서 1위지만 OS-3(충돌)에서 8위로 OP/OS 간 성능 비대칭 확인.
- 실패 유형을 representation dropout(물체 존재 표현 소실)과 causal decoupling(개별 사건은 그리지만 인과 연결 실패)으로 정리.
- automatic metric(CLIP, SSIM 등)이 물리 위반을 포착하지 못함을 실증 — human preference를 primary로 쓴 방법론적 선택을 정당화.
- AWS Trainium2 네이티브 PyTorch 학습 스택(pwm) 공개, step time 15.1s→5.7s 최적화 기록.

## 한계
- PWM-WROP 성능 향상이 WROP 데이터 파인튜닝 효과인지 Cosmos3-Nano 베이스 자체의 강점인지 분리하는 ablation(파인튜닝 전 baseline)이 없음.
- OS 계열 신뢰구간이 매우 넓음(패밀리당 36~44게임) — 중위권 5개 모델이 109 Elo 안에 몰려 순위 구별이 어려움.
- rater 20명의 판정 분포(편중 여부)가 명시되지 않음.
- 태스크가 모두 "정적 장면 + 단일 핵심 사건" 구조라 복합·연쇄 사건은 다루지 않음(저자도 스코프로 명시).
