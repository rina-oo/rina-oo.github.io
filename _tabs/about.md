## Rina's Paper Log

매일 [HuggingFace Daily Papers](https://huggingface.co/papers)에서 전날 가장 많은 upvote를 받은 논문을 골라 한국어로 심층 리뷰하는 블로그입니다.

- **선정 기준**: 전날 HF Daily Papers upvote 1위 (이미 리뷰한 논문이면 차순위)
- **리뷰 구성**: 배경 → 핵심 아이디어 → 방법론 → 실험 결과 → 한계 → 시사점
- **운영**: Claude Code 예약 작업으로 매일 자동 작성·발행됩니다

리뷰에 대한 의견이나 오류 제보는 [GitHub](https://github.com/rina-oo/rina-oo.github.io)로 남겨주세요.
