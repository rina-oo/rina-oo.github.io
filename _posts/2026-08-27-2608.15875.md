## 한눈에 보기

- **핵심 기여**: (1) System 1(행동)·System 2(이해)·System 3(예측·평가)로 나뉜 3계층 구조를 하나의 배포 정책 안에 통합 (2) 37,256시간의 이질적 임바디드 궤적(실로봇/UMI/EGO/시뮬레이션/월드모델 생성)과 2억 7천만 개 VLM 샘플을 원스테이지로 동시 학습 (3) Soft Knowledge Insulation으로 행동 학습이 VLM의 언어·시각 능력을 갉아먹지 않게 조절 (4) GigaWorld-1 기반 World Value Model이 미래 관측(subgoal image)과 진행도 가치(value)를 동시에 예측해 System 1에 조건으로 제공 (5) 오프라인 AWR → 온라인 actor-critic + 사람 교정으로 이어지는 배포 후 지속 개선 파이프라인
- **성능**: post-training 없이도(zero-shot) 학습 데이터에 없는 물체·장면·과업 조합에서 언어 지시를 따르고 변형 가능한 옷 접기를 수행. post-training 후에는 언어 추종 과업에서 AgileX PiPER 91.5%, Maker H01 84.2%(둘 다 π0.5·GigaBrain-0.1보다 우위)를 기록했고, 복합 조작 과업에서는 H01 평균 74.1%로 π0.5(45.2%)와 GigaBrain-0.1(43.2%)을 크게 앞섭니다. - **한 줄 요약**: "무엇을 할지"(System 2)와 "어떻게 될지·잘 되고 있는지"(System 3)를 행동 생성(System 1)에 명시적으로 주입하고, 그 정책을 대규모 이질적 경험으로 학습시킨 다음 실제 배포 경험으로 계속 다듬어가는 임바디드 파운데이션 모델입니다.

## 어떤 문제를 풀려고 했나

VLA(Vision-Language-Action) 모델들은 사전학습된 VLM을 행동 생성기로 개조해서 꽤 강력한 성능을 내고 있지만, 저자들은 두 가지 근본적인 한계를 지적합니다.

첫째, **데이터 이질성 문제**입니다. 로봇마다 자유도·액션 스페이스·실행 조건이 다 달라서, 단순히 데이터를 많이 모은다고 무조건 좋아지는 게 아니라 정렬(alignment) 없이 섞으면 오히려 서로 간섭한다고 합니다.

둘째, **반응형 구조의 한계**입니다. 대부분의 VLA는 "지금 보이는 것 → 다음 행동"이라는 즉각적 매핑에 머물러 있어서, 미래 상태를 미리 그려보거나 지금 하고 있는 행동이 실제로 진전을 만들고 있는지 스스로 판단하는 메커니즘이 부족하다는 겁니다. π0.7이나 GigaBrain-0.5M* 같은 최근 시스템들이 subgoal 이미지나 월드 모델 조건화를 시도하긴 했지만, 저자들은 "이해·예측·행동·경험기반 개선이 학습 생애주기 전체에 걸쳐 부분적으로만 조율되어 있다"고 표현합니다. 그래서 이 논문의 목표는 단일 정책을 더 키우는 게 아니라, 이해-예측-행동-지속개선을 하나의 시스템으로 통합하는 것입니다.

## 핵심 아이디어

### 3-시스템 아키텍처

GigaBrain-0.7의 뼈대는 아래 그림입니다.

![System 1(행동)·System 2(이해)·System 3(예측·평가)의 상호작용과 오프라인/온라인 강화학습 인터페이스](/assets/img/posts/2608.15875/fig2_architecture.png)
_Figure 6. GigaBrain-0.7 아키텍처 — System 2가 현재 관측+과업 지시를 받아 CoT와 서브태스크를 만들고, System 3가 같은 입력으로 미래 관측과 가치를 예측해 System 1에 조건으로 넘긴다_

그림에서 눈여겨볼 부분은 System 1(위쪽, 파란색)이 받는 입력의 개수입니다. 왼쪽부터 "memory + 현재 관측", System 2가 만든 "CoT + 서브태스크", "상태 + 로봇 ID"를 투영한 것, System 3가 만든 "미래 관측", 그리고 System 3의 가치에서 유도한 "Advantage" — 다섯 갈래 정보가 전부 System 1의 VLM 스트림에 토큰으로 들어갑니다. 오른쪽의 초록색 블록(온라인 RL)은 별도의 actor-critic 루프인데, 화살표가 System 1 쪽으로만 향하는 게 아니라 "HIL Rollout"과 "Offline RL"이라는 라벨을 달고 System 1에서 나가는 화살표도 있습니다 — 즉 배포된 정책이 만든 경험이 다시 학습 파이프라인으로 들어가는 순환 구조라는 걸 보여줍니다.

System 1은 PaliGemma2(3B) VLM과 Action Expert(0.5B)를 Mixture-of-Transformers(MoT)로 묶는데, 이 결합 방식이 논문에서 "Dual Stream"이라 부르는 구조입니다.

$$
\mathbf{O}^{\mathrm{AE}}_l = \mathrm{Attn}_l\!\left(\mathbf{H}^{\mathrm{AE}}_l;\; \bigl[\mathbf{H}^{\mathrm{VL}}_l,\,\mathbf{H}^{\mathrm{AE}}_l\bigr]\right)
$$

$\mathbf{H}^{\mathrm{VL}}_l$과 $\mathbf{H}^{\mathrm{AE}}_l$은 각각 층 $l$에서 비전-언어 스트림과 액션 익스퍼트 스트림의 은닉 상태이고, $\mathrm{Attn}(\mathbf{Q};\mathbf{C})$는 쿼리 $\mathbf{Q}$가 컨텍스트 $\mathbf{C}$의 키·값에 어텐션한다는 뜻입니다. 즉 액션 익스퍼트는 자기 자신뿐 아니라 VLM 스트림 전체와도 어텐션하는 반면(양방향), VLM 스트림 쪽은 자기 자신에게만 인과적(causal) 어텐션을 겁니다 — 액션 쪽 표현이 VLM의 사전학습된 언어 이해를 오염시키지 않으면서, 액션 쪽은 풍부한 의미 맥락을 끌어다 쓸 수 있게 하는 비대칭 설계입니다. 논문은 이 방식을 "Last-Layer Cross Attention"(액션 헤드가 VLM 마지막 층 표현에만 접근), "Multi-Layer Cross Attention"(층별로 대응하는 VLM 표현에 접근)과 비교했는데, 뒤쪽 실험 결과에서 다시 다루겠습니다.

### Soft Knowledge Insulation — VLM 지식을 지키며 행동을 가르치기

연속 행동 학습의 그래디언트는 VLM 백본을 크게 흔들 수 있습니다. 기존 KI(Knowledge Insulation)가 그래디언트를 아예 차단했다면, GigaBrain-0.7의 Soft KI는 계수만큼 줄여서 통과시킵니다.

$$
\nabla_{\theta_{\mathrm{VL}}} \mathcal{L}_{\mathrm{VLA}} = \nabla_{\theta_{\mathrm{VL}}} \mathcal{L}_{\mathrm{NTP}} + \alpha_{\mathrm{KI}} \nabla_{\theta_{\mathrm{VL}}} \mathcal{L}_{\mathrm{FM}}, \qquad 0 < \alpha_{\mathrm{KI}} < 1
$$

$\mathcal{L}_{\mathrm{NTP}}$는 언어·서브태스크·이산 행동 토큰을 예측하는 next-token 손실, $\mathcal{L}_{\mathrm{FM}}$는 flow matching으로 연속 행동을 생성하는 손실이고, $\alpha_{\mathrm{KI}}$가 후자의 그래디언트가 VLM 백본에 도달할 때 곱해지는 감쇠 계수입니다. VLM 백본은 언어 목표에서는 전체 그래디언트를 그대로 받고, 행동 목표에서는 줄어든 그래디언트만 받습니다. "완전 차단"과 "완전 개방" 사이의 다이얼을 하나 더 만든 셈인데, 다만 $\alpha_{\mathrm{KI}}$의 구체적인 값이나 이 값을 어떻게 정했는지에 대한 민감도 분석은 본문에 나오지 않아서, 이 부분은 실무적으로 얼마나 튜닝이 필요한 하이퍼파라미터인지 가늠하기 어려웠습니다.

### World Value Model — 미래를 상상하고 그 상상을 점수로 바꾸기

System 3는 GigaWorld-1을 로봇 조작 영상으로 이어서 사전학습한 뒤, 가치 추정을 얹어 만든 "World Value Model"입니다. 같은 백본에서 두 가지를 뽑아냅니다: 서브태스크 길이만큼의 미래 영상(마지막 프레임을 subgoal 이미지 $g_t$로 사용)과, 현재 실행이 과업 완료에 얼마나 가까워졌는지를 나타내는 스칼라 가치 $V_t$입니다. 이 둘을 실제로 어떻게 쓰는지 보여주는 그림이 인상적입니다.

![박스 뚜껑이 떨어지는 실패를 세계 모델이 미리 상상하고, advantage 값이 급락했다가 회복하는 과정](/assets/img/posts/2608.15875/fig4_system3_prediction.png)
_Figure 10. World Value Model의 예측과 평가 — 위쪽은 "실패 구간"과 "회복 구간"에서 실제 관측과 모델이 상상한 미래 관측을 나란히 보여주고, 아래 그래프는 시간에 따른 advantage 값_

위쪽 두 박스를 보면, 빨간 박스("Failure Window")에서는 실제 관측에서 상자 뚜껑이 떨어지고 있고, 모델이 상상한 미래("predict future")도 똑같이 뚜껑이 떨어지는 장면을 그립니다. 초록 박스("Recovery Window")에서는 실제 관측에서 로봇이 뚜껑을 다시 집어 뒤집기를 이어가고, 모델의 상상도 그 회복을 따라갑니다. 즉 이 월드 모델은 단순히 그럴듯한 영상을 만드는 게 아니라 현재 정책이 실제로 만들어낼 행동의 결과를 미리 반영해서 상상한다는 뜻입니다. 아래 그래프에서 이 상상이 숫자로 바뀌는데, 시간 축 300 부근에서 advantage가 0.08 근처에서 -0.16까지 급락했다가(실패 구간), 400 부근에서 다시 0.04~0.08 대로 회복합니다(회복 구간). 이 값은 다음 식으로 이산화됩니다.

$$
A_t = \mathbb{1}\!\left[V_{t+\delta_t} - V_t > 0\right] \in \{0, 1\}
$$

$V_t$와 $V_{t+\delta_t}$는 액션 청크 구간 내 두 시점의 가치 추정이고, 그 차이가 양수면 $A_t=1$(진전 중), 아니면 $A_t=0$(정체·후퇴)로 이진화해서 System 1의 프롬프트에 조건으로 넣습니다. 추론 시에는 항상 "진전 중"에 해당하는 조건으로 정책을 유도해서, 노이즈가 섞인 시연 데이터의 영향을 줄인다고 합니다. subgoal 이미지와 이 advantage 조건은 각각 50%, 15% 확률로 독립적으로 드롭아웃되도록 학습해서, 두 신호가 없을 때도 정책이 정상 동작하게 만듭니다.

개인적으로 흥미로웠던 지점은, 이 방식이 π0.7이나 π*0.6처럼 사람 라벨이나 VLM 추론에 의존해 행동 품질을 판단하는 접근과 달리, 전적으로 학습된 월드 모델의 "미래 상상"에서 평가 신호를 뽑아낸다는 겁니다. 다만 이 상상이 실제 물리와 어긋나면(월드 모델의 hallucination) advantage 자체가 잘못된 방향으로 정책을 유도할 수 있다는 위험은 구조적으로 남아 있는데, 이 실패 모드에 대한 정량적 분석은 논문에 없습니다.

### 데이터 피라미드 — 얼마나, 어떻게 섞어야 느는가

37,256.98시간의 궤적 데이터는 실로봇(55.1%), UMI(22.2%), EGO(7.7%), 시뮬레이션(3.9%), 월드모델 생성(11.2%)으로 구성됩니다. 데이터 스케일링 실험 결과를 보면 이 구성의 의미가 드러납니다.

![사전학습 데이터 스케일에 따른 검증 손실, 로봇 데이터 스케일에 따른 성공률, UMI/EGO 조합 효과](/assets/img/posts/2608.15875/fig3_data_scaling.png)
_Figure 8. 데이터 스케일링 — (a) 데이터 비율별 검증 손실 곡선 (b) 로봇 데이터 비율에 따른 두 과업 성공률 (c) UMI·EGO를 섞었을 때 사전학습/후속학습 성공률_

(a)를 보면 12.5%부터 100%까지 다섯 개 곡선이 20만 스텝 내내 순서를 유지한 채 벌어져 있는데, 특이한 건 12.5%·25% 곡선이 12만 스텝 이후 다시 살짝 올라간다는 점입니다(과적합으로 읽힙니다) — 반면 100% 곡선은 계속 완만하게 내려갑니다. 데이터가 적을수록 어느 시점부터 검증 손실이 나빠지는 전형적인 과적합 패턴이 큰 데이터에서는 관측 기간 내에 나타나지 않는다는 뜻이라, "데이터를 늘리면 손실이 준다"보다는 "데이터를 늘리면 과적합 시점 자체가 뒤로 밀린다"는 해석이 더 정확해 보입니다.

(b)는 로봇 데이터 비율(5%→100%)에 따른 두 과업의 성공률인데, 과일 집기는 60%에서 시작해 완만하게 100%까지 올라가는 반면, 어질러진 옷 접기는 5%·15%에서 0%·10%로 거의 실패하다가 30%에서 30%, 60%에서 70%, 100%에서야 100%에 도달합니다. 저자들은 이걸 "긴 호흡의 변형 물체 조작이 더 넓은 사전학습 커버리지를 요구한다"는 근거로 씁니다. (c)는 로봇 3,000시간을 기준으로 UMI 또는 EGO 3,000시간을 각각 더했을 때와 둘 다 더했을 때를 비교하는데, 점선(사전학습만)과 실선(후속학습까지) 모두 "로봇+UMI+EGO" 조합이 가장 높습니다. 다만 여기서 짚고 싶은 점이 있는데, 이 비교의 마지막 조건(로봇+UMI+EGO)은 총 9,000시간인 반면 나머지 조건들은 6,000시간입니다. 즉 "여러 소스를 섞는 게 좋다"는 결론과 "데이터를 더 많이 넣으면 좋다"는 결론이 이 실험만으로는 완전히 분리되지 않습니다. 총량을 고정한 대조군(가령 로봇 4,500h + UMI 4,500h처럼 총합을 맞춘 조합)이 있었다면 더 설득력 있었을 것 같습니다.

### 경험 기반 강화학습 — 배포 이후에도 끝나지 않는 학습

post-training까지 끝난 정책을 실제로 배포한 뒤에도 학습이 이어집니다. 먼저 배포된 정책이 만든 롤아웃(성공·실패·사람 교정 포함)을 모아 AWR(Advantage-Weighted Regression) 방식으로 오프라인 정제를 하는데, 여기서 advantage는 $\tilde{A}_t = G_t - \tilde{V}_t$(누적 리턴에서 가치 추정을 뺀 값)로 정의되어 진행도가 높은 세그먼트에 더 큰 가중치를 줍니다. 이후 실제 로봇에 다시 배포해 사람이 어려운 상태에서 개입·교정하는 온라인 actor-critic 학습으로 넘어갑니다. 다만 이 온라인 RL의 구체적인 알고리즘·보상 설계는 "전용 후속 GigaBrain 리포트에서 상세히 다루겠다"고만 되어 있어서, 지금 이 논문만으로는 재현이 불가능한 부분입니다.

_\*Gemma 4의 Clean Desk는 제한된 범위의 위치 일반화 설정에서 별도로 평가됨_

| Architecture | Clean Desk | Fruit Picking | Shirt Folding | Train s/step | Infer. s |

두 표에서 읽히는 패턴은 "크다고, 혹은 정교하게 연결한다고 무조건 좋아지지 않는다"는 겁니다. 8.5B인 Gemma 4는 정돈된 책상 치우기·과일 집기에서는 가장 강하지만 옷 접기에서는 0%로 완전히 실패했고, 오히려 가장 작은 PaliGemma2(3.5B)만 옷 접기에서 0%가 아닌 성공률(30%)을 냈습니다. 결합 구조 쪽도 비슷해서, Multi-Layer Cross Attention은 Last-Layer보다 학습·추론 비용을 더 쓰고도 옷 접기에서 여전히 0%입니다. 저자들도 이 표들을 "엄밀한 스케일링 법칙이 아니라 아키텍처 선택을 위한 진단"이라고 못박는데, 표본이 과업 3개·평가 시행 수도 명시되지 않은 소규모 비교라는 점에서 이 신중한 표현이 적절해 보입니다. 결국 이후 모든 실험은 Dual Stream + PaliGemma2 조합으로 고정됩니다.

### 시뮬레이션 벤치마크

RoboTwin 2.0(50개 과업 co-train)에서는 π0.5가 Easy(70.7%)에서는 GigaBrain-0.7(66.8%)을 앞서지만, 도메인 랜덤화가 들어간 Hard에서는 GigaBrain-0.7이 67.9% 대 π0.5의 46.0%로 역전해서 Overall 67.35% vs 58.35%로 최종 우위를 가져갑니다 — 시각적으로 흔들리는 조건에서 더 강인하다는 뜻으로 읽힙니다. EBench(이동형·장기호흡 과업 포함)에서는 GigaBrain-0.7이 SR 33.30%·Score 46.1로 π0(23.59%/37), π0.5(28.08%/42)보다 앞섰고, Real2Sim2Real 방식인 RoboColiseum의 네 축(명령 추종·공간 추론·강건성·일반 조작)에서도 모두 최고점(0.82/0.47/0.68/0.61)이었다고 보고합니다. 다만 이 세 벤치마크 모두 "공식 리더보드에 있는 대표적인 공개 모델만" 뽑아 만든 표라서, 부록에 전체 리더보드 스냅샷을 따로 첨부한 점은 투명성 면에서 긍정적이지만, 본문 표 자체는 여전히 저자들이 고른 부분집합이라는 점은 감안해야 합니다.

## 아쉬운 점 / 의문점

- **데이터 총량 혼입**: 위에서 짚었듯, UMI/EGO 조합 실험에서 "로봇+UMI+EGO" 조건만 총 데이터량이 9,000시간으로 다른 조건(6,000시간)보다 많습니다. "이질적 소스의 조합 자체가 좋다"는 결론이 "데이터가 더 많아서 좋다"는 결론과 완전히 분리되지 않습니다.
- **MiMo 벤치마크 오염을 저자가 직접 인정**: 공개되는 최종 체크포인트의 헤드라인 점수(0.5704)는 저자들 스스로 "held-out이 아니다"라고 밝힌 수치이고, 실제 공정 비교치는 그보다 낮은 0.4621입니다.
- **아키텍처 비교의 프로토콜 불일치**: 백본 비교 표에서 Gemma 4의 Clean Desk 결과는 각주로 "제한된 범위 설정에서 평가"라고 밝혀져 있어, 같은 표 안에서도 완전히 동일한 조건의 비교가 아닙니다. 저자들도 이걸 "스케일링 법칙이 아니라 진단"이라 부르며 선을 긋습니다.
- **온라인 RL 세부사항 비공개**: 경험 기반 강화학습 절에서 온라인 actor-critic의 구체적인 알고리즘·보상 함수·사람 개입 프로토콜은 "전용 후속 리포트에서 다루겠다"며 이번 논문에는 나오지 않습니다. 지금 이 논문만으로는 해당 파이프라인을 재현할 수 없습니다.
- **코드·가중치는 아직 미공개**: 초록에 "학습 코드와 사전학습 가중치를 공개할 예정"이라고 미래형으로 적혀 있어, 이 글을 쓰는 시점 기준 실제로 접근 가능한 저장소인지는 확인하지 못했습니다.
- **초안 흔적**: 앞서 언급한 대로 LaTeX 소스에 전혀 다른 논문(월드 모델 정책 평가자)의 초록과 결론 초안이 주석으로 남아 있어, 최종 교정 이전 상태로 공개된 것으로 보입니다.
- **평가 시행 수 미기재**: "과업당 보통 10~20회"라고만 밝혀져 있고, 데이터 스케일링 곡선의 각 점이 정확히 몇 회 시행의 평균인지는 본문에서 확인하지 못했습니다. 로봇 실험에서 이 정보는 신뢰구간을 가늠하는 데 중요한데, 아쉽게도 공개되어 있지 않습니다.

## 마치며

이 논문에서 가장 기억에 남는 건 화려한 벤치마크 수치보다는, System 3 소거 실험에서 "성공률은 이미 포화됐는데 평균 점수와 완료 시간은 계속 개선된다"는 관찰이었습니다. 로보틱스 논문들이 보통 이진 성공률 하나로 승부를 보려는 경향이 있는데, 여기서는 "안 되던 걸 되게 하는 것"과 "되는 걸 더 잘하게 하는 것"을 구분해서 봐야 한다는 걸 데이터로 보여준 셈입니다.

여담이지만, 이 논문이 데이터 총량 37,256시간이라는 숫자를 여러 차례 강조하는 것과 별개로, 정작 성능 격차가 가장 크게 벌어지는 곳은 자체 하드웨어인 Maker H01이라는 점이 눈에 띕니다. 개인적으로는 다음 GigaBrain 보고서에서 (1) 온라인 RL의 구체적인 알고리즘이 공개되는지, (2) 코드·가중치가 실제로 릴리즈되는지, (3) 데이터 총량을 통제한 소스 조합 실험이 추가되는지를 관전 포인트로 잡고 지켜볼 것 같습니다.
